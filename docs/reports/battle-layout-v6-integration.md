# 对战布局 V6：扩展场地与整副手牌收起

2026-10-11。调整 Godot 场地预览布局，复用上一版 imagegen 生成的透明刻纹与卡图边框。

- 手牌两侧下移，中间形成拱起的弧线；选中牌仍会伸出、置于最上层，右键先收回选中牌。
- 无选中牌时，右键收起整副手牌，再次右键展开。底部同时提供“收起手牌／展开手牌”按钮。收起清除选择、拖动和手牌点击区域，保留原始卡牌投影；展开恢复原有布局。
- 解析区宽度增至场地的78%。我方解析区高度增至41.5%，下沿到场地高度的99%，延伸到手牌背后。
- 双方施法区高度从6%增至9%，与解析区保持间隔，继续用连续地面刻纹提示范围。
- 方形卡图缩至1080p下最多80像素。阵法从解析区左上开始排列，法术按所属阵法的环位索引从左到右布置，空环位保留位置；不绘制格子。改变环位数量不会把阵法重新居中。
- 详情、效果选择、隐私遮挡继续使用现有交互。效果选择弹窗显示时，右键不会收起手牌或绕过强制选择。

修改位置：`godot/ui/field_canvas.gd`、`godot/pages/field_page.gd`、`godot/tests/frontend_smoke.gd`。复用素材位于 `godot/art/battle-v5/`，原始源图与生成提示词位于 `assets/art/godot-2d-v2/battle-production-v5/`。

Godot 4.7.2 实际 OpenGL 渲染检查通过721项，覆盖1280×720、1600×1000、1920×1080、30张官方卡牌、0/1/7/12个环位、五个阵法和20张手牌。新增检查包括底部区域覆盖、卡图左对齐与稳定位置、右键收起／展开、隐藏手牌无点击区域、按钮关闭选择UI，以及强制效果选择时的右键防护。最新日志无错误，修改文件的 `git diff --check` 通过。
