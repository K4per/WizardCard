# 当前规则内核、独立动作查询与 Godot 单前端

已接受，2026-10-27。延续 ADR 0001 的 C++17 权威内核和单进程模块化，只支持 2.5.5 / mechanicsRevision 9；历史规则执行器退出生产，当前 2.5.5-hotfix.1 复盘通过格式适配保留。稳定查看者投影、无副作用动作查询、时钟及增量事件分别传输，协议升级后拒绝混合客户端，以消除查询试执行和全量动作组合对常规读取的成本。

卡牌能力在装载时绑定静态处理器，通用原语负责状态变更与触发时序；共享不可变卡池，命令仍通过运行状态副本原子提交。预算耗尽回滚并技术暂停，只有经规则确认的循环可判平局。Godot 保持唯一产品前端，删除 SFML 专属实现并保留共享交互、表现和声音决策逻辑，避免双前端持续迁移成本。
