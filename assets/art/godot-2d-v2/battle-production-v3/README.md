# WizardCard 对局美术资产 V3

以 dungeon-topdown/source-v2.png 为视觉基准，使用内置 imagegen 生成。卡框、卡背和原有卡牌插图继续复用，不包含在此次重绘范围。

- 地下城场地底图：`01-dungeon-background.png`，1 个取用区域。
- 连续施法区、解析行与分隔刻纹：`02b-field-structure-atlas.png`，3 个取用区域。
- 放大卡牌详情面板：`03-card-detail-panel.png`，1 个取用区域。
- 卡牌上方操作条：`04-card-actions-atlas.png`，6 个取用区域。
- 对局效果候选选择弹窗：`05b-effect-selection-popup.png`，10 个取用区域。
- 通用按钮与控件：`06-common-controls-atlas.png`，16 个取用区域。
- HUD与荷载进度条：`07-hud-load-bar-atlas.png`，6 个取用区域。
- 生命、魔素、荷载图标：`08-resource-icons-atlas.png`，3 个取用区域。
- 卡图交互状态：`09-selection-state-atlas.png`，8 个取用区域。
- 牌库、副卡组、灰烬区底座：`10-zone-plates-atlas.png`，4 个取用区域。

共12组正式图像，74个取用区域。计数包含整块弹窗与它的组成区域，不代表74张互不重叠的独立图片。原生图像尺寸见 image-metadata.json；背景原图1672×941，另提供适配1920×1080版本。透明素材保持生成的原生尺寸，避免切片坐标失效。

## 对局效果选择弹窗

正式使用 05b-effect-selection-popup.png。05-search-decision-modal.png 是澄清前的通用检索设计，已废弃，不要用于对局效果。

- 由效果触发弹窗，标题显示当前效果要求。
- 候选区仅展示当前可选择的卡牌；数量由实际决定数据提供。
- 点选候选展示完整卡牌/说明，并标记选择状态和已选数量。
- 确认是否可用由当前选择条件决定。
- 返回/取消仅在当前决定允许时显示；强制决定不提供关闭入口。
- 弹窗时禁用场地操作，背景遮罩用运行时纯色半透明层绘制。
- 同一外观可用于检索、选择目标、选择材料等流程，文案与候选内容动态提供。
- 整体图已包含按钮、分页箭头的外观。正式接入可用74区中的组件分开组装，尤其需要隐藏返回时，应使用独立页眉、候选主体、页脚底纹和按钮，不能直接把整图按钮当作可隐藏控件。裁图中的装饰不构成交互功能。

## Godot取用建议

atlas-regions.json 提供基于原始PNG像素的 [x,y,width,height] 坐标，可作为 AtlasTexture.region 的起始坐标。不要把整张图集直接贴到场景中。较宽的区域包含透明边距，排版时按可见内容对齐；部分组件具有柔和透明光晕。

- 场地底图最底层；连续施法区刻纹置于其上，可进一步降低透明度。
- 解析行按实际阵法数量重复；阵法槽和右侧长条内显示卡图裁切，保持行归属。
- 完整卡牌继续使用既有卡框，只出现在手牌、放大详情及需要完整卡牌的候选展示中。
- 卡牌操作条浮于点选卡图上方；文字由Label等运行时控件叠加，详情面板不承载操作按钮。
- 荷载条：load_track 是底槽，load_fill_normal / load_fill_warning 为内侧色带区域，不含外框。两种色带区域高度相差1px，接入时统一显示高度，叠于底槽内，并按荷载/容量裁切，数值另行显示。警示条件由游戏状态提供。
- 按钮具备正常、悬停、按下、禁用外观；焦点可叠加选择/高亮素材。图集各状态尺寸及留白可能不同，接入前统一控件的显示矩形。
- 为保证像素边缘，缩放采用最近邻。大型面板可先按比例显示；九宫格拉伸边距需要实际排版后确定，尚未验证。
- 弹窗与滑条里已绘制的按钮/滚动条只提供皮肤，需要真实控件与交互区域；不要误认为图片提供功能。
- 这批为静态美术资产；呼吸高亮、进度变化等由引擎实现，未提供动画帧。

## 核验与版本

所有正式透明UI PNG已检查具有透明像素，图集坐标已检查不超出图像边界。alpha抽检数量和SHA-256记录在 image-metadata.json。经过目视审阅，02b 的刻纹替代过亮的02；05b按最新说明替代05。两个旧版本留存便于追溯，不进入正式素材压缩包。

本次未修改Godot场景或替换现有素材，也未完成运行时排版/导入测试。图集由生成工具绘制，正式适配时仍需检查小尺寸辨识度、各状态对齐和九宫格边距。

生成提示词：generation-plan.json 为初版各组提示；revision-prompts.json 为施法区和效果弹窗修订提示。index.html 可浏览全部正式素材。
