# WizardCard 2.5.0-preview.3-hotfix.1

本 hotfix 在 preview.3 的 Godot 前端和卡图发布基础上，加入正式风暴系列卡牌及其规则实现、法律动作、AI选择、联网投影和回归测试。规则与卡池版本继续使用 `2.5.0`；程序版本推进至 `2.5.0-preview.3-hotfix.1`。

卡池现有62种正式卡牌，包含15张阵法、22张解析法术、12张言灵法术、8张咒符法术和5张符文。卡牌效果与数值见[正式卡池图鉴](../card-catalog.md)。

本次修正 Alpha v2 持续法术每个全局结束阶段递减的行为，并将新状态字段纳入 2.5 状态摘要，同时避免改变旧版本摘要格式。详细验证结果见[交付报告](../reports/2.5.0-preview.3-hotfix.1.md)。
