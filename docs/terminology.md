# 卡牌与操作术语规范

玩家自带基础荷载容量2，总容量为基础容量与场上阵法容量之和。阵法卡面容量仅表示自身贡献；均衡8+2=10，生命之五芒星5+2=7。

适用版本：程序1.0.0-alpha、规则1.0.0、卡池1.0.0。界面与卡面采用以下用词；卡牌名称、ID、效果参数和规则含义沿用用户设计。历史报告中的旧称保留为当时记录。

## 稀有度

| 内容ID | 界面名称 |
|---|---|
| common | 普通 |
| uncommon | 罕见 |
| rare | 稀有 |
| epic | 史诗 |
| legendary | 传说 |

详情与组合筛选共用此映射，内容ID继续用于保存和查询；显示修正不改变卡牌规则。

## 卡牌与区域

当前卡名以卡池图鉴与 `assets/cards.json` 为准。旧名映射：结构瓦解→碎环术、清心→心如止水、蓄能阵→阿克乌姆之弧、导流阵→逆三角星符、均衡→均衡之六芒星。“混乱波”旧资料按持续来源荷载效果对应紊乱波动，不是魔力扰动。

**空白阵法**指不承载解析法术的阵法，附着符文本身不取消空白资格。正式术语使用“空白”，旧“空闲”仅为历史同义词；基础阵法不能成为相关销毁目标，其他保护另按卡牌规则。

**构筑方向**指核心收益与操作路线，**预设卡组**是具体牌表。当前五种代表性构筑方向、九套预设，不将历史的四套/七套作为当前数量。

| 正式名称 | 含义与使用范围 |
|---|---|
| 卡牌 | 统一称呼，不混用“卡片”“手卡” |
| 行动卡 | 从手牌使用，处理行动效果 |
| 解析法术 | 需要开始解析，解析完成后准备施法再释放，或按明确能力直接释放 |
| 言灵法术 | 可预置；符合声明时机时响应，设置后立即释放的卡牌另按其效果处理 |
| 阵法卡 / 阵法 | 前者为卡牌类型，后者为场上的阵法或规则对象 |
| 符文卡 / 符文 | 前者为卡牌类型，后者为附着的符文或规则对象 |
| 卡池 | 当前版本所有可用于构筑的卡牌；无筛选时全部可查询，分页浏览 |
| 主卡组 | 构筑时的30张卡牌，同名最多3张；同名计数不以ID代替 |
| 基础阵法 | 从明确具有资格的阵法中选择，不计入30张主卡组 |
| 牌库 | 对局中尚未抽取的卡牌区域；不能用该词称呼编辑器中的30张构筑 |
| 手牌 | 玩家持有、尚未打出的卡牌 |
| 解析区、言灵区、施法区、行动区、灰烬区 | 对局区域；状态改变使用“进入/离开”相应区域 |

## 费用与资源

取消能力分开命名：`cancel`＝取消准备；`negate_link`＝取消合法待结算链节；`counter_spell`＝法术反制，对方待释放法术无效并销毁，反制者承担该目标实际施法费用等量的次回合临时荷载。它们不是同一字段的三个别名；声明的响应条件与目标仍须合法。

| 正式名称 | 含义 |
|---|---|
| 魔素 | 可支付的资源；支付魔素与增加荷载分别描述 |
| 使用费用 | 行动卡的基础费用 |
| 解析费用 | 解析法术开始解析时的费用 |
| 施法费用 | 解析法术准备施法时支付，已准备的法术实际释放时不重复支付；就绪直接释放/快速响应在宣告时支付 |
| 设置费用 | 设置阵法或预置言灵法术的费用；立即释放卡牌按其定义设置并释放 |
| 附着费用 | 附着符文的费用 |
| 额外成本 / 弃置成本 | 如准备施法时额外弃置手牌；属于宣告支付，不因反制默认返还 |
| 位阶 | 解析法术、言灵法术的属性；其他类型不显示虚构的“位阶0” |
| 阵体、荷载上限、环位数、承载位阶上限、魔素收入 | 阵法属性；不把荷载上限笼统写成“容量” |
| 绑定荷载 | 与卡牌实例关联的荷载，按规则随实例清理 |
| 临时荷载 | 有到期或临时清除规则的荷载 |
| 临时生命之核 | 独立于生命，取较高值，伤害先扣除，默认不随回合到期 |
| 来源关联临时荷载 | 只随指定来源销毁或临时清除效果清理 |
| 埋伏 / 反转 | 支付1魔素背面放置 / 在后续全局回合翻开并支付费用发动 |
| 咒文速度 | 1–4速，限制阶段及连锁跟随；四速之后不可响应 |
| 独立荷载 | 保留至被对应效果清除；生命缝合产生的2点属于此类 |
| 魔力过载 | 状态检查时总荷载超过荷载上限导致的败北 |

卡池筛选的“费用”比较各类型的基础费用（`cost`），详情展示其具体名称；“施法费用”仅匹配解析法术（`castCost`），“位阶”仅匹配两类法术。筛选组合取交集。特征标签使用伤害、回复、抽牌、弃置、反制、准备施法、魔力荷载、魔素收入等；用户明确设计的标签原样保留。

## 操作与效果

| 正式名称 | 含义与区别 |
|---|---|
| 设置阵法 / 替换阵法 / 拆除阵法 | 对应设置、替换和主动拆除；不统称“使用” |
| 开始解析 | 支付解析费用，将解析法术放入合适阵法的环位 |
| 解析中 / 解析完成 | 解析法术的状态；“解析完成”仍需准备施法 |
| 准备施法 | 宣告目标与额外成本，支付施法费用，开放规定响应窗口 |
| 待释放 | 已完成准备并进入施法区的法术状态 |
| 释放法术 | 施法阶段选择法术，按规则建立连锁并结算；不写作“施放” |
| 持续生效 / 维持专注 | 持续法术的状态或专注维持操作，保留定义中的持续方式 |
| 预置言灵法术 / 设置并释放 | 区分预置与设置后立即释放的卡牌 |
| 响应 / 放弃响应 | 持有优先权时，在合法窗口宣告响应或让出优先权；不称为“触发言灵” |
| 被动触发 / 结算被动触发 | 规则或卡牌条件产生的触发，与玩家主动响应区分 |
| 附着符文 / 拆除符文 | 统一使用“附着”，卡面对应“阵法附着效果 / 法术附着效果” |
| 使用行动卡 | 支付费用并宣告行动效果 |
| 弃置 | 手动或效果要求的弃牌操作；不混用“丢弃” |
| 销毁 | 效果或规则销毁对象，按关联清理处理；与弃置、拆除分别描述 |
| 放弃法术 | 主动移除自己场上可放弃的卡牌，不称为“取消施法” |
| 取消链节 / 取消准备施法 | 反制具体宣告；支付不默认返还 |
| 清除荷载 | 效果清除；强制分配选择可用“移除1点临时荷载” |

五阶段名称继续使用“抽卡、准备、主要、施法、结束”。构筑操作使用“加入一张、移除一张、保存卡组、保存草稿、返回卡组列表”；构筑移除不会产生对局中的弃置或销毁效果。

连锁完整规范仍以[五阶段与轻量连锁](alpha-v1.0-rules.md)为准。构筑界面不会修改卡牌定义。
