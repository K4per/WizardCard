# WizardCard Alpha v2.5.2

发布日期：2026-10-21。程序、规则与卡池版本均为 `2.5.2`，机制修订为 `5`，内容哈希为 `d68b7eefca8e509a`。

- 完整接入最新设计的 101 项定义，保留恩格亚斯四角星兼容卡，正式卡池达到 102 张；包含 17 张阿卡那与 19 张味契卡。稳定 ID 保留旧卡组关联，支援术迁移为言灵；正十字、逆十字和安卡十字沿用 2.5.1 规则。
- 修复多符文连续附着、单枚解除、宿主离场清理，以及对方回合合法时点的高速咒符反转。恢复统一的“移除阵法”入口与确认流程。
- 碎环术先完成设置、解析和无目标准备，在发动时选择对方空白阵法；副卡组阵法送灰在结算时处理，没有可送灰阵法时不破坏目标。
- 临时生命可以按来源叠加，分别记录期限、吸收伤害与到期清除；对局投影、网络快照和复盘保留来源明细。
- 修复图鉴和构筑超过 48 张卡时的插图引用失效；102 张正式卡均检查实际插图。多步目标、移除确认、快速反馈和多枚符文命中使用权威动作与当前投影。
- 收录 25 张阿卡那与星芒原图，以及三张新提供的味契原图；炙烤、吹火术、回火已抠为透明 PNG 并使用独立插图，登记来源与哈希。地震术共用碎环术插图。
- 终局复盘改为后台验证，验证期间继续发送心跳；确认验证通过后再保存和回执，修复完整对局结束时客端超时的问题。

12 组 Godot 前端烟测与正常对局、投降、断线重连三个双进程联机场景通过。全量原生测试、打包校验与下载文件校验值见[交付报告](../reports/2.5.2.md)；逐卡测试范围见[验收矩阵](../reports/alpha-v2.5.2-card-acceptance.md)。

旧复盘继续按版本、机制修订和内容哈希检查兼容性，不兼容文件在加载前明确拒绝。下载包解压后运行 `WizardCard.exe`。
