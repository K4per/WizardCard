# 首轮探索测试

> **模板与交付边界**：用户已取消2026-10-07本次Alpha v1.0的20局真人门槛，按自动验收交付。下文保留探索模板，尚无填写入库的真人记录；是否为后续内容平衡重新设立20局门槛待用户决定，不能把此模板当作本次发行未完成条件。

目标约20局真人对战；每组交换先后手与操作者。固定卡池版本，不在同一轮同时调整多组核心参数。命令行 smoke 仅检查规则稳定性，不计入真人场次。

每局保留 `logs/local-match.json`，并填写下表（复制表格逐局追加）：

| 项目 | 记录 |
|---|---|
| 日期 / 两位操作者 | 待填 |
| 程序 / 规则 / 卡池版本 / 内容哈希 | 由复盘读取 |
| 复盘文件 / 种子 / 先手 | 待填 |
| 胜负与原因 / 双方自己的回合数 | 待填 |
| 连续等待回合及原因 | 待填 |
| 荷载是否形成取舍 / 突然过载 | 待填 |
| 言灵是否值得预置 / 是否锁死施法 | 待填 |
| 阵法是否存在必选路线 | 待填 |
| 符文是否改变准备决策 | 待填 |
| UI 障碍、错误提示及复现步骤 | 待填 |

调整记录必须包含：观察依据、旧数值、新数值、预期改善、卡池新版本与测试批次。20局仅是探索，不得据此宣称平衡。

人工验收：检查窗口缩放及中文、滚动选择、所有决策弹窗、响应换手遮挡、结束弃牌、终局与重开；从解压后的独立目录启动，确认字体及资源无需依赖源码树。
