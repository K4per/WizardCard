# WizardCard 2.5.0

Alpha v2.5.0 将开局阵法选择、抽阶清理、法术施法区生命周期和局域网权威计时纳入正式规则。旧版 `2.0.0-rc.1` 复盘格式明确拒绝播放。

## 已实现

- 开局从副卡组选择等级 1 阵法，候选隐私、同时公开、免费设置和副卡组扣除。
- 抽阶临时资源清理顺序，以及持续法术准备、发动和回位时序。
- 局域网 300 秒计时、回合补充、断线冻结、超时判负和同回合网络投影更新；本地、AI、教学不计时，联网菜单与设置继续计时。
- 程序、规则和卡池更新为 `2.5.0`，网络协议 3、复盘格式 4；新增命令追加到编码末尾。
- Godot 对局场景改为可编辑骨架和布局资源：全屏场地、双方中心对称、每方 5 行阵法槽及对应法术区域、中央紧凑施法区、并列状态栏、合法卡高亮、悬停详情和 Esc 菜单。
- 页面、状态栏、菜单、确认框、换手遮罩、区域查看器和决策面板保存在 `.tscn`；对局及复盘引用可编辑的 `simple_battle_theme.tres`。布局资源改变区域/牌堆位置，Scene Region Overrides 支持手调节点锚点。
