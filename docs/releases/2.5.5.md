# Alpha v2.5.5（2026-10-25）

- 程序、规则和卡池版本统一为 `2.5.5`，机制修订为 `9`，正式卡池135张。
- 符文不再提供玩家手动拆除动作；效果拆除与宿主离场仍按原持有者进入灰烬区。卡牌实例同时保存所有者与控制者，回放和联机投影沿用该归属。
- 阵法手动设置、替换、拆除共享每回合一次额度，效果操作不消耗该额度；七星开阳替换瑶光、启曜无合法目标回滚和耀/黯分支校验已收紧。
- 法术反制的 X 使用目标链节实际设置费用与实际发动费用之和，覆盖折扣、附着符文和替代支付；血契心印和风契指示物显示由权威合法动作与投影驱动。
- 暂时关闭时点弹出音效，设置中可独立恢复；更新地震术卡图、图鉴和运行时资产校验。

## 验证范围

本版本完成原生核心构建、七星与血契专项测试、卡池/图鉴同步校验、前端风契和血契提示烟测，以及 Windows x64 便携包启动、内容校验和回放验收。联机和跨平台回放由 GitHub Actions 在推送后复核。

## 已知限制

- 历史 2.5.3/2.5.4 回放因版本、卡池或内容哈希变化而拒绝播放；旧牌组保留稳定 ID，可在构筑器中修复。
- Godot 编辑器与导出模板必须使用锁定的 4.7.2 版本；未安装模板时只可运行原生核心测试。
