依据 `E:\Project\WizardCard-Design\10.24`（`10.24改动报告.md`、【七星】系列、【血契】系列、卡图目录）整理。核对日期：2026-10-24。10.24 目录未包含新版玩家规则书；通用规则新增以改动报告为依据，卡牌字段同时核对各列表。内容源之间有矛盾时列入“待确认”，不得静默任选。以下均为待实现与验收需求。

## 1. 程序规则修改与缺陷修复

- [ ] 解析法术卡的目标选择改为在发动时才进行；设置、盖伏和准备施法时不提前要求选择发动目标。验证目标法术（如【战车】、【死神】、血刃系）从盖伏到发动的完整流程。
- [ ] 修复响应窗口弹出时，点击灰烬区、副卡组等可弹窗区域导致界面卡住的问题；连锁流程中此类弹窗要么禁止打开，要么打开后可正确关闭并恢复响应操作。覆盖双方均有响应机会、放弃响应、连续连锁等场景。
- [ ] 修复 AI【碎环术】会炸盖伏卡的问题：【碎环术】应只选择合法目标，AI 目标选择与玩家规则一致；补充 AI 目标合法性的回归测试。
- [ ] 回合数改为只以己方回合计数；检查回合数显示、按回合数生效的效果（如【七星】耀/黯）及日志、回放中的回合标记一致性。
- [ ] 规则化“那之后，可以……”类效果：后续效果必须以前置效果实际执行为前提（如【味契·烈火回炉】先回收才能抽卡，未回收则不可抽卡），且后续效果可选择是否适用。更新对应卡牌实现与测试。
- [ ] 修复【愚者】判定错误：言灵法术卡设置后自动准备并发动会进入施法区，【愚者】后错误地将其仍视为解析区，导致无法发动第二张【愚者】及其他言灵法术。修正区域判定，补充覆盖“设置→自动准备→发动→再次设置”的测试。
- [ ] 规则书新增：无法回到手卡的卡牌受到“加入手卡”类效果时，回到其初始位置（例如从灰烬区选择阵法卡时，该阵法卡回到副卡组）。在规则内核实现回退目标解析，并同步更新规则书文本。
- [ ] 规则书新增：生命值上限可被效果增加或减少，上限为 40，下限为 1。实现上限/下限钳制，区分一次性上限变更和持续修正，明确来源离场是否恢复；不能统一恢复所有上限变更，明确临时生命与生命上限互不干扰。
- [ ] 规则书新增：支付生命值不属于伤害，实质为直接扣除生命值；以生命值作为费用支付的替代同理。同步支付类卡牌（【血契】系列、【七星·星移】）的伤害免疫、受伤触发、恢复上限等判定测试。

## 2. 新增响应询问模式切换

- [ ] 对局中新增“全时点 / 自动时点 / 忽略时点”三种响应询问模式切换，明确显示当前模式。此处“时点切换”指响应询问策略，不是选择或跳转回合阶段。
- [ ] 全时点：在规则允许给予本方响应优先权的每个时点询问，允许玩家响应或主动放弃；即使当前没有可发动卡，也保留本次放弃入口。不能创建规则未授予的优先权或响应机会。
- [ ] 自动时点：由权威规则内核判断当前是否存在合法响应；有可用响应时询问，无合法响应时自动放弃本方优先权。
- [ ] 忽略时点：自动放弃本方可选响应优先权，持续至玩家切换模式；不能跳过必须处理的效果、强制选择、结算或对方响应机会。切换模式立即作用于尚未提交放弃的当前询问。
- [ ] 模式仅控制本方询问/自动放弃，不展示对方手牌、隐藏响应或对方模式；单机、联机遵守同一合法动作校验。回放按记录的实际响应/放弃命令重现，不用观看者当前模式重新决策。
- [ ] 模式按钮不得遮挡手牌、解析区、阵法区和确认/放弃按钮；常用分辨率、缩放与响应托盘收起/展开后均可使用。
- [ ] 验收：覆盖三种模式之间的双向切换、双方均可响应、连续连锁、无合法响应、当前响应窗口切换忽略、强制选择不被忽略、联机隐私和回放确定性。
