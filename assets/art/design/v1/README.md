## 重新导出

需要 Python 3、Pillow 和 NumPy，以及项目 `assets/fonts/NotoSansCJKsc-Regular.otf`。在项目根目录依次运行：

```text
python assets/art/design/v1/build_ui.py
python assets/art/design/v1/build_previews.py
python assets/art/design/v1/finalize_art.py
```

脚本仅绘制原创 UI、组合示例和更新清单，不重新生成或改动卡牌插画。插画变更需使用图像生成工具；本轮使用 OpenAI 内置 imagegen。字体许可沿用 `assets/fonts` 内原有文件，未引入外部图库素材。
