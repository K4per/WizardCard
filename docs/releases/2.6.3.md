# Alpha v2.6.3

程序、规则和卡池统一为 **2.6.3**。正式卡池90张，72条风味文本保留原文；内容哈希 `61f9b39a65c02fff`。规则修订12，状态v8，复盘6，摘要4；中央传输协议5。正式联机严格要求相同版本与内容。

## 对局与规则

- 猜拳决定先手，双方确认后公开，平局重来。猜拳不扣对局时间；随后双方抽5张，再私下选择初始阵法，同时公开设置。
- 解析法术、盖伏和预载言灵明确选择阵法及环位。表侧设置与反转检查等级，盖伏不限；混沌之环与硫磺在表侧设置、反转时检查限制。
- 更新五条进阶配方。强化法阵可使用当前己方控制的任意盖伏法术；材料选择与取消由权威内核校验。
- 修订恩格亚斯之星、十字阵法、阿克乌姆之弧、安卡十字、硫磺、步履维艰、捕获打击及相关法术行为。
- 有效环位相加后，土石喷发每份独立向下减半并独立到期。连锁、派生效果和持续法术回位完成后，控制者选择超容量卡送灰。
- 固定2点基础荷载上限；严格超过才过载，伤害为新增超额×2。持续计时在控制者结束阶段触发处理后递减。维持专注仅支付魔素。
- 持续法术回合法解析环位，无位送灰；普通结算法术在施法区待结束清理。抽牌与单纯查看不洗切；明确置顶、置底及两项占卜效果保留规定顺序。

## 界面、指南与联机

- 缩窄左侧详情，纵向扩大场地，中央分两条施法区；手牌独立置底，可收起。高容量施法区支持箭头和滚轮翻页，每张卡均可访问。
- 响应默认“可用时点”，支持持续忽略、全时点、是／否询问、收起看场地及取消返回。强制专注与超容量决策不能忽略。
- 专注先确认询问，再点击高亮卡，明确选择维持或放弃；无关同步保留合法选择，失效选择阻止提交。
- 主菜单“巫师指南”统一提供五章教程、版本化完整规则书和90张卡图鉴，全部离线可用。章节均开放，本机保存完成标记，重试从章首开始。
- 教程真实执行猜拳、免费初始设置、付费升级、火球7点火伤、火花3点火伤、护盾将飞弹4点力场降至0，并保留飞弹后续盖伏销毁选择。
- 正常房间入口默认连接 `aq.rainplay.cn:23513`，内置公开信任证书，保留域名、有效期及证书校验。高级配置默认折叠，可恢复正式服配置。

## 升级与交付

守护法阵、幻象法阵退池，其他稳定ID与卡图对应不变。旧卡组先备份，再自动移除这两张卡；备份失败不改原档，不自动补卡，构筑不合法时不能开局。继续使用原有用户数据目录。

Windows便携包和Linux服务端包均在 `RELEASE.json` 记录同一个锁定源码提交及树；外部SHA-256和包内文件清单用于复核。最终验收、部署备份和归档证据见 `docs/reports/2.6.3.md`。
