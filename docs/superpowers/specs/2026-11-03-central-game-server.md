# 中心游戏服务器设计

已确认，2026-11-03。

## 目标

C++17 单进程 Linux 权威服务器承载 20 个双人房间、40 名远端玩家，接入现有 Godot 4.7.2 前端，替换产品中的局域网房主/访客模式。保留规则内核、查看者投影、确定性复盘以及 P2P 协议 4 的诊断回归。首版无账户、排位、自动匹配、观战、分片和重启续局。

## 权威与接口

新增中央协议 5：TLS -> Hello（协议/规则/机制/卡池/hash）-> Welcome（256-bit 随机 token、每次进程启动的新 instance ID）-> CreateRoom/JoinRoom -> RoomJoined。创建/加入之前客户端必须保留 Welcome；RoomJoined 丢失后用旧 token 和 instance 恢复。凭据仅存客户端内存。Resume 不允许替换仍在线的连接；旧实例拒绝恢复。

RoomConnectOptions 包含 endpoint(hostname, port=24443, optional trusted CA path)、entry(Create/Join)、roomCode。RoomSession 的 connect 接收上述选项和卡组；Application 只注入 RoomFactory，不依赖套接字。房主权限、稳定房间席位及开局分配的 PlayerId 分离。状态包括 Waiting/Playing/Completed/Aborted，reconnecting、technicalPaused、storageBlocked 为独立标志。所有行为和查看者身份来自已绑定连接，外部 actor/viewer 不可越权。

每个席位独立递增命令序号和最近 256 条回复。相同序号同内容重试返回原回复；不同内容拒绝；太旧请求要求重新同步，不能再执行。投影和事件不得泄露私牌、种子或对手动作查询。完整复盘仅在正常规则终局后发送，64 KiB 分块、总长最多 32 MiB，客户端校验后原子保存。中止和诊断仅管理端保留。

## 房间生命周期

服务端生成房间码和随机种子，验证双方卡组，房主可配置自己是否先手以及自动阶段；变更卡组或配置重置准备；双方准备后开局。沿用现有规则计时/自动推进。活动对局正常退出投降；断线或强退冻结双方规则时钟，失联判定后 60 秒内可恢复，任意席位到期则 Aborted，无胜者。等待房访客离开/超时释放席位，房主离开/超时关闭房间。双方断线分别计时；存储暂停不延长重连和寿命期限。

默认容量 20 驻留房间/40 席位/64 连接，8 字符随机房间码；握手 10 秒、心跳 2 秒、失联 6 秒、重连 60 秒；等待空闲 15 分钟、对局上限 4 小时、终局保留最多 10 分钟且双方离开即回收。正常完成者可在终局保留期内凭内存 token 重取复盘。超预算或寿命中止，不伪造规则 result。

## 并发与存储

默认一条网络 I/O 线程、两条规则线程，每房间串行 executor，以及一条独立、有界的持久化线程。网络帧上限 1 MiB、接收 2 MiB、发送 4 MiB；每连接请求 20/s、突发 40；等待处理最多 64 条且 2 MiB；全局持久化积压 32 MiB。慢读者按失联流程处理，不阻塞其他房间。规则执行继续使用现有预算和原子拒绝语义。

MatchSession 提供只读的命令、事件增量游标；日志含初始配置、所有新增权威命令/事件（含规则超时和自动动作）、持久化 revision 和生命周期。Accepted 代表权威已执行，不承诺崩溃时已落盘。异步追加失败后 storageBlocked 冻结房间，保留精确待写内容和已知偏移，重试前截断半次写入。恢复只清除 storageBlocked，不解除 technicalPaused。正常终局只生成一次格式 5 复盘。累计命令、事件和封装预算 32 MiB（预留 1 MiB 封装），权威命令最多 100000；增量核算而非反复生成全量 JSON。服务器重启仅识别完整持久化前缀，将未完成记录标记中止，不重建可游玩状态，旧 token 作废。历史数据不自动删除。

## TLS、产品和部署

服务端 standalone Asio 1.36.0（231cb29bab30f82712fcd54faaea42424cc6e710）+ OpenSSL >=3，仅可选服务器/native probe 引入；纯内核/普通 Godot 构建不依赖 OpenSSL。客户端 Godot 内置 TLS，异步 DNS，保留原始主机名用于证书验证，禁止 unsafe TLS。生产默认正式 assets/release-v260（rules/cards 2.6.0、mechanics 10、hash 41eac6fc263abd5e）。历史测试继续显式使用历史卡池。

房间页提供服务器、房间码、创建/加入、选卡组、房主配置和准备；显示自己席位、连接状态和中止原因。对局页正确处理重连倒计时、技术暂停、存储暂停、中止退出和正常终局复盘等待。网络 pump 不受页面、动画和设置暂停影响。

交付 Linux 二进制、容器/Compose、用户服务配置和部署指南；证书只读，数据持久化，非 root。健康/就绪仅回环 24444，游戏 TLS 24443。SIGTERM 停止接入、中止未完成房间、限时刷盘。结构化日志不得包含 token、私牌或种子。用户授权推送至远程 dev，并通过 ssh WizardGameServer 尝试部署；无 sudo 时使用用户目录与用户服务。没有可信公网证书时使用显式信任 CA，不能关闭 TLS 验证。
