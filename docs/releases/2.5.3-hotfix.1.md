# WizardCard Alpha v2.5.3-hotfix.1

程序与规则版本推进至 `2.5.3-hotfix.1`，卡池保持 `2.5.3`，机制修订为 `7`。

手牌二速言灵只能在持有者自己的回合响应。对方回合的合法动作列表不再提供这类手牌动作，权威规则内核也会拒绝直接提交的命令。场上已准备及满足盖伏等待期限的法术仍按各自速度、来源与卡面条件响应。

修复炽热射线在第一束伤害后卡住的问题。第二、第三束会正常显示双方玩家的目标选项，选择后继续造成伤害并完成结算。

Windows x64 便携包为 `dist/WizardCard-2.5.3-hotfix.1-windows-x64.zip`，校验值见同目录 `.sha256` 文件。完整验证记录见[hotfix交付报告](../reports/2.5.3-hotfix.1.md)。
