# Alpha v2.5.1 界面与反馈验收

## 显示与字号

设置提供 1280×720、1600×900、1440×900、1600×1000、1920×1080、2560×1440；已有自定义尺寸继续显示。窗口可自由缩放，最小为 1280×720，回归覆盖上述六种尺寸。

全局字号为 90%、100%、110%、120%，默认 100%。点击“保存并应用”后即时同步，存入现有 `settings.json`；旧设置缺少 `fontScale` 时按 100% 读取。主菜单、页面控件、富文本、动态控件、提示、弹出菜单与自绘卡面均使用该比例。自绘卡面按原卡框区域限制行高并省略溢出文字；详情保留完整可滚动规则文本。

所有业务页面共享灰蓝灰盒控件：背景、面板、输入框、按钮、焦点、禁用态与间距沿用构筑和对局的层级。主菜单保留既有 Banner、背景与入口美术：Logo 位于左侧，右侧纵向排列七个同级主按钮，依次为“单人游戏、多人游戏、卡组构筑、卡牌图鉴、对局复盘、游戏设置、退出游戏”。图鉴和复盘使用与其他入口相同的主按钮；键盘 Tab、方向键及手柄焦点按此顺序循环。开关与滑块保留已有图标，卡牌插图与战场区域不变更。

菜单验收同时检查 Logo 与按钮列无交叠、七个按钮全部可达且不溢出、按钮文字完整，以及图鉴、复盘和设置入口实际导航。

## 构筑问题与交付范围

| 问题 | 期望行为与验收 |
|---|---|
| 加入、移出后难以确认结果 | 立即更新主／副卡组数量，显示卡名、操作和剩余数量，使用 240 ms 卡牌高亮反馈；连续操作不排队 |
| 达到同名或张数上限时原因不清晰 | 显示上限原因，保留当前牌组；不可用卡池条目保持禁用遮罩 |
| 保存结果不明显 | 显示保存成功、仍需补齐或具体错误；保存按钮给出短暂反馈 |
| 详情编号缺失 | 图鉴／构筑／对局详情显示 `number`，牌组仍以稳定 `id` 持久化 |
| 拖放结束后残留高亮 | 成功、取消、窗口失焦和页面释放均清理拖放状态 |
| 大字号遮挡长规则文本 | 详情和检查弹窗正文可滚动，关键按钮仍在可视范围 |
| 小窗口筛选器下方卡池卡牌过小 | 卡池依据剩余高度使用一至三行，分页同步调整；已构筑主／副卡组仍保留固定分区 |

牌组列表提供“导入”，编辑页提供“导出”。公开交换格式为 `wizardcard-deck` version 1：保存名称、主／副卡组分区、稳定 `id` 和数量，不包含运行时状态。导入先完成格式、版本、重复条目和完整牌组合法性校验；缺卡、类型不符、张数或同名上限错误均显示原因，失败时保留当前草稿。合法牌组导出后再导入保持内容一致。本地可修补草稿继续使用 format 3，两种格式各自维护版本。

## 动效清单与优先级

| 优先级 | 状态变化 | 实现与验收 |
|---|---|---|
| P0 | 页面切换、按钮确认 | 160 ms 淡入、短暂按压；页面立即接收输入 |
| P0 | 构筑加入／移出／数量变化、拖放完成 | 即时结果文字、240 ms 卡牌高亮反馈；状态先更新，再播放装饰 |
| P0 | 保存成功／失败、上限拒绝 | 220 ms 控件色彩反馈，结果文字持续可见 |
| P1 | 手牌进入／离开、卡牌离场 | 新位置边框、旧位置轮廓在 240 ms 内淡出，不移动真实卡牌或命中区域 |
| P1 | 设置／盖伏／反转、准备施法／发动、连锁处理 | 可见投影的区域或状态发生变化时，240 ms 暖色边框反馈；使用投影数据，不在前端重新判定规则 |
| P1 | 伤害／治疗 | 对应玩家区域以红／绿边框淡出，生命值立即使用最新投影 |
| P2 | 复杂飞行动画、粒子与镜头移动 | 本版不引入；上述短暂反馈覆盖关键变化，避免拖慢复盘和快速操作 |

所有动效服从“精简动画”。该模式下文字、数量、生命和位置即时更新。连续新投影替换旧反馈；隐私遮罩立即清除旧轮廓；页面释放终止所属 Tween。动效不延迟指令、不修改规则状态、不移动输入命中区域，也不延迟复盘步进。

## 回归入口

- `godot/tests/frontend_smoke.gd`：主流程、战场、构筑、设置、复盘及六种窗口尺寸（1280×720、1600×900、1440×900、1600×1000、1920×1080、2560×1440）；七个主按钮的布局、文字、焦点与导航。
- `godot/tests/typography_smoke.gd`：六种窗口尺寸 × 四档字号；反复切换防止字号累乘；继承、显式、富文本、提示与动态控件；主菜单文字和关键操作按钮边界。加 `--capture-output <目录>` 时输出 1280×720、120% 字号的六个页面截图。
- `godot/tests/feedback_smoke.gd`：新状态立即生效、快速投影替换、生命变化、离场、隐私清理、精简动画和命中区域稳定性。
- `godot/tests/deck_exchange_smoke.gd`：公开格式往返、未知版本、重复条目、缺卡、分区与数量错误，以及失败时保留当前牌组。
- `godot/tests/network_frontend_smoke.gd`：真实页面入口连续三轮创建／加入／开始对局／退出房间。
- 原生 `tests/application.cpp`：字号四档、旧设置兼容、无效字段拒绝与重启持久化。

运行前先构建当前原生桥接并执行 Godot 导入，所有使用扩展的进程串行运行。`--assets` 指向当前正式 `assets`，`--user-data` 使用隔离目录；不能以旧版卡池夹具的通过结果代替本版验收。截图需以有渲染的 Godot 运行后检查，headless 只用于行为与边界断言。
