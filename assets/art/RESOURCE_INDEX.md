# 美术资源索引与重绘状态

后续前端统一以 **1920×1080（16:9）** 为主设计基准。当前主界面参考为 C 版月夜城堡、金边深蓝按钮和青色宝石。本批七份独立素材及两份装配预览均以 1920×1080 PNG 交付；透明组件使用全尺寸画布，实际区域由 manifest 指定。

## 当前推荐入口

- [2.0 新卡插图与图鉴](godot-2d-v2/card-illustrations-v2-20261011/README.md)：32 张新卡，16 张复用旧图、16 张 ImageGen 透明新图；包含提示词、映射、数值文字与 Godot 实际截图。
- [主界面重绘包](godot-2d-v2/main-menu-1080p-v1/README.md)：背景、透明 LOGO、按钮五态、1080p 装配预览。
- [原始卡框接入预览](godot-2d-v2/card-frame-integration-v1/README.md)：五种 ImageGen 完整框体、匿名卡背、图鉴与场地的 Godot 实际截图。
- [共享 UI 与设置重绘包](godot-2d-v2/ui-components-1080p-v1/README.md)：六份 1080p 透明组件、原稿、提示词、切片清单，以及设置和图鉴的实际预览。
- [开源中文字体](fonts/noto-sans-cjk-sc/README.md)：Noto Sans CJK SC，主菜单 Black 900、标题与操作 Bold 700、正文 Regular 400；附原始字体、OFL 许可、来源哈希与实际截图。
- [构筑与编辑重绘包](godot-2d-v2/deck-builder-1080p-v1/README.md)：七份 1080p C 版资产、原稿与提示词，保留 v1.1 三栏并支持 40 张主卡组 / 10 张副卡组，附 Godot 实际截图。
- [全目录盘点](ART_INVENTORY.json)：逐文件位置、格式、PNG 尺寸和占用空间。盘点含源稿与副本，不能把文件数量当作独立设计数量。
- [新版全前端需求](../../docs/art-resource-requirements-godot-2d.md)：后续重绘的范围依据。

上述 1150 个文件为本次新菜单素材以外的美术文件盘点，包含 PNG、SVG、PXO 等，不包含 `.import`、JSON 或文档。`godot/art` 是运行时镜像，由 `godot/art/assets.json` 与同步脚本管理，不作为额外源稿重复计数。

## 重绘顺序

| 阶段 | 状态 | 交付范围 |
|---|---|---|
| 主界面 | 已接入 Godot，待视觉验收 | 新背景、透明 LOGO、五态按钮、1080p 预览 |
| 卡牌与构筑 | 原始 AI 卡框与构筑编辑已接入 | 三栏、40/10 主副卡组、卡池筛选与原生草稿保存；新版对局规则迁移另行推进 |

| 联机与专用弹窗 | 专用流程待实现 | 复用新共用材质；独立页面与异常状态按业务进度接入 |
| 动态演出 | 待制作 | 火焰、宝石及战斗特效，另行定义帧序列 |

旧目录原位保留。新菜单、五种完整 AI 卡框及匿名卡背已加入 `godot/art` 运行清单，由同步脚本管理；简化卡框不再参与运行资产选择。卡框保留原始 1086×1448 透明 PNG，前端与实际截图仍以 1920×1080 为设计基准。PNG 栅格原稿可以再次编辑，但 AI 原稿不等同于交付 Pixelorama 手工分层源稿。
