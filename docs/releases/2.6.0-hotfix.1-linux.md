# WizardCard 2.6.0-hotfix.1 Linux

支持 Ubuntu 24.04+ 和 Arch Linux x86_64 的 X11、原生 Wayland 桌面。
Godot 4.7.2 使用 GL Compatibility，需要支持 OpenGL 3.3 的图形驱动。
正式内容为 92 张卡、mechanicsRevision 10；规则、网络协议和复盘契约与
相同版本的 Windows 客户端一致。

## 安装与启动

```sh
sha256sum -c WizardCard-2.6.0-hotfix.1-linux-x86_64.tar.gz.sha256
tar -xzf WizardCard-2.6.0-hotfix.1-linux-x86_64.tar.gz
cd WizardCard-2.6.0-hotfix.1-linux-x86_64
./run.sh
# 也可以显式选择显示后端：
./run.sh --display-driver x11
./run.sh --display-driver wayland
```

保留同目录的 `WizardCard.x86_64`、`WizardCard.pck`、`bin/` 和 `assets/`。
启动器可从任意工作目录调用，原生内容会从可执行文件同级目录定位。
若解压工具丢失权限，运行 `chmod +x run.sh WizardCard.x86_64 bin/*.so`；
官方 tar.gz 已保留这些权限。

默认用户数据为 `$XDG_DATA_HOME/WizardCard`，未设置或为空时使用
`$HOME/.local/share/WizardCard`，包含 `settings.json`、`decks.json` 和
`replays/`。使用独立测试目录：

```sh
./run.sh -- --user-data /tmp/wizardcard-test-data
```

## 系统依赖与故障排查

包使用系统 glibc、libstdc++、libgcc、libm，不捆绑标准 C++ 运行库。
桌面需要 X11 或 Wayland/xkbcommon、fontconfig、Mesa 或厂商 OpenGL 驱动；
音频使用 PulseAudio/PipeWire 或 ALSA。中文字体已随前端发布。
Ubuntu 可安装：

```sh
sudo apt install libstdc++6 libgcc-s1 libgl1 libglx-mesa0 libegl1 \
  libx11-6 libxcursor1 libxinerama1 libxi6 libxrandr2 libxrender1 \
  libwayland-client0 libwayland-cursor0 libwayland-egl1 libxkbcommon0 \
  libfontconfig1 libasound2t64 libpulse0
```

Arch 需要 `glibc gcc-libs mesa libglvnd libx11 libxcursor libxinerama libxi
libxrandr libxrender wayland libxkbcommon fontconfig alsa-lib libpulse`，并安装
与 GPU 匹配的驱动。保持滚动发行版完整更新。

- 装载失败：运行 `ldd bin/libwizard_godot_bridge.release.so` 和
  `ldd WizardCard.x86_64`，补齐 `not found` 库。不要用随机下载的 `.so` 覆盖系统库。
- Wayland 启动失败：确认会话存在 `WAYLAND_DISPLAY`、有效 `XDG_RUNTIME_DIR`；
  用 `--display-driver wayland` 获取明确诊断。可在 XWayland 中选择 `x11`。
- Hyprland 等平铺 compositor 控制窗口状态和尺寸；Godot 4.7.2 无法在 compositor
  拒绝取消最大化时切换窗口模式。需要调整尺寸或切换全屏时，先将游戏窗口设为浮动，
  或使用 compositor 的全屏快捷键。
- 图形异常：更新驱动，或使用 `LIBGL_ALWAYS_SOFTWARE=1 ./run.sh` 诊断；
  软件渲染仅用于定位性能/驱动问题。
- 保存失败：检查数据目录权限或使用 `--user-data` 指向可写目录。
- 无声音：检查系统输出设备与游戏总音量/音效音量，确认音频服务可用。

## 构建和验收

发行包只在 Ubuntu 24.04 x86_64 构建，使用官方
`4.7.2.stable.official.ed1daf0bf` 编辑器和匹配导出模板；Arch 同 commit
版本允许本地开发与实机验收，不能替代发行构建基线。

```sh
cmake --preset linux-godot-release -DGODOT_BIN=/absolute/path/to/official-godot
cmake --build --preset linux-godot-release --parallel 4
python3 tools/package_godot.py --platform linux \
  --godot /absolute/path/to/official-godot --build build/linux-godot-release
```

打包器验证内容、复盘、ELF 依赖、执行权限和解压后的隔离启动；生成
`RELEASE.json`、`SHA256.json`、tar.gz 与 `.tar.gz.sha256`。Linux GDExtension
强制 `GODOTCPP_USE_STATIC_CPP=OFF`，以避免桌面进程中的 C++ locale 冲突。
CI 运行 headless、Xvfb/X11 与 Weston/Wayland 检查并上传证据。
真实桌面上的音频听感、中文输入法、多屏缩放和物理局域网连接仍需实机验收。
