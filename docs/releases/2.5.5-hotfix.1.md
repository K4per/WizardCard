# WizardCard Alpha v2.5.5-hotfix.1

程序版本推进至 `2.5.5-hotfix.1`，规则与卡池保持 `2.5.5`，机制修订保持 `9`。

修复七星启曜耀分支发动后的选择错误。内部的“受到7点光耀伤害”和“获得7点独立荷载”选项现在使用独立合法动作标签，前端投影不会再把它们查询为卡牌，因此选择后可以继续结算。

法术反制的卡面费用改为动态 `X`。其实际支付规则保持不变：X 等于被连锁法术的实际设置费用与实际发动费用之和，图鉴、Godot 卡面、桥接投影与卡包字段保持同步。

Windows x64 便携包为 `dist/WizardCard-2.5.5-hotfix.1-windows-x64.zip`，校验值见同目录 `.sha256` 文件。完整验证记录见[hotfix交付报告](../reports/2.5.5-hotfix.1.md)。
