# WizardCard Alpha v2.5.1

Alpha v2.5.1 把规则、卡池和程序版本统一推进到 `2.5.1`，并把 `mechanicsRevision` 推进到 `4`。正式卡池从 62 张扩充至 78 张，接入完整 16 张味契系列；新增拆卸符文、配对检索、伤害上限、费用代付、回收、洗牌和反制等原生规则效果。旧版复盘因版本与卡池内容哈希不匹配而明确拒绝播放。网络协议保持版本 3，复盘记录结构保持格式 4。

卡牌源数据仍由 `assets/catalog.json` 与其列出的单卡定义维护；`assets/cards.json` 与图鉴为生成产物。开发者卡牌包格式保持 `1`，玩家牌组交换格式为 `wizardcard-deck` 版本 `1`，本地存档格式独立保留现有版本。

玩家牌组导入／导出、分辨率和全局字号设置、v1.0.0 构图的主菜单入口、灰盒控件统一、构筑与对局即时反馈、回放检查点缓存，以及多人本地建房／加入流程修复纳入本版。主菜单继续使用当前 Logo 和 Banner，七个主入口依次为单人、多人、构筑、图鉴、复盘、设置、退出。

便携包通过 Godot 4.7.2 固定导出模板与匹配的 Release 原生桥接构建。包内不包含测试夹具、设计稿、开发工具和本地玩家数据；`SHA256.json` 记录包内文件校验值，zip 的 SHA-256 写入旁置 `.sha256` 文件。构建细节与验收数据见[交付报告](../reports/2.5.1.md)。
