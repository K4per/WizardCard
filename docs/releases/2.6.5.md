# Alpha v2.6.5

## 战场与操作

- 缩小场地，展开的手牌完整位于窗口内，悬停时抬起单张手牌供查看。
- 设置或盖伏法术时点击高亮环位，直接选定阵法和环位。支付配方时从手牌或场地上的高亮卡牌选择材料。
- 统一场上法术卡的尺寸，并将「暂无合法操作」移出操作列表。

## 复盘与存档

- 终局结算显示胜负与原因。玩家可命名保存回放或放弃保存，联网双方的选择各自生效。
- 回放支持 1×、2×、4× 自动播放和进度条跳转，可在同一步切换查看者。
- 两端桌面便携包默认把卡组与回放保存在游戏根目录的 `saves/`。旧数据会复制到新位置，同名文件与旧目录原件保留。2.6.4-hotfix.1 使用同一正式卡池的格式 6 回放可以继续播放。

## 兼容与交付

程序及发行包版本为 `2.6.5`。规则及卡池版本沿用 `2.6.4-hotfix.1`，机制修订为 13，正式卡池 90 张，内容哈希 `54d3d845557007f7`。中央协议 5、状态 v8、复盘格式 6、摘要格式 4 均沿用。中央房间仍要求双方客户端和服务器的程序、规则、卡池、协议及内容元数据严格匹配。

发行包包括 Windows x64 客户端 ZIP、Linux x86_64 桌面客户端 tar.gz，以及 Linux x86_64 中央服务器 tar.gz。三个归档从同一发行提交构建，每个归档附带 SHA-256 校验值。
