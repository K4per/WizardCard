# 对战场地 V7 最后调整

2026-10-11。Godot 场地预览页完成卡图边距、资源显示和场地字体调整，复用现有美术与 Noto Sans CJK 字体。

- 解析区按刻纹内缘设置安全区域：左右留6.5%的区域宽度，上下留12%的区域高度，并在标签下保留卡图间距。卡图、空环位落点与阵法浏览数量共用该区域，左侧阵法卡不再压住边框。
- 生命、魔素、荷载图标的显示容器扩大到32–46像素，HUD增高到96像素。数值采用真实 Bold 700 字重、20–26像素字号；较长数值根据单元宽度缩小字号，荷载进度条继续显示在下方。
- 场地标签采用 Bold 700、深色描边和明亮文字。阶段24像素并居中，解析区／施法区22像素，牌库／副卡组／灰烬区18像素；阵法滚轮提示单独放在右侧，避开区域标题。

修改：`godot/ui/field_canvas.gd`。原有手牌扇形、选中伸出、右键收回、整副手牌收起／展开、详情与强制效果选择继续保留。

Godot 4.7.2 实际 OpenGL 渲染检查通过719项，覆盖1280×720、1600×1000、1920×1080及30张官方卡牌。最终日志无错误，已查看1080p和720p实际截图，`git diff --check`通过。

报告：`build/battle-v7-render-report.json`。日志：`build/battle-v7-render.log`。截图：`build/battle-v7-captures/field-1920x1080.png`、`field-1280x720.png`、`battle-hand-collapsed-1920x1080.png`。
