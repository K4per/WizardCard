## 一、游戏定位与核心体验

巫师牌是一种以法术对抗为核心的**集换式卡牌游戏（TCG）**。第一阶段只实现双人对战，多人规则在双人机制稳定后另行设计。

对局中的玩家称为巫师、法师或术士。玩家通过设置阵法、解析法术、预置言灵和附加符文，击碎对手的生命之核，或迫使对手魔力过载。

游戏的核心体验是：**提前准备威胁，在有限的魔力容量中安排施法顺序，并判断对手的准备是否值得干预。**

- **魔素结晶**限制玩家能够支付多少费用。
- **魔力荷载**限制玩家能够同时保留多少法术与预置手段。
- **解析时间**让威胁提前公开，为对手留下应对机会。
- **阵法和符文**决定卡组的施法结构及调整方式。

首版应优先验证这些机制能否形成互动，再扩展角色、流派和卡池。

## 二、玩家要素与胜负条件

### 2.1 生命之核 Life Core

生命之核是玩家的生命值。

- 初始生命为 **20**，生命上限为 **30**（Alpha v0.5 暂定节奏测试值）。
- 受到伤害时减少生命；恢复生命时不能超过当前生命上限。
- 生命上限若下降，当前生命超过新上限的部分立即失去。
- 第一版中阵法不改变生命上限；特殊阵法或角色可以在后续版本引入此类效果。

### 2.2 魔素结晶 Mana Crystal

魔素结晶用于支付卡牌及规则操作的费用，简称**魔素**。

- 初始魔素为 **1**，魔素储存上限为 **12**。
- 魔素可以跨回合保留。
- 玩家在自己的准备阶段获得基础收入 **1**，再获得各阵法提供的魔素收入。
- 设置新的阵法不会立即获得它的每回合收入。
- 超过储存上限的魔素直接失去，不转化为荷载。
- 未明确写出的费用为0；费用不能低于0，也不能在魔素不足时部分支付。

费用和荷载是两个独立数值。行动卡及符文支付魔素时，不会自动产生等量荷载；是否产生荷载由规则或卡面明确规定。

### 2.3 魔力荷载与荷载上限

为避免术语混淆，统一使用以下名称：

| 名称 | 含义 |
| --- | --- |
| 当前荷载 Magic Load | 玩家当前承担的所有法术荷载与临时荷载之和 |
| 荷载上限 Magic Capacity | 玩家能够承受的最大荷载，主要由阵法提供 |
| 法术荷载 | 绑定于某张法术，在该法术离场或规则明确释放时移除 |
| 临时荷载 | 独立于卡牌存在的负担，按指定期限或效果移除 |

荷载不通过每回合刷新自动清空。

```text
当前荷载 = 所有仍存在的法术荷载 + 所有尚未移除的临时荷载
荷载上限 = 基础阵法提供的容量 + 扩展阵法提供的容量 + 其他修正
```

当前荷载等于荷载上限时仍然安全；**严格超过**上限时才构成过载。

玩家主动执行操作时，必须满足：支付费用及执行该操作所必需的自身荷载变化后，不会超过荷载上限。不能先超载，再以稍后释放法术为理由宣告操作。

对手的效果、已经开始的结算或强制规则处理则可能使玩家超过上限。过载是否导致败北，按下文的状态检查时点判断。

### 2.4 败北与平局

在状态检查时，出现任一情况的玩家败北：

1. 生命之核为0或更低。
2. 当前荷载超过荷载上限。
3. 必须抽牌时牌库为空，产生了抽牌失败。

一方败北时另一方获胜；双方在同一次状态检查中满足败北条件时，判为平局。玩家可以随时投降并立即败北；双方同时投降时平局。无法终止的强制效果循环判为平局，可选择停止的循环不得宣告无限执行。

**状态检查时点：** 每次支付与宣告完成后、每项效果结算并完成直接离场清理后，以及每个阶段结束时。检查发生在下一项效果开始前。

一项效果内部的各句按顺序处理，不能在句子之间插入操作。例如“销毁阵法及其承载法术”必须先完成全部关联离场与荷载移除，再检查过载，不能只降低容量就提前判负。

## 三、构筑与开局

### 3.1 构筑规则（暂定）

- 主牌库固定 **30张**。
- 同名卡最多 **3张**，不同稀有度采用相同限制。
- 每名玩家额外配置一张基础阵法与一个角色，二者不计入主牌库。
- 主牌库可以包含阵法卡；从牌库设置的阵法称为扩展阵法。
- 同名基础阵法不占用主牌库的同名卡限额。额外设置的同名阵法也不具有基础阵法的保护。
- 首个原型固定使用基础阵法“均衡”和无技能角色。
- 稀有度用于收藏及表现，不直接规定卡牌强弱或额外构筑权限。

### 3.2 开局流程

1. 双方公开角色与基础阵法，将基础阵法设置到解析区。
2. 双方设置生命20、魔素1、当前荷载0，并由基础阵法计算荷载上限。
3. 洗牌，各抽5张起始手牌。
4. 随机决定先后手，先手开始第一个回合。

先手的第一个抽卡阶段跳过基础抽1张；后手正常抽牌。双方第一次准备阶段均正常获得魔素。其他先后手补偿暂不加入，待实测后调整。

### 3.3 手牌与牌库

- 手牌只对拥有者可见，牌库内容及顺序不公开。
- 默认手牌上限为 **8张**，只在自己的结束阶段检查。
- 超过上限时，玩家自行选择多余手牌弃入灰烬区。
- 必须抽多张牌时逐张抽取；若中途牌库为空，记录抽牌失败，并在该项效果结束后的状态检查中判负。
- 抽牌失败不会因为同项效果后续将卡洗回牌库而被撤销。

## 四、对局场地

除手牌与牌库外，每名玩家有五个基本区域。

| 区域 | 容量与用途 | 默认可见性 |
| --- | --- | --- |
| 行动区 | 展示正在处理的行动；不设置每回合使用次数上限 | 公开 |
| 解析区 | 五个阵法槽位；阵法按阵体占位，法术附属于具体阵法的环位 | 公开 |
| 咒文区 | 三个槽位，用于预置言灵法术 | 公开 |
| 施法区 | 无固定槽位上限；容纳待施放法术与持续生效法术 | 公开 |
| 灰烬区 | 放置弃置、销毁或结算离场的卡牌 | 公开，可查看 |

解析区的五个槽位**只限制阵法占位**。阵法承载多少法术，由各自环位决定，不再额外占用这五个槽位。

行动结算后进入灰烬区。行动区仅展示当前正在处理的行动，不限制每回合使用次数；每次使用仍须支付费用并满足时机、目标和荷载要求。

施法区中的法术必须标记为“待施放”或“持续生效”，两者不能混淆。持续生效法术不会在每个施法阶段重新释放。

符文不单独占用区域槽位，而是附属于宿主卡。

## 五、回合阶段

一个回合指**某一名玩家完整执行自己的五个阶段**，不是双方各行动一次。下文所称“下个自己的回合”均采用这一含义。

### 5.1 抽卡阶段

回合玩家基础抽1张牌，先手首回合例外。处理抽卡阶段触发效果，并进行状态检查。

### 5.2 准备阶段

依次处理：

1. 获得基础魔素收入与当前已设置阵法的收入，超过储存上限的部分失去。
2. 推进解析进度。默认在上个自己的回合开始解析的法术，此时解析完成。
3. 处理“在你的准备阶段”触发的效果。
4. 完成状态检查。

新设置阵法必须等到下个自己的准备阶段才提供收入。解析完成只改变法术状态，不自动准备施法，也不移除荷载。

### 5.3 主要阶段

回合玩家可以按自己选择的顺序：

- 使用行动卡，不限次数，仍受费用、目标和荷载限制。
- 设置、拆除或替换扩展阵法，受阵法操作额度限制。
- 开始解析法术。
- 为已解析完成的法术准备施法。
- 在咒文区预置言灵法术。
- 附加或主动拆除符文。
- 放弃自己正在准备或维持的法术。

主要阶段中，准备施法会开启言灵响应窗口。非回合玩家只有在明确的响应或强制处理时才能操作，不能自由使用手牌。

### 5.4 施法阶段

回合玩家将自己施法区的“待施放”法术按自选顺序逐张结算。

- 每张法术完整处理、清理并检查胜负后，再结算下一张。
- 进入施法阶段后，不能新增准备施法、开始解析、附加符文或使用普通行动卡。
- 所有待施放法术都必须在本阶段处理完毕，不能留到下一回合。
- 若对局已经结束，剩余待施放法术不再处理。

### 5.5 结束阶段

依次处理：

1. 处理“回合结束时”触发效果。
2. 移除在本结束阶段到期的临时荷载与限时修正。
3. 自己持续生效法术的持续计数减1；计数归零的法术离场。
4. 弃置超过手牌上限的手牌。
5. 清除本回合行动统计、阵法操作、符文主动拆除及施法准备被取消等标记。
6. 完成状态检查，将回合交给对手。

每项触发效果及直接离场清理完成后仍需检查胜负，不能把全部结束阶段效果合并成一次检查。

## 六、卡牌基本要素

对局使用四类卡牌：**行动、法术、阵法、符文**。法术再分为解析法术与言灵法术。

所有卡牌至少具有以下信息：

- 卡牌名、卡牌类型、卡牌附图。
- 稀有度：普通、罕见、稀有、史诗、传说，对应白、绿、青、紫、金。
- 魔素花费：阵法设置费用固定为0；其他卡牌明确标注。
- 规则效果：说明目标、时点、数值、限制与持续期限。
- 背景说明：故事、风味文本或梗，不具有规则效力。

法术额外标注位阶、准备方式与持续类型；阵法额外标注阵体、荷载容量、魔素收入、环位与最高位阶。

卡牌的专有效果可以修改明确指出的普通规则，但不能用含糊文案推翻核心限制。无法支付费用、目标不合法或主动操作会导致过载时，不得宣告操作。

## 七、行动卡 Action

行动代表巫师进行的即时操作，例如抽牌、整理资源或施加干扰。

### 7.1 使用流程

1. 检查使用时机、目标、魔素及卡面要求。
2. 支付费用与额外成本；若标注自身荷载负担，同时登记该负担。
3. 将卡放入行动区，记录本回合已使用行动数量（仅用于统计，不作为限制）。
4. 结算效果，然后将卡放入灰烬区。

行动卡费用不会自动转化为荷载。自身临时荷载作为使用负担时，即使行动效果失效，也保留至指定期限。普通行动卡只能在自己的主要阶段使用。

### 7.2 示例：奥术回想

```text
普通 · 行动
奥术回想
魔素费用：2
使用负担：获得1点临时荷载，在本回合结束阶段移除。
效果：抽两张牌。
背景说明：尚未熄灭的记忆，也能成为下一道咒文。
```

此牌使用时就登记1点临时荷载，以避免“先抽到解压牌，再承担负担”的顺序漏洞。该负担不随行动卡进入灰烬区而立即消失。

## 八、阵法卡 Pentacle

阵法是解析法术的施法基础，也是卡组构筑的基础。

### 8.1 阵法属性

| 属性 | 规则含义 |
| --- | --- |
| 阵体 | 该阵法占用的解析区槽位数量 |
| 荷载容量 | 对玩家荷载上限的贡献，可与其他阵法叠加 |
| 每回合魔素聚集 | 在拥有者准备阶段提供的魔素收入 |
| 最大环位 | 同时承载的解析中或解析完成法术数量 |
| 最大位阶 | 可以在该阵法上开始解析的最高法术位阶 |

最高位阶只在开始解析时检查。后续位阶修正不自动销毁已承载法术，除非效果另有说明。

### 8.2 基础阵法

基础阵法在开局直接设置，正常占用阵体槽位，提供容量、收入和环位。

- 基础阵法不能被销毁、主动拆除、替换或使其整体失效。
- 可以正常附加和拆除符文。
- 其承载的法术仍可被取消、放弃或销毁。
- 第一版不设计直接降低基础阵法属性的效果。

这项保护用于确保玩家始终保有最低施法能力。扩展阵法承担资源增长与遭受破坏的风险。

### 8.3 设置与调整扩展阵法

每个自己的回合有 **一次阵法操作额度**，可以选择一种操作：

| 操作 | 费用与处理 |
| --- | --- |
| 设置 | 从手牌设置一张扩展阵法，费用0，必须有足够空槽 |
| 拆除 | 支付2魔素，销毁自己一张扩展阵法及其承载法术、附属符文 |
| 替换 | 支付2魔素，拆除一张自己的扩展阵法，再将手牌的一张阵法设置到腾出的空间 |

替换视为一次整体操作；新阵法可以使用原有空槽和拆除腾出的槽位。操作结束后的总阵体不能超过5，当前荷载不能超过新上限。

玩家应在宣告前验证替换的最终结果。不能先支付2魔素、拆除旧阵法，再发现新阵法无法放下。

阵法从设置成功时立即提供容量与环位，但不会补发魔素收入。替换本身不获得新阵法的收入。

### 8.4 阵法离场与关联清理

扩展阵法被销毁或离场时：

1. 其承载的解析中及解析完成法术全部离场。
2. 这些法术的全部绑定荷载移除，附属符文进入灰烬区。
3. 阵法自身的附属符文进入灰烬区。
4. 重新计算玩家容量与收入，再检查状态。

已经成功移入施法区的法术不再占用原阵法环位，也不再随原阵法被销毁。其符文与绑定荷载仍跟随法术。

若强制效果减少阵法环位，拥有者选择多余的承载法术放入灰烬区，并移除相应荷载。主动拆除提供环位的符文前，必须先自行放弃多余法术，不能留下超出环位的场面。

### 8.5 示例：均衡

```text
普通 · 阵法
均衡
附图：由上三角和下三角构成的六芒星。
设置费用：0
阵体：2
荷载容量：8
每回合魔素聚集：1
最大环位：3
最大位阶：2
背景说明：秩序不偏向任何一边。
```

作为基础阵法时，“均衡”与玩家基础收入合计每回合提供2魔素。基础阵法以外再设置的“均衡”正常作为可破坏的扩展阵法。

## 九、解析法术 Analytic Spell

解析法术通过有序符号、魔法阵和逻辑结构改变现实。它们必须依托阵法准备，威胁从开始解析时公开。

### 9.1 费用与状态

解析法术采用双段费用：

```text
COST：解析费用 / 施法费用
```

例如“3 / 1”表示开始解析时支付3魔素，准备施法时再支付1魔素。两次支付的实际费用分别产生等量绑定荷载；若卡牌明确规定不同荷载，则按卡面处理。

解析法术有四种场上状态：

1. 解析中：占用阵法环位，尚不能准备施法。
2. 解析完成：仍占用环位，可以等待或准备施法。
3. 待施放：位于施法区，等待本回合施法阶段。
4. 持续生效：已成功释放，留在施法区维持效果。

### 9.2 开始解析

自己的主要阶段中：

1. 选择自己的一个阵法，检查最高位阶与空闲环位。
2. 支付解析费用，增加等量法术荷载。
3. 将法术附于所选阵法，记录开始解析的自己的回合编号。

默认在**下个自己的准备阶段**完成解析。例如在自己的第2回合开始解析，在自己的第3回合准备阶段完成。

已解析完成的法术可以继续等待，但会持续占用环位与荷载。解析中的法术可以附加符文，但除非卡面明确允许，不能提前施法。

### 9.3 准备施法

自己的主要阶段中：

1. 选择自己解析完成的法术，选择法术目标及模式，并验证合法性。
2. 支付施法费用，登记本次费用记录，增加等量绑定荷载。
3. 宣告“准备施法”，开启言灵响应窗口。此时法术暂留在原阵法上，并继续占用环位。
4. 若准备未被取消且法术仍存在，将其移入施法区，标记为待施放，并释放原环位。

不能在准备施法后继续为这张法术附加符文。目标与模式在宣告时确定，结算时不能自行更换。

### 9.4 准备被取消

若取消了准备施法：

- 法术留在原阵法上，恢复为解析完成状态。
- 已支付的施法魔素不退还。
- 移除本次尝试新增的施法荷载，保留原解析荷载。
- 本回合不能再为同一张法术准备施法；下个自己的回合可以重试。
- 如果法术或源阵法已经被其他效果销毁，按离场清理处理，不再恢复或重复移除荷载。

“取消准备”与“销毁法术”是不同效果，卡面必须明确区分。

### 9.5 施法结算与目标失效

在施法阶段，逐张处理待施放法术：

1. 检查目标是否仍合法。
2. 全部必需目标均无效时，法术失效并离场；费用不退还，荷载正常移除。
3. 有合法目标或不需要目标时，处理对应效果。多目标法术只对仍合法的目标处理，不重新选择目标。
4. 处理成功释放的附加效果，再根据持续类型决定是否离场。

一个合法法术造成的伤害被减至0，仍算成功释放；因全部目标失效而未执行的法术不算成功释放。

### 9.6 持续类型

| 类型 | 规则 |
| --- | --- |
| 瞬时 | 结算一次及其成功释放附加效果后离场 |
| 持续N | 成功释放后留在施法区，持续计数设为N；自己的每个结束阶段减1，归零离场 |

“持续2”包含释放的当前回合：本回合结束由2减为1，下个自己的结束阶段减为0并离场。首版法术不支持无限期持续；某个效果若仅持续到特定时点，直接在效果文本中写明。

持续法术的绑定荷载一直保留到离场。不能把“成功释放”理解成自动清空荷载。持续法术之后的周期效果不是再次释放，不重复支付施法费用，也不重复触发成功释放奖励。

### 9.7 放弃与离场

自己的主要阶段可以主动放弃自己解析区或施法区中的法术，也可以撤销自己的预置言灵。放弃不退费用，卡牌及附属符文进入灰烬区，并移除全部绑定荷载。

玩家不能在对手回合临时放弃法术来躲避过载，除非某张卡明确提供这种响应。

法术被销毁、被弃置、返回手牌或洗回牌库时，都视为离开法术存在区域：移除绑定荷载，附属符文进入灰烬区。它以后再次被使用时，是一次新的法术准备，不继承原进度与费用记录。

### 9.8 示例：火球术

```text
稀有 · 解析法术
火球术 Fireball | RANK 2
COST：3 / 1
解析时间：1个自己的回合
持续类型：瞬时
目标：对手玩家
效果：造成6点火焰伤害。
背景说明：经典之选。
```

**荷载示例：** 开始解析时占用3荷载；准备施法时再占用1，合计4；成功结算或销毁后移除全部4点。若原本当前荷载为8、上限为8，则不能为火球术支付追加费用，因为宣告后会达到9荷载。

## 十、言灵法术 Power Word Spell

言灵以短句、吟唱与仪式条件驱动法术。第一版将其定位为**公开预置、条件响应**，与解析法术的主动威胁形成区别。

公开预置意味着对手能够看到反制，判断是否绕开、试探或先行移除。隐藏咒文及长期吟唱机制暂不加入。

### 10.1 预置流程

自己的主要阶段中：

1. 检查咒文区空槽、费用及荷载上限。
2. 支付卡面费用，增加等量绑定荷载。
3. 将卡正面放入咒文区，成为预置言灵。

言灵位阶用于分类及后续构筑机制，第一版不受阵法最高位阶限制。设置完成即可在之后符合条件的窗口响应，但不能响应已经发生的事件。

预置言灵不会自动消失，不按回合重复缴费，也不会因为未触发而释放荷载。其拥有者可以在自己的主要阶段撤销它。

### 10.2 响应流程

当发生卡面指定的响应事件时，拥有者可以选择触发符合条件的预置言灵。是否触发默认是可选的，不因条件满足而强制消耗。

1. 选择一张言灵，验证触发条件与目标。
2. 将它移入施法区，立即结算；不等待自己的施法阶段。
3. 处理效果后，卡牌进入灰烬区并释放绑定荷载。

第一版的言灵全部为瞬时法术，不支持在对手回合开始长期持续。没有言灵可以直接从手牌响应。

### 10.3 示例：银光锐语

```text
罕见 · 言灵法术
银光锐语 Silvery Barbs | RANK 1
COST：4
持续类型：瞬时
响应条件：对手为一张解析法术宣告准备施法时。
效果：取消那次准备施法。
背景说明：“嘿，听我说！”
```

对手按“准备被取消”规则保留解析进度，失去本次施法费用，释放本次追加荷载。

## 十一、符文卡 Seal

符文不能单独留在场上，必须附加到一个合法宿主。它们通过固定类型的效果修正法术或阵法，为构筑提供调整空间。

### 11.1 附加限制

- 普通符文只能在自己的主要阶段附加。
- 第一版只允许附加到自己的阵法或解析区中的解析法术。
- 首版每个宿主（法术或阵法）最多附加一张符文；按位阶扩展符文数量留待后续。
- 待施放、持续生效及预置言灵法术暂不接受新增符文。
- 附加符文必须支付卡面费用，但不自动产生荷载。
- 每回合可以附加不限数量的符文，受费用、宿主数量及其他合法性限制。

一张符文若有“阵法附加效果”和“法术附加效果”，只执行与当前宿主匹配的那一项，不同时获得两项效果。

### 11.2 拆除与离场

- 自己的主要阶段每回合可以主动拆除一张自己的附属符文，费用不退还。
- 拆除后立即失去其尚在提供的持续修正；已经完成的抽牌、伤害或魔素获得不回滚。
- 主动拆除不得使最终状态超过荷载上限或环位限制。
- 宿主离场时，其符文一同进入灰烬区；这种关联清理不占用主动拆除额度。
- 宿主在解析区与施法区之间移动时，符文跟随移动。
- 符文不能从一个宿主免费转移到另一个宿主。

若对手的效果强制移除符文，则先完成关联状态调整，再检查是否过载。

### 11.3 改写范围

第一版优先支持伤害、费用、解析时间、环位和成功释放后的奖励等明确修正，不支持任意删除或替换整段规则文本。

符文不能依靠模糊文本绕过“解析完成”“目标合法”“不能主动超载”等限制；需要例外时，卡牌必须明确写出，并单独测试。

### 11.4 示例：奥术圆环

```text
普通 · 符文
奥术圆环 The Ring
COST：1
阵法附加效果：该阵法最大环位+1。
法术附加效果：宿主成功释放后，获得等于本次准备施法实际支付费用的魔素。
背景说明：闭合的圆，会把尚未散去的力量带回起点。
```

法术附加效果只返还**本次成功准备的施法段费用**，不返还解析费用、符文费用或过去被取消尝试的费用。返还受魔素储存上限限制，不移除荷载。

对于火球术，通常返还1魔素，而不是3或4魔素。法术准备被取消、被销毁或因全部目标失效而失效时，不返还。

## 十二、效果结算、响应与规则术语

### 12.1 第一版响应窗口

第一版只在**解析法术宣告准备施法后、成功移入施法区前**提供主动言灵响应窗口。普通行动、阵法设置和符文附加不开放即时反制窗口。

每个窗口按以下流程处理：

1. 回合玩家先决定是否触发一张条件符合的预置言灵。
2. 完整结算该言灵、清理并检查胜负。
3. 如果原操作仍存在且未被取消，非回合玩家再决定是否触发一张条件符合的预置言灵。
4. 完整结算、清理并检查胜负，然后继续原操作。

每方在同一个窗口最多触发一张言灵。条件在实际选择时重新检查；前一个响应已经取消准备时，窗口直接关闭，后一个尚未使用的言灵保留。

言灵响应的过程中不再打开新的响应窗口，首版没有“反制另一个反制”的多层链。不得在对手选择言灵后，临时从手牌补放自己的应对牌。

### 12.2 被动触发与连续结算

“在你的准备阶段”“成功释放后”等被动效果，与主动言灵响应不同。

- 因同一个事件触发的效果，先列出该事件结束时已产生的触发项。
- 回合玩家选择自己触发项的结算顺序，随后非回合玩家选择自己的顺序。
- 逐项处理，每项结束后清理并检查状态。
- 某项效果又产生新触发时，将新项追加到本次等待队列末尾，不插入正在处理的效果。
- 已经进入队列的触发项，不因来源卡之后离场而自动取消；需要来源或目标继续存在的效果，应在文本中明确，并在结算时重新验证。
- 如果对局已结束，不再处理等待队列。

成功释放的宿主符文奖励属于宿主结算的附加部分，应在宿主离场前处理，不会因宿主即将离场而丢失。持续法术的后续效果则按卡面时点进入触发队列。

### 12.3 常用术语

| 术语 | 定义 |
| --- | --- |
| 支付 | 执行费用或额外成本；已经支付的资源默认不退还 |
| 设置 | 将阵法放入解析区并开始提供属性 |
| 解析 | 将解析法术附于阵法，等待其准备进度完成 |
| 准备施法 | 为解析完成的法术支付施法费用并宣告移入施法区 |
| 成功释放 | 法术结算时有合法目标或无需目标，按规则执行效果 |
| 取消准备 | 阻止本次移入施法区，不等于销毁法术 |
| 销毁 | 令场上卡牌进入灰烬区，并执行关联清理 |
| 弃置 | 令手牌进入灰烬区，不视为销毁场上卡牌 |
| 放弃 / 撤销 | 拥有者主动令自己的场上法术离场，不退费用 |
| 空闲阵法 | 不承载任何解析中或解析完成法术的阵法；附有符文不影响空闲判定 |
| 额外成本 | 在宣告时一并支付的条件，如弃置一张手牌 |

原文的“空白阵法”统一改为“空闲阵法”，避免被误解为没有符文、没有文字或失去效果的阵法。

## 十四、角色

角色描述巫师的形象与能力，开局公开，位于五大区域之外。

第一版使用统一无技能角色：

```text
角色：见习巫师
初始生命：20
生命上限：30
初始魔素：1
魔素储存上限：12
基础魔素收入：1
角色能力：无
```

后续角色可以有一项被动能力或一项每回合限次的主动能力。角色能力必须注明费用、时点、次数与荷载；不能以“特殊能力”为由省略规则。

第一阶段不让角色同时大幅改变生命、抽牌、收入和容量，以免掩盖基础机制的问题。角色也不由稀有度直接决定强弱。

## 十五、规则演算示例

### 15.1 开局火球术

双方使用基础“均衡”。以某玩家自己的回合为例：

| 时点 | 魔素 | 当前荷载 / 上限 | 处理 |
| --- | --- | --- | --- |
| 开局 | 1 | 0 / 8 | 基础阵法已经设置 |
| 第1回合准备阶段后 | 3 | 0 / 8 | 基础收入1加均衡收入1 |
| 第1回合开始解析火球术 | 0 | 3 / 8 | 支付解析费用3 |
| 第2回合准备阶段后 | 2 | 3 / 8 | 获得2魔素，火球术解析完成 |
| 第2回合宣告准备施法 | 1 | 4 / 8 | 支付施法费用1，进入响应窗口 |
| 第2回合施法阶段结算后 | 1 | 0 / 8 | 对手受6伤害，火球术及其4荷载离场 |

### 15.2 银光锐语取消准备

沿用上例。对手已经预置银光锐语并承担4荷载。

1. 火球术使用者支付1魔素，当前荷载从3变为4。
2. 对手触发银光锐语，取消这次准备。
3. 火球术使用者仍有1魔素，追加的1荷载移除，当前荷载回到3。
4. 火球术留在阵法上，保持解析完成，本回合不能再次准备。
5. 银光锐语离场，其拥有者的4荷载移除。

取消方付出一张言灵及4魔素；被取消方失去1魔素和本回合的施法机会，但没有失去火球术本身。

### 15.3 破坏扩展阵法导致过载

玩家有基础均衡和扩展均衡，总上限16，当前荷载10。扩展均衡空闲，全部法术荷载位于其他区域或基础阵法上。

结构瓦解成功销毁扩展均衡后，没有关联法术需要释放荷载，因此上限降至8而当前荷载仍为10。完成关联清理后的状态检查判定该玩家过载败北。

如果被销毁阵法承载法术，一般销毁效果应先移除这些法术的荷载，再计算最终是否超载；但结构瓦解本身不能以非空闲阵法为目标。

### 15.4 临时荷载与行动离场

玩家当前荷载为7、上限8，可以使用奥术回想，支付2魔素并登记1临时荷载，达到8。抽牌后行动卡进入灰烬区，荷载仍为8；直到自己的结束阶段才移除这1点负担。

若使用前已经有8荷载，则不能使用奥术回想。相反，清心没有自身荷载负担，只要有足够魔素并满足使用时机就可以使用。

## 十六、原型开发范围与测试目标

### 16.1 第一版实现范围

优先实现：

- 双人轮流回合与五个阶段。
- 固定基础阵法与无技能角色。
- 四类卡牌、资源支付、解析进度和绑定荷载。
- 公开言灵与单层响应窗口。
- 每宿主一张符文。
- 生命败北、过载败北及抽牌失败。
- 完整操作记录，方便复盘费用、荷载与触发顺序。

卡池先扩展至约12—16种功能清晰的牌，再组成固定的30张测试卡组；本稿示例牌仅覆盖机制，不视为完整首发套牌。

以下内容暂不加入：隐藏咒文、多层反制链、多个符文叠加、复杂角色能力、无限持续法术、牌库外生成大量卡牌，以及多人对局。

### 16.2 开发中必须可追踪的数据

法术至少需要记录：拥有者、当前区域和状态、源阵法、开始解析回合、目标、模式、绑定荷载、本次施法支付费用、持续计数与附属符文。

临时荷载至少需要记录：承担者、来源、剩余数值和到期时点。它不能只用一张已进入灰烬区的行动卡来代表。

规则处理应明确区分“支付”“效果结算”“关联清理”“状态检查”，避免阵法容量下降与法术荷载释放之间出现中途判负。

### 16.3 必须验证的交互

| 交互 | 应有结果 |
| --- | --- |
| 支付施法段后恰好达到上限 | 允许准备 |
| 支付施法段后超过上限 | 禁止宣告，不扣费 |
| 准备被取消 | 不退魔素，释放本次追加荷载，保留解析进度 |
| 阵法与其法术一同销毁 | 完成全部清理后再检查过载 |
| 源阵法在法术成功移入施法区后被销毁 | 不影响该法术 |
| 持续法术成功释放 | 保留绑定荷载直到离场 |
| 宿主法术离场 | 符文一同离场，不占主动拆除次数 |
| 火球术附加奥术圆环成功释放 | 通常获得1魔素，法术荷载正常移除 |
| 所有必需目标失效 | 法术失效，无成功释放奖励，绑定荷载移除 |
| 同一窗口两张言灵都符合条件 | 每方最多一张，按规定顺序选择并重验条件 |
| 行动卡离场但临时荷载未到期 | 临时荷载继续存在 |
| 必须抽牌而牌库为空 | 效果结束后判负 |

### 16.4 首轮对局需要记录的问题

- **节奏：**平均每名玩家经历多少个自己的回合？胜负是渐进形成还是频繁突然结束？
- **等待：**是否出现连续回合只能抽牌、等待解析，没有有效选择？
- **荷载：**玩家是否经常为容量做取舍，还是始终远离上限？
- **反制：**银光锐语是否值得占用4魔素和4荷载？是否让进攻方长期无法施法？
- **阵法：**扩展阵法是否成为每局都必须尽早抽到的唯一最优选择？
- **过载攻击：**魔力扰动和阵法破坏是否有足够的预防空间？
- **符文：**符文是否改变施法计划，还是只有少数宿主值得附加？
- **先后手：**轮换先后手与套牌使用者后，优势是否仍稳定存在？

第一轮可以先进行约20局探索测试，但不要据此宣称已完成平衡。每轮尽量只调整一组核心参数，并保留修改记录。

## 十七、后续需要斟酌的方向

以下内容是扩展议题，不影响按正文运行第一版：

1. **基础阵法选择。** 是否允许构筑时选择不同基础阵法？若允许，应提供容量、收入、环位和位阶之间的明确取舍，并避免某一种全面占优。
2. **过载互动。** 若即时行动造成过载过强，考虑将强干扰改为有预警的解析法术，或加入有限的预置减压言灵。
3. **言灵特色。** 后续是否分为短句响应与多回合吟唱？长期吟唱需要自己的进度与中断规则，不能直接套用瞬时言灵。
4. **隐蔽信息。** 是否加入盖放咒文？若加入，要补充查看、揭示、验证与数字版提示规则。
5. **更多符文。** 若开放多符文叠加，必须先定义修正顺序、同名限制和冲突处理，再扩展卡牌。
6. **角色与流派。** 在资源循环稳定后，让角色改变一个主要策略轴，而不是同时获得多项通用优势。
7. **商业与收藏。** 游戏先验证可玩性；卡包、获取方式、稀有度分布和交易机制单独形成运营设计，不与基础规则混写。
8. **多人对战。** 另行定义目标选择、响应顺序、玩家离场、资源规模和联合攻击问题，不直接沿用双人回合规则。

## 十八、相对原案的主要修改

| 原设计 | 本稿调整 | 目的 |
| --- | --- | --- |
| 荷载、载荷、荷载牌混用 | 区分当前荷载、荷载上限、法术荷载与临时荷载 | 让资源可计算、可追踪 |
| 未规定开局与收入底线 | 加入固定基础阵法、基础收入与起始资源 | 保证双方能开始施法 |
| 魔素是否积累不明确 | 允许跨回合保留，设置储存上限 | 支持分段费用与资源规划 |
| 阵法不能主动销毁 | 允许付费拆除或替换扩展阵法 | 给前期布局保留升级出口 |
| 行动区有三槽但立即清空 | 行动区仅展示正在处理的行动，不设每回合次数上限 | 行动节奏由资源与规则条件决定 |
| “下个回合后”不明确 | 下个自己的准备阶段完成解析 | 避免双方回合计数歧义 |
| “立即”同时指回合结束 | 改为瞬时与持续N | 区分结算时间和维持时间 |
| 火球术兼具伤害与阵法破坏 | 拆分为火球术与结构瓦解 | 分别测试两种攻击路线 |
| 银光锐语取消并抢先准备自己的法术 | 首版只取消准备，补齐费用与荷载收尾 | 简化跨回合时序 |
| 奥术圆环返还“对应COST” | 只返还本次成功准备的施法段实际费用 | 避免资源返还歧义 |
| 符文可广泛改写且叠加未限 | 首版每宿主一张，采用明确修正 | 控制组合与开发复杂度 |
| 角色章节只有一句描述 | 增加统一测试角色与后续能力边界 | 为后续扩展预留结构 |

这份修订稿的第一目标是让双方可以完整、无歧义地打一局；下一步应通过固定测试卡组验证准备时间、费用和荷载是否形成预期的攻防。
