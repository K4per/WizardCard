# Alpha v2.5.3-hotfix.1 交付报告

日期：2026-10-23。程序与规则版本 `2.5.3-hotfix.1`，卡池版本 `2.5.3`，机制修订 `7`。

## 变更

响应阶段从手牌发动的二速言灵现在要求发动玩家就是当前回合玩家。限制位于权威响应命令校验中，因此合法动作投影不会列出对方回合的手牌二速动作，伪造或直接提交的命令也会被拒绝。手牌持有者在自己的回合仍可照常响应；其他速度、场上已准备法术、盖伏反转及一般回合操作不受此规则影响。

炽热射线的后续目标选择使用玩家目标标记。此前合法动作投影把标记当作卡牌编号读取，抛出 `invalid map<K, T> key`，导致界面无法继续。修复后玩家目标使用独立标签并作为全局选择提供，三束射线可依次选择目标、结算伤害并结束。回归测试从合法动作列表发动和选择，覆盖实际界面调用的完整路径。
