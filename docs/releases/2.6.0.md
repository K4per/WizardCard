# Alpha v2.6.0 正式发行

日期：2026-10-31

Windows x64 修复版便携包为 `dist/WizardCard-2.6.0-windows-x64-talisman-costfix.zip`，同目录的 `.zip.sha256` 是下载校验值。包内 `RELEASE.json` 标记 `status: released`，程序、规则与卡池版本均为 `2.6.0`，机制修订为 `10`。

玩家运行时读取 `assets/release-v260/` 晋升快照：92 张卡（解析法术 39、言灵法术 21、咒符法术 12、符文 3、阵法 17），并只提供 v2.6.0 的入门预组。旧 2.5.5 资产保留在仓库中用于历史回归与迁移证据，不进入本发行包的玩家卡池。

本卡池的 49 张对应设计卡图来自 `WizardCard-Design/Alpha 现有卡池`：29 张 RGB 图已由脚本移除烘焙棋盘底，20 张 RGBA 图保留原始 alpha。逐卡源文件、处理方式和哈希记录在 `assets/art/alpha-v260/current-pool/manifest.json`；其余卡图继续沿用逐卡登记的历史资源。

主界面与卡牌图鉴已完成本版本灰盒化：主界面去除背景和按钮皮肤美术，只保留 banner、纯色布局和可访问的文字控件；图鉴去除卡框美术，只保留卡牌插画、类型色带、文字详情、搜索和筛选。后续美术迭代不改变卡池版本。

咒符卡面按 `castCost` 显示施法费用；“法术反制”保留动态 `X` 费用。

发行验证：原生 loader 加载 92 definitions；40 张主卡与 10 张阵法副卡 smoke 通过；同一内容的 replay 重演通过；咒符费用回归检查覆盖 12 张卡；Godot 4.7.2 前端 smoke 加载 92 张正式卡并完成图鉴资源检查。
