# v1.5 2.5D 对局场景

2026-10-07。规则／卡池保持 1.0.0；程序保持 1.5.0-dev。承接已有 Godot 本地客户端，替换对局呈现与输入层，不增加联网或新规则。

## 当前交付

正式入口仍为 `godot/scenes/wizard_client.tscn`，对局实例化 `godot/scenes/match/match_view.tscn`。牌桌、区域、三维卡牌、前景手牌和 HUD 均有独立场景。摄像机固定斜俯视，Compatibility 渲染，不需要额外建模软件或第三方模型。

按用户追加的 MD 参考调整为全画面叠加布局：3D 牌桌取景不受侧栏开关影响；详情在左侧悬浮，悬停／点选更新；右侧连锁与可收起日志、下方手牌与操作栏均在对局场景内。悬停只展示信息，选择、费用、目标和确认仍交给 C++。这里的 UI 是 Godot 场景内的 Control 覆盖层，不是投射到牌桌表面的文字。

双方保留五区及牌库。解析区五个槽位按阵体计数，宿主与符文偏移叠放，关联与候选高亮；拥挤区域可从“区域浏览”逐卡选择。对手手牌只使用数量生成匿名牌背，隐藏实例不绑定卡名和定义。手牌支持扇形排列、放大、排序、滚轮和跨二维／三维拖放。

对局场景在普通刷新及设置暂停期间保持实例。三维卡牌按会话代次、查看者、实例 ID 管理，区域移动复用节点；换手遮挡时销毁旧卡牌、手牌和效果。继续使用原有换手、三档 AI、固定教学、暂停、离开确认、终局、重开和保存恢复。

## 表现接口

`LocalSession::accepted` 返回新增 `cues` 数组，来自已有 `MatchPresentation::observe(before, after, reducedMotion)`。每条包含字符串 `sequence/source/host/target`、数值 `kind/player/from/to/amount/duration` 与展示文字 `text`。不携带卡牌定义、完整状态或原生指针；隐藏卡文字统一为“隐藏卡牌”。既有 `sounds`、`generation`、`revision`、保存结果不变。

Godot 按提交代次／修订消费一次提示；快照读取与保存重试不产生新提示。移动、抽牌、公开翻面、解析／释放／响应／反制和资源飘字不提交规则。后续提交结束旧过渡；换手清空，暂停冻结，精简模式保留短反馈。AI 和空阶段推进等待短表现窗口，手动操作保持可用。

卡面合成纹理按公开定义缓存，无逐卡实时 SubViewport。3D 牌桌使用一个独立 SubViewport，以便 UI 保持清晰且射线坐标可验证；场上射线与卡牌局部平面／边界求交，不使用物理模拟决定玩法。

## 验证与证据

- 最终 Release 完整回归：**210/210 通过**，317.31 秒（原有 208 项，新增桥接表现契约和场景输入检查）；Debug 导入、边界、页面、场景输入及旧 Alpha 复盘 **5/5 通过**。Godot 检查现在将 `SCRIPT ERROR` / `ERROR:` 判为失败，最终全部运行日志未发现此类错误；修复了重挂场景及尺寸未就绪时的镜头取景调用。见 [Release 日志](evidence/v1.5-25d/release-final-tests.log)、[Debug 日志](evidence/v1.5-25d/debug-final-tests.log)和[33 项场景输入断言](evidence/v1.5-25d/scene-input-tests.log)。
- 场景输入检查通过 Godot `Input.parse_input_event` 注入鼠标／键盘事件，覆盖三维命中、浮层阻挡、二维手牌拖到三维区域、实际 drop 信号进入桥接、无效落点、过期请求、右键／Esc 和失焦通知取消、暂停保留、换手清理、隐藏卡以及退出释放。它不是真人外设操作记录。最终 GPU 截图进程 stderr 为空，源码工程导入无运行错误。
- 换手、三档 AI 和教学经正式对局控制完成，保存复盘逐步摘要继续与 CLI 参考一致。教学和最终确认不走绕过规则的专用接口；自动复盘测试主动结束表现时间，以测试正常命令结果而非等待动画。五份记录归档后另经 CLI 重放成功，结果与路径见[复盘校验](evidence/v1.5-25d/replay-verification.json)。
- 截图来自实际 GPU 渲染；复杂场面由普通 AI 参考复盘前 107 步构造，分别检查 1280×720、1600×1000、1920×1080。`logical-scale-150-percent` 是逻辑缩放模拟，不是 Windows 显示设置切换。`effect-layout-synthetic` 明确为合成提示排版样本，不作为真实伤害证据。
