# Alpha v1.0 补充卡与五方向构筑

2026-10-07。用户授权补充卡池，卡名借鉴D&D法术命名，以下效果为WizardCard原创规则适配。卡池由24扩至30种，六张原始透明像素插画通过内置imagegen生成，提示词与来源见assets/art/alpha-release/manifest.json。

| 卡牌 | 类型 / 学派 / 速度 | 费用 | 效果与定位 |
|---|---|---|---|
| 寒霜射线 | 解析1阶 / 塑能 / 1速 | 解析1，施法1 | 3寒冷伤害，低费用非火焰输出 |
| 闪电束 | 解析2阶 / 塑能 / 1速 | 解析3，施法2 | 8闪电伤害，应对火焰抗性 |
| 护盾术 | 言灵1阶 / 防护 / 2速 | 设置2 | 6临时生命；预置后响应或主动释放 |
| 次级复原 | 解析1阶 / 防护 / 1速 | 解析2，施法1 | 立即解析，清除自身全部临时荷载，治疗2；不清独立或绑定 |
| 虚假生命 | 解析1阶 / 死灵 / 1速 | 解析2，施法1 | 立即解析，8临时生命，代价为2独立荷载 |
| 奥术复苏 | 行动 | 使用0 | 获得3魔素（上限12），2临时荷载本回合结束清除 |

两张立即解析法术仍支付解析费用并占环位，需要另行释放。临时生命取较高值不叠加，没有自然到期。临时荷载清理可处理来源关联临时荷载，但不处理独立荷载；独立荷载仍是虚假生命的长期代价。

| 方向 / 示例预设 | 核心路线 | 主要代价与应对 |
|---|---|---|
| 塑能爆发 / 五芒星塑能 | 基础折扣→铺开射线→火球/闪电收尾 | 低容量下控制准备数量；非火伤穿过避火咒 |
| 速解 / 速解与支援 | 恩格亚斯→加速解析→魔法飞弹快速时点 | 费用转化与独立荷载制约连续释放 |
| 荷载控制 / 持续荷载与防护 | 魔力扰动→紊乱波动持续来源→反制保护节奏 | 对手清理临时荷载或销毁来源；自身反制负担 |
| 防护续航 / 防护与续航 | 护盾/抗性承受伤害→结界持续伤害 | 独立荷载不能无限续命，持续法术需要维持费用 |
| 言灵节奏 / 言灵与节奏 | 先设置→响应准备/伤害→检索行动与资源转化 | 共用3后场位、响应费用和速度约束 |

每套主卡组30张，同名最多3张；基础阵法另选，全部可用于玩家或AI。总共九套预设（原四套与上述五套）。自动完整跑局验证可玩流程与稳定性，不作为胜率平衡结论。

发行规则：初始/最大生命40/40；基础容量2，均衡总容量10、五芒星7。施法阶段可选择本阶段不再释放，待释放卡、已支付费用和荷载保留，下个自己的施法阶段可再释放。所有言灵可以单独设置；零阶另外提供设置并释放，三个后场位已满时可以选择立即释放而不长期占位。后场拖放默认只设置，拖到施法区可选择零阶设置并释放。
