# Alpha-v1.0 分阶段开发计划

更新日期：2026-10-07。目标交付：Windows x64 本地游戏 Alpha-v1.0。

正式Alpha版为程序 `1.0.0-alpha`、规则 `1.0.0`、卡池 `1.0.0`；Alpha v0.5保留为历史基线。本计划替代旧 v0.6 路线；阶段状态依据实际交付记录填写。

## 1. 已确定的交付要求

- 主菜单恰好五项：单人测试对战（换手）、单人AI对战、卡组构筑、游戏设置、退出游戏。教学入口放在单人AI对战子页面。
- 回合仍为抽卡、准备、主要、施法、结束五阶段。各阶段有明确处理和响应时点；空阶段可自动通过，强制决策必须完成。
- 使用轻量多层连锁，允许符合条件的预置言灵、就绪快速解析法术与埋伏卡参与；按速度判断，手牌禁止加入，四速后禁止响应。
- 玩家自带基础荷载容量2；均衡开局总容量10，生命之五芒星阵法容量5、开局总容量7。
- 主卡组30张、同名最多3张；选择一张具有基础资格的阵法，角色暂用无技能角色。基础阵法不计入主卡组。
- 构筑器管理卡组内容与份数；新卡由用户设计，不在构筑器内修改卡牌定义。
- 本地AI提供简单、普通、困难三档，使用代表性、具有教学意义的预设卡组；另有固定引导教学局。
- 卡池至少支持五种核心策略与操作路线不同的合法卡组。具体方向、卡数、卡牌由后续卡池规划确定。
- 音效保留来源与许可；首批采用用户提供的AIGC音效，用户指定CC0；美术采用AIGC，制作与同步接入按用户指示分批进行。

## 3. 产品实现边界

### 菜单和设置

共用总音量、音效音量、窗口模式、分辨率、空阶段自动通过，并持久化。主要阶段始终由玩家明确结束。局内另有继续、保存复盘、投降和返回主菜单；打开设置暂停AI提交动作，保留当前规则决策及换手遮挡。返回主菜单前确认结束当前局并保存记录。保存复盘不等于提供中断对局存档恢复。

换手开局分别选择双方卡组。AI开局选择玩家卡组、对手预设及难度。终局提供重开和返回主菜单。教学作为AI子页面入口，不增加第六个主菜单选项。

### 构筑和持久化

基础阵法仅在卡组编辑页面设置，对战配置只展示并使用所选卡组的值。卡组保存稳定ID、名称、基础阵法ID及卡牌ID/份数。可保存未完成草稿，仅合法卡组可进入对战。组合查询包含卡名部分匹配、类型、稀有度、费用、位阶和设计标签；解析/施法费用分别展示。用户数据和发布资源分开，内容升级后重新校验卡组并显示具体问题，保存失败保留编辑内容。

### AI、教学和资源

AI仅用自身手牌、公开信息及合法动作。简单采用基础优先级，普通采用资源与收益评分，困难增加组合顺序与反制风险评估；模块无窗口可运行。覆盖响应、释放顺序、触发排序、弃置、荷载选择等决策，计算有预算，对局切换后拒绝过期结果。

教学采用固定卡组、种子和脚本化AI，经正常核心教授资源、解析、准备、释放及连锁；错误操作有提示并可重开。最终每种卡组方向配代表性AI预设与打法说明。

音效由界面动作和已提交的规则事件映射，音量设置实际生效；资源缺失不会改变规则。美术分批更新资源清单，沿用缺图回退，保留来源及许可记录。阶段1不生成新美术或替换现有插画。

## 4. 验收与版本

- 规则：执行全部设计回归场景，保留当前费用、荷载、状态清理和胜负回归；新增命令编码往返和过期决策拒绝检查。
- 界面：点击/拖放共用规则提交，连锁换手遮挡、设置暂停、构筑草稿与查询、不同窗口比例、教学完整流程。
- 运行：固定种子AI完整对局、Windows客户端验证、Linux核心CI、跨平台同版本复盘。
- 发布：独立目录检查字体、卡牌、UI、音效和许可；本次20局真人门槛经用户明确取消，按自动验收交付；自动跑局不作为真人平衡结论。
- 当前基线记录的45项测试属于Alpha v0.5；阶段1文档交付不将其重新记为本轮运行结果。Alpha-v1.0仅在功能与交付验收满足后升级程序和发行标签。

运行规则版本已升级 `1.0.0`，复盘格式2。程序、规则、卡池及内容哈希独立记录，旧版不兼容复盘明确拒绝读取。

暂不加入联网、收藏获取系统、卡牌定义编辑器、角色技能、多符文叠加和完整游戏王式速度/时点体系。
