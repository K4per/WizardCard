# 巫师牌：声音资源需求清单

更新日期：2026-10-05。开发基线：程序 `0.9.2-dev` / 规则 `0.3.1` / 卡池 `0.2.1`。

目标：为当前可玩的主菜单、构筑、本地双人、AI对局与教学补齐声音反馈。本文保留完整需求，首批P0已按用户提供的资源接入，状态见第9节。

## 1. 当前情况

- 已有卡牌选择、独立详情与操作条、拖放、最终确认、阶段推进、多层连锁、专注、卡组编辑、设置、AI和教学流程。
- `assets/audio/` 已有用户提供的17个AIGC MP3，许可按用户确认记录为CC0；来源、校验值及技术信息见[资源清单](../assets/audio/manifest.json)。旧confirm.wav占位调用已替换。
- 运行层支持声音缓存及音效音量；设置已有总音量与音效音量，有效音效音量由两者共同决定。
- 已有最多6个声音实例，终局优先、事件合并和同类限频；规则反馈消费过滤视角中的新增结构化事件。音乐播放和独立音乐音量留待音乐批次。
- 下表P0功能已绑定，专用平局音暂缺，使用确认音回退；P1与音乐仍待资源。实际听感与不同设备验证另记。

## 2. 优先级与声音方向

P0：完成基本操作和对局辨识；P1：补齐主要机制与当前卡池特色；P2：音乐和体验润色。按可复用功能音制作，不要求13张卡每张都有一整套独立声音。

建议声音方向：配合像素奇幻UI，采用轻纸张、石质阵纹、金属符文、短促魔法音色。界面音轻、短，结算音更有质感；长时间对局中避免尖锐高频、长混响和频繁重低音。该方向为制作建议，尚待试听确认。

## 3. P0：第一批必需声音（18条）

时长为建议范围，最终通过试听与实际操作节奏确定。

| 资产ID | 建议文件 | 触发时机 | 声音要求 / 建议时长 |
|---|---|---|---|
| SFX-01 | `ui_click.wav` | 菜单、筛选、设置等有效按钮点击 | 轻触/短木石音，0.05–0.15秒；同一次点击不叠加多条通用UI音 |
| SFX-02 | `card_select.wav` | 选中卡牌并更新详情 | 轻纸张与细小符纹声，0.1–0.25秒；详情重绘不重复播放 |
| SFX-03 | `ui_cancel.wav` | 主动取消选择、拖放或关闭操作流程 | 轻收束音，0.1–0.25秒；不同于法术被反制 |
| SFX-04 | `ui_reject.wav` | 无效落点、数量限制、实际被拒绝的操作或保存失败 | 柔和短低音，0.15–0.35秒；配可读原因，不高频连响 |
| SFX-05 | `card_place.wav` | 合法拖放选定命令但尚未确认；构筑中增减卡牌或手牌重排完成 | 纸张落位音，0.1–0.3秒；不暗示已经支付或结算 |
| SFX-06 | `confirm.wav` | 对局命令通过核心提交；需要时复用成功保存反馈 | 清楚而克制的确认音，0.15–0.35秒；兼容现有调用路径，控制放弃响应等高频命令的播放频率 |
| SFX-07 | `card_draw.wav` | 真实抽牌发生 | 纸张抽取音，0.15–0.35秒；多张抽取采用短序列或合并反馈 |
| SFX-08 | `card_discard.wav` | 弃置手牌进入灰烬区 | 纸张滑落/灰烬轻散，0.2–0.45秒；不与阵法销毁音混淆 |
| SFX-09 | `turn_ready.wav` | 操作权交给本方；本地双人需要接手 | 清晰短双音，0.3–0.6秒；AI对局仅在玩家需要行动时提示 |
| SFX-10 | `phase_change.wav` | 玩家可感知的阶段切换 | 短符纹节拍，0.15–0.35秒；自动通过空阶段时合并，避免连串提示 |
| SFX-11 | `analysis_ready.wav` | 法术由解析中变为解析完成 | 轻亮闭合音，0.35–0.7秒；不暗示法术已经释放 |
| SFX-12 | `response_open.wav` | 新响应窗口或连锁优先权需要玩家决定 | 短悬念提示，0.25–0.5秒；同一未变决策只播一次 |
| SFX-13 | `spell_release.wav` | 法术实际结算并成功执行效果 | 通用魔法释放，0.35–0.8秒；不是点击准备施法时播放 |
| SFX-14 | `damage.wav` | 玩家实际生命减少 | 清晰冲击，0.2–0.5秒；伤害量不靠音量无限放大 |
| SFX-15 | `heal.wav` | 玩家实际生命恢复 | 柔和上行音，0.4–0.8秒；区别于魔素收入 |
| SFX-16 | `victory.wav` | 玩家视角胜利 | 简短明亮结尾，1.5–3秒；本地双人以结果窗口操作者视角为准 |
| SFX-17 | `defeat.wav` | 玩家视角失败 | 简短低沉收束，1.5–3秒；不要过于刺耳或惩罚感强 |
| SFX-18 | `draw_result.wav` | 对局平局 | 中性收束，1–2秒；终局三者互斥，只播一次 |

构筑拖放、右键增减、保存、改名和删除可复用这些UI音，不要求每个页面单独制作。纯输入、滚动、鼠标经过每张卡牌默认不加音，避免密集噪声。

## 4. P1：规则机制与魔法特色（12条）

| 资产ID | 建议文件 | 触发时机 | 声音要求 / 建议时长 |
|---|---|---|---|
| SFX-19 | `formation_set.wav` | 阵法设置或替换成功 | 石纹/几何结构闭合，0.4–0.8秒 |
| SFX-20 | `analysis_start.wav` | 解析法术开始解析成功 | 能量聚入阵法，0.35–0.7秒；与完成音成对 |
| SFX-21 | `cast_prepare.wav` | 准备施法宣告已提交，费用已支付 | 蓄势短音，0.3–0.6秒；结尾保持悬而未决，区别于释放 |
| SFX-22 | `word_set.wav` | 言灵预置成功 | 短咒文/符号成形，0.3–0.6秒；不使用配音念词 |
| SFX-23 | `seal_attach.wav` | 符文附着成功 | 金属圆环与符纹锁定，0.3–0.65秒 |
| SFX-24 | `magic_dismiss.wav` | 主动拆除符文/阵法、放弃法术或结束专注 | 平静能量消散，0.25–0.6秒；区别于销毁和反制 |
| SFX-25 | `counter_cancel.wav` | 准备施法或链节实际被取消 | 银色锐音截断蓄势，0.3–0.7秒；响应宣告与反制生效分开 |
| SFX-26 | `formation_destroy.wav` | 阵法确实被销毁 | 几何碎裂与石纹崩解，0.45–0.9秒；关联卡离场不反复叠播 |
| SFX-27 | `load_increase.wav` | 临时或独立荷载增加、需要表现负担变化 | 低频绷紧/失谐，0.25–0.6秒；绑定荷载可合并到解析/准备音，避免重复 |
| SFX-28 | `load_clear.wav` | 临时荷载被清除 | 松弛消散音，0.3–0.7秒；不暗示生命缝合的独立荷载被清除 |
| SFX-29 | `mana_gain.wav` | 准备收入或符文奖励实际增加魔素 | 细小结晶聚拢，0.25–0.55秒；多个来源可合并 |
| SFX-30 | `concentration_keep.wav` | 玩家选择维持专注并成功承担荷载 | 稳定持续感的短脉冲，0.35–0.7秒；一次确认播一次，不做无休止循环 |

维持专注、取消准备、多层连锁与独立荷载均按当前规则设计。不要沿用旧版“固定持续2回合”或“只一层反制”的声音时序。

| `clarity` 心如止水 | 弃置手牌、临时荷载清除 | 水纹平复，可由清除音兼任 |

| 资产ID | 资源 | 数量 | 使用范围 | 建议规格 |

## 7. 交付规格

- 短音效：WAV、PCM 16位、48kHz，UI/通用事件优先单声道。背景音乐：OGG Vorbis、48kHz立体声；保留无损WAV母版。均附制作源或可追溯原始文件。
- 音效起音及时，首尾无意外静音、点击杂音或削波；短尾音适配连续确认。文件峰值建议不高于-1dBFS，同类音主观响度一致，具体混音以实机试听为准。
- 循环音乐附循环起止点、淡入淡出建议与完整尾部；首尾衔接无跳变。UI音、规则音与音乐相对音量单独记录，不用文件本身过响来提高重要性。
- 建议目录：`assets/audio/ui/`、`assets/audio/game/`、`assets/audio/results/`、`assets/audio/music/`。本批统一映射到 `assets/audio/*.mp3`，替换旧 confirm.wav 调用，不保留重复副本；后续目录分层时同步更新映射。
- 资产清单包含ID、文件名、用途、时长、采样率、声道、循环点、建议增益、作者/来源、许可及修改记录。采用免费资源时确认可随游戏分发并保存必要署名；“免费试听”不等于可打包分发。

## 8. 程序接入与听觉验收要求

1. **区分操作与事件。** 选中、拖放、确认、支付、响应和实际结算分别绑定；法术失效不能播放成功效果音。AI动作走相同事件音，不以模拟鼠标点击来播放玩家UI音。
2. **建立事件消费与去重。** 消费本次新增事件，不每次刷新遍历全部历史；连锁建立/逆序结算的音序跟随真实规则。已有日志事件不足以辨识效果时补充结构化信息，不靠匹配中文文本猜测卡牌声音。
3. **音效并发与优先级。** 增加有限声音实例池。终局/反制/伤害高于抽牌和普通UI音；短时间多个同类事件合并或限频，防止当前单实例互相截断，也避免无限叠加。
4. **保护私有信息。** 换手遮挡期间不得播放可推断某张私有卡身份的特色音；抽牌和查看使用通用音。隐藏AI手牌的内部决策不播放专属卡牌提示。
5. **设置与模式。** 总音量0时全部静音，音效音量0时规则/UI音静音；新增音乐后明确独立音乐音量及总音量关系。设置暂停AI时不重复决策提示；恢复、重开、教学重置和返回菜单清理旧对局音序。
6. **反馈克制。** 自动空阶段只合并提示，不连续催促；对手AI连续行动不会让UI点击音与结算音密集叠加。响应提示只在玩家确实需要决定时响。
7. **故障回退。** 缺失/损坏音频不阻断规则、复盘或客户端；离线独立安装包能找到所有音频及许可证。

首轮试听场景：菜单与音量设置、构筑快速增减、拖放/取消/确认、抽多张牌、解析完成、准备被取消并再次响应、连锁逆序结算、治疗后独立荷载增加、专注维持/放弃、清除临时荷载、AI连续行动、教学提示、胜/负/平局与重开。

验收需记录不同设备与音量下的实际听感；自动重放可以验证触发逻辑，不能代替试听。音效不驱动规则时序，也不成为完成操作的必要条件。

## 9. 建议执行顺序与状态

1. 先试听点击、确认、抽牌、反制、伤害5条，统一声音方向与响度。
2. 补齐P0共18条，接入UI与主要事件反馈，验证音量、去重和并发。
3. 补齐P1共12条，覆盖阵法、解析、符文、荷载与专注；全13张卡复用映射检查。
4. 最后制作2首循环音乐及必要特色变体，进行连续对局与教学听觉验收。

当前：用户提供的P0 Sounds.7z中17个AIGC MP3已接入，按用户确认采用CC0。原始格式为44.1kHz立体声，未转码；SFX-12使用response.mp3，SFX-18暂复用confirm.mp3。18种P0功能映射已落实，专用平局音、P1及2首音乐待后续资源；实际播放和自动验证见[接入报告](reports/audio-and-design.md)，混音听感仍需真人试听。

进度状态：待选材/制作→待试听→待接入→待实机验收→已验收。首批交付为P0，完整功能声音包为P0+P1；音乐作为独立后续交付。
