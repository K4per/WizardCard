## 测试、版本与联机

- Windows 原生及 Godot CTest **390/390**，Linux 原生及中央服 CTest **363/363**。正式客户端离线图鉴校验 90 张卡、5 个教学章节、15 个规则分区。
- 两个从最终 ZIP 解出的 Windows 客户端以 TLS 接入独立 Debian WSL2 测试服。双方在第一轮验证手势保密、切换时点与取消，平局重猜后完成两次初始阵法选择。实战执行 79 条命令，双方观察到法术结算，手动重连 2 次，意外断线 0 次。终局后两端收到逐字节相同的复盘，Windows、Linux 回放均得 `8e34753e7e6b6e28`。[联机复盘](2.6.4-hotfix.1/network-replay.json)
- 两平台分别以种子 42 完成 2579 条命令。两份文件逐字节相同，SHA-256 为 `ec3568b99908b63d62acc6e076ced38424c0e261bf0736045dc5085a4ec897ca`。交叉回放均得 `20ccdb7b1474a233`。
- 使用 2.6.4 卡池及客户端代码导出含【汲血之触】的旧牌组，新版按原 ID 导入并保存。旧正式复盘被版本校验拒绝，旧版握手收到“程序、协议、规则或卡池版本不一致”。[旧版导出的牌组](2.6.4-hotfix.1/legacy-deck.json)
