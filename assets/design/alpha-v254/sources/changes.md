# 程序修改：

1. 解析法术卡目标的选择在发动时才进行选择。

2. 响应窗口弹出时，点击灰烬区或者副卡组这种会弹出窗口的地方就会卡住，不进行连锁就无法进行操作。

3. ai【碎环术】会炸盖伏卡。

4. 回合数更改为只以己方回合计算。

5. 部分卡牌中“那之后，可以...”的描述，后续效果的适用必须保证前置效果的实行（例如【味契·烈火回炉】的回收并抽卡需要先回收，才能抽卡。若未回收则不可抽卡），且后续效果可选择是否适用。

6. 【愚者】bug：言灵法术卡设置后自动准备并发动会进入施法区，但【愚者】将其判定为仍在解析区，导致在发动【愚者】后无法发动第二张【愚者】以及其他言灵法术。

7. 规则书新增：无法回到手卡的卡牌，受到此类效果，会回到其初始位置。例如“将1张卡从己方灰烬区加入手卡”的效果选择阵法卡时，会使阵法卡回到副卡组。

8. 规则书新增：生命值上限可被效果增加或减少，但最多为40，最少为1。

9. 规则书新增：支付生命值，不属于伤害，实质为直接扣除生命值，将生命值作为费用支付的替代同理。
