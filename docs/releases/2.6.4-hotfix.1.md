# Alpha v2.6.4-hotfix.1

## 对局与操作

- 开局猜拳时可切换响应模式。尚未提交时，取消或按 Esc 都会回到本轮的三种手势。提交后等待对方，平局进入下一轮。
- 准备阶段点击高亮专注来源，再选择维持或放弃。维持按当前应付数值扣费，魔素不足或被【扰神曲】禁止维持时可放弃。
- 全时点会在没有合法响应时询问是否查看场面。可用时点只询问可发动的响应，忽略时点自动放弃可选响应。两种模式均保留强制选择。
- 连锁询问与操作确认共用可拖动窗口。拖动标题可以露出场面，取消尚未提交的操作可返回选择。

## 卡牌与费用

- 对方回合禁止从手牌发动效果，适用于三速【扰神曲】。场上牌仍按原有时点、速度、等待期限与优先权判断。
- 设置费在实际支付时锁定，包括 0。离场后重新设置时重新报价。言灵在同一动作中分别记录设置费与发动费，【奥术圆环】只引用实际设置费，【法术反制】引用两项之和。
- 【汲血之触】（020024）的基础解析时间改为 1。合法减时照常生效，设置、发动各需 2 魔素，造成 5 点暗蚀伤害并恢复己方 2 点生命。

## 战场表现

手牌平滑抬升与回落。牌库入手、手牌入场、副卡组设置阵法与场上卡进入灰烬区按所在一侧及实际位置播放移动。生命、临时生命与魔素获得显示实际变化，连锁按处理顺序标出公开效果及目标。开启“减少动态效果”仍可读取结果。

## 兼容与交付

程序、规则及卡池为 `2.6.4-hotfix.1`，机制修订 13，正式卡池 90 张，内容哈希 `54d3d845557007f7`。中央协议 5，状态 v8，复盘格式 6，摘要格式 4。房间要求双方客户端和服务器使用同版本。2.6.4 正式复盘可用原客户端播放。既有卡组沿用稳定卡牌 ID 和原玩家目录。

发行包包括 Windows x64 客户端及 Linux x86_64 中央服，附带各自的 SHA-256 校验文件。[正式卡池图鉴](../card-catalog.md)
