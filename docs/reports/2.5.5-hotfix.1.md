# Alpha v2.5.5-hotfix.1 交付报告

日期：2026-10-26。程序版本 `2.5.5-hotfix.1`，规则与卡池版本 `2.5.5`，机制修订 `9`。

## 变更

七星启曜耀分支完成第一次检索后会让玩家选择代价。此前合法动作投影把两个内部选项值当作卡牌 ID 查询，抛出 `invalid map<K, T> key`。现在这两个选项使用独立标签并标记为无卡牌来源；权威选择逻辑仍分别结算7点光耀伤害或7点独立荷载。

法术反制已按被响应法术的实际设置费用和实际发动费用支付 X，但卡面元数据显示固定费用5。新增 `dynamicCost` 字段并贯通内容解析、桥接投影、Godot 卡面、图鉴生成与卡包字段校验，统一显示为 `X`。
