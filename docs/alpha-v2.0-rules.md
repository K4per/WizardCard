# Alpha v2.0 规则规格

2026-10-10 最终规则同步，规格标识 `alpha-v2-final-2026-10-10`。依据最终报告 [原文与来源](sources/wizardcard-v1.2-final-2026-10-10.md)，以及用户本轮确认的两项解释：结束收尾后仅检查回合玩家两倍过载；持续法术保留回位例外。明确变化覆盖此前计划，报告未修改的既有约定继续保留。内容迁移草案尚待组内审定，当前正式规则/卡池仍为1.0.0；本文件是实现目标，不代表程序已全部实现。同步差异及实现缺口见 [同步记录](reports/alpha-v2.0-final-rule-sync.md)。历史规则文档描述对应历史版本。

## 1 构筑与开局

主卡组恰好40张，仅含符文、解析、言灵和咒符；副卡组恰好10张，仅含阵法。各卡组独立按同名计数，上限3张。副卡组需含至少一张1级阵法。

每名玩家开局从自己的副卡组选择一个1级阵法实体，免费移入场上，不计本回合设置额度。其余阵法留在副卡组，不洗入牌库，不经抽牌取得；后续设置从中选择实体，离场进入灰烬区。取消旧的规则性基础阵法销毁保护；卡面明确保护仍有效。初始身份仅用于卡面明确的开局效果。

双方起手5张，初始/最大生命40、初始魔素1、储存上限12、玩家基础荷载容量2、手牌上限8。先手首回合不抽牌，但正常获得收入。

本人能查看副卡组全部内容；对手仅看到剩余数量及已设置的公开阵法。网络开局确认双方选择后再启动，不因房间或候选列表泄露对方副卡组牌表。

## 2 阵法与配方

每个己方回合最多设置或替换一个阵法；初始阵法除外。阵法等级1–7，基础可承载位阶上限等于等级，明确符文/效果修正另计。法术定义位阶1–7。

配方为有限类型成本组合：支付魔素、将本人指定合法材料送入灰烬区等。先检查全部材料、数量、目标、空间和费用，再一次性支付和设置；取消、失败或过期选择不消耗材料或额度。材料费用及替换离场后的关联清理同属一次权威提交。取消或反制不默认退款。

保留阵体/场上容量规则和单宿主单符文规则。配方正式参数由逐卡迁移审定确定，禁止解释卡面文本作为可执行规则。

## 3 卡牌与区域

- 解析法术：占合适阵法环位进行解析；盖伏期间不解析。
- 言灵法术：占合适环位立即解析、立即准备至施法区并发动，可盖伏；默认2速及以上，旧行动卡并入此类。
- 咒符法术：必须在合法环位先盖伏，过等待期限后才可发动；默认2速及以上。
- 符文：附着于合法阵法或法术宿主，按明确附着规则结算。

解析区统一承载解析、盖伏和持续生效。施法区包含已准备、正在发动及效果已处理但尚待清理的法术，槽数等于己方当前场上总环位数；删除独立行动区和言灵区。所有法术的发动效果在施法区处理，普通法术处理后留在施法区，结束阶段送灰烬；永续、专注、计时依第6节回位，属于用户确认保留的持续法术例外。内部结算暂存不作为额外玩家可操作场地区域。

盖伏只可在己方主要阶段进行，与速度无关；不支付魔素、不产生荷载，并占环位，期间不进行解析。反转/发动时依法支付并产生对应荷载，魔素不足不可进行。盖伏当个全局回合不能反转或发动。解析法术必须解析完成才能准备；1速仅己方主要阶段准备，高速卡按第5节动作阶段表与来源限制共同校验，不能继续统一硬编码为主要阶段。

## 3.1 玩家动作

| 动作 | 含义 |
|---|---|
| 设置 | 从副卡组设置阵法，或从手牌将法术表侧放入解析区，按定义适用设置时规则 |
| 盖伏 | 从手牌将法术背面朝上放入解析区 |
| 准备（准备施法） | 将解析区已解析完成的法术移至施法区 |
| 反转 | 将盖伏卡翻为表侧，按定义适用反转时规则 |
| 发动 | 宣告施法区法术生效，建立链节并按连锁结算 |
| 附着 | 将符文附着于合法宿主 |
| 替换 | 用副卡组的新阵法替换场上已有阵法，与设置共用每回合额度 |
| 放弃 | 主动将自己的解析区法术送灰烬 |

设置或反转不是让尚未发动的法术主体效果提前在解析区结算。具体卡牌的设置/反转效果和额外操作权限必须有明确内容定义。此前施法阶段允许的放弃施法区法术继续保留，称为“放弃施法”，与报告定义的解析区“放弃”区分。

## 4 荷载、生命与枯竭

每次正向增加荷载，如果增加后的总荷载超过当前上限，立即产生本次全部新增荷载×2规则伤害。上限10、荷载9增加4至13时受8伤害；已过载时再增加1受2伤害；降荷载不返还伤害。一次不可中断支付中的荷载增量合并计算，独立效果分别计算。

普通过载允许继续支付、发动和清除荷载，不沿用旧的荷载空间支付禁令。纯上限下降不产生增量伤害。规则伤害先扣临时生命，再扣普通生命，不适用法术属性抗性或免疫。

生命归零或投降立即终局。两倍过载败北仅在结束阶段效果、计时、双方施法区及既有手牌收尾完成后检查回合玩家自身：总荷载超过上限且达到其2倍则败北；上限0/荷载0不会因0≥0败北。不检查非回合玩家，也不因双方同时过载判平局。临时越过2倍再合法降至阈值以下不会提前判负。此处采用报告第八节详细顺序和本轮用户确认，第二节“结束阶段开始”的概述不作为提前判负依据。

每名玩家维护枯竭计数。每次空牌库抽牌将计数增加1，并受到该计数的规则伤害；连续抽3张失败分别产生1、2、3伤害。发生终局后停止尚未处理的抽牌，不直接因空牌库判负。

临时生命维持旧的取较高值、不叠加语义。每次己方准备阶段第2步清除自身所有临时生命；不在结束阶段清除，不再使用“下一己方结束”到期字段。清除步骤之后新获得的临时生命保留至下一次己方准备清除；对方准备不清除自己的临时生命。因抽牌阶段早于准备，抽牌阶段发生的枯竭伤害仍可被当时尚存的临时生命吸收。

每次己方准备阶段第1步清除自身所有临时荷载；独立、绑定及来源关联荷载不随之删除。结束阶段不再进行无条件临时荷载清理，因此该回合产生的临时荷载仍计入结束阶段两倍过载检查。

## 5 时点、速度与连锁

合法动作完成（盖伏、设置、反转、准备、发动、附着、替换、放弃、放弃施法）、阶段开始/结束和实际连锁处理结束产生时点。非回合玩家先取得优先权；无合法响应自动放弃。拒绝命令和纯界面选择不产生时点。放弃响应与空窗口关闭不再制造同类窗口，避免无限空连锁。

发动建立C1，后续为C2、C3，按C3、C2、C1处理；连锁结算途中不插入新响应窗口，被动效果队列在规定流程处理。

| 速度 | 己方反转、设置、准备 | 己方发动 | 对方反转、准备、发动 | 跟随 |
|---|---|---|---|---|
| 1 | 主要阶段 | 施法阶段 | 不允许 | 仅启动 |
| 2 | 主要、施法阶段 | 主要、施法阶段 | 主要、施法阶段，来源为此前己方主要阶段盖伏卡 | 可跟1/2 |
| 3 | 全部阶段 | 全部阶段 | 全部阶段，来源为此前己方主要阶段盖伏卡 | 可跟1/2/3 |
| 4 | 全部阶段 | 全部阶段 | 全部阶段，来源为此前己方主要阶段盖伏卡 | 可跟1/2/3；之后不可响应 |

所有速度的盖伏均仅己方主要阶段；自己回合反转也须满足非本全局回合盖伏。所有连锁响应均禁止手牌。速度只决定时机上限，不绕过类型、解析完成、盖伏期限、环位、施法槽、卡面窗口、费用与目标条件。对方回合的通用入口不因速度自动扩展为任意表侧解析卡；现有快速解析响应能力在迁移表中单独审定，不能自动继承与新来源规则冲突的旧特例。4速虽可启动或跟随低速，但前一4速已关闭响应，因此不存在实际4速跟4速。

## 6 五阶段与持续回位

抽牌：先结算场上阵法及附着效果收入，再抽1张；玩家固定1魔素收入取消。

准备严格按以下子步进行：1. 清除自身所有临时荷载；2. 清除自身所有临时生命；3. 阵法上至下处理阵法效果；4. 从最上方阵法开始、环位左至右处理永续效果；5. 同样顺序询问专注是否维持，维持则支付费用和荷载；6. 所有本方解析中的法术进度+1，盖伏不增加。第3–5步之后新产生的临时资源不能再次被本阶段的第1–2步清除。处理顺序由权威场地顺序确定，界面滚动和重排不改变它。

主要：设置/替换阵法、设置法术开始解析、盖伏、反转、附着、放弃解析区法术、将完成解析的法术准备至施法区，以及类型和速度允许的其他操作。

施法：发动或放弃施法区法术。请求结束阶段时先完成当前连锁，再依确定的场地顺序将永续、专注、未到期计时法术回位，最后正式结束阶段。回位不预留原环位；本人重新选合法阵法和空环位，无合法位置进入灰烬区。非施法阶段发动的持续法术在所属连锁完成后回位。回位不是再次支付、再次发动或再次获得首次效果。

结束严格按以下子步进行：1. 阵法上至下处理阵法效果；2. 从最上方阵法开始、环位左至右处理永续效果；3. 所有计时法术计时-1，归零进入灰烬区；4. 双方施法区所有剩余法术进入灰烬区；5. 完成手牌上限等既有收尾后，仅检查回合玩家两倍过载败北。临时生命和临时荷载的无条件清理已移至己方准备，不在此阶段提前移除。该阶段所有子步及回位/维持暂停都必须可恢复，不能重复递减、收费或触发。

每名玩家仍最多一个专注。永续无自然计时到期，计时n按全局结束阶段递减；召唤只保留为未来术语，不在本轮实现。

## 7 验收场景

过载9→13、已过载追加、魔素不足拒绝、临时生命吸收、上限下降、两倍暂时跨越与结束检查；非回合玩家达到两倍不在本方结束判负、双方过载不自动平局、临时荷载保留至结束判负；连续枯竭及中途终局、抽牌阶段枯竭先于临时生命清除；免费盖伏、所有速度仅主要阶段盖伏与全局等待；1速主要准备/施法发动、高速动作阶段、同速链、4速终止、所有手牌响应拒绝；普通法术结算后留施法区；配方取消/不足/重复请求；持续回位无槽与换宿主；准备六步次序、专注费用、清除后新增临时资源不再清除、阶段暂停恢复不重复；副卡组和盖伏隐私。
