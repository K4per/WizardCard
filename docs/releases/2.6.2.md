# Alpha v2.6.2

程序、规则、卡池版本均为 `2.6.2`，mechanics revision `11`。正式卡池保持92张，沿用原有ID；内容哈希 `cc7c6005e8f96820`。

本版处理2026年11月4日至5日反馈中的46项问题、35张卡牌。包括响应时机、弃牌费用、阶段触发、持续修饰、额外回合、控制权暂借，以及卡牌目标与真实选择。阳炎爆改为2速，防死结界采用反馈的新文本。

## 规则裁定

- 计时从成功发动开始，只在控制者的结束阶段开始递减一次；先结算该阶段触发，再减计时，归零送灰。计时3因此可以触发三次。
- 过载真实伤害按新增超额荷载的两倍计算。19/20增加2点荷载，只受2点真实伤害。
- 真实伤害只扣普通生命，绕过临时生命与普通减伤，保留明确的真实伤害免疫；生命最低为0。
- 维持专注只支付魔素。禁止维持效果会同时限制选择、合法动作和实际执行。
- 解析时间增减排除已经发动、持续生效的法术。油腻术环位减半向下取整，超容量由控制者选择送灰。
- 灾祸术产生的独立荷载在对方结束阶段清除；加速术新增荷载翻倍持续至下个回合结束阶段结束。

## 操作与兼容

响应窗口显示全部合法来源并允许翻页。点击解析区卡牌用于查看、选择；选完目标与费用后再确认发动。玩家目标按当前观察者显示“己方／对方”。卡牌详情显示计时与最后一次触发顺序，云雾术和油腻术的目标显示对应状态。

保留中央传输协议5，程序版本、规则版本、内容哈希需与服务器一致。状态格式为 `wizardcard-state-v7`，复盘格式5、digest schema 3；旧版本复盘会明确拒绝。稳定卡牌ID仍可用于修复旧牌组。

Windows便携包为 `WizardCard-2.6.2-windows-x64.zip`，解压后运行 `WizardCard.exe`，保留同级资源和运行库。Windows用户数据目录延用 `WizardCard Alpha v2.6.1`，避免丢失原有设置、牌组。服务端同版包为 `WizardCard-CentralServer-2.6.2-linux-x86_64.tar.gz`。

逐项验收、测试记录、校验值及部署回退信息见 [2.6.2交付报告](https://github.com/K4per/WizardCard/blob/dev/docs/reports/2.6.2.md)。
