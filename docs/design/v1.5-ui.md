# v1.5视觉与交互规范

日期：2026-10-07。当前依据用户指定的布局实施：对局沿用1.0双方镜像五区（解析、施法、言灵、行动、灰烬），构筑沿用详情/主卡组/卡池三栏，全部逐卡显示。采用已提供的A古籍金饰素材，费用与状态图标同步接入。实际截图与验证见[本轮报告](../reports/v1.5-local-client.md)。

## 当前运行规范（界面精修）

- 标题页采用居中 Logo、短副标题和五个纵向菜单按钮；320×48、间距12，底部只显示版本。移除三张装饰卡、全高菜单侧栏和开发流程文字。
- `WizardSkin` 集中管理字号与主题：页面28、分区20、正文及按钮18、辅助14、卡牌次要状态12。沿用思源黑体，灰度抗锯齿；卡牌文字以最终显示像素布局，不使用整体缩放文字。
- 主要按钮保留金饰、左右36px内容留白；次要控件和区域内部采用浅色底板、细铜边。危险操作使用危险按钮样式。悬停、选中、禁用、键盘焦点分别反馈；卡牌支持Tab焦点及回车选中。
- 精绘框、Logo、背景线性过滤并生成运行时mipmap；像素卡图、费用与状态图标保持nearest。原始美术文件不修改。
- 缩略卡分为两行卡名、插画、费用、状态；超长省略，悬停可读全名及效果。主卡组90×148、卡池118×164，网格仍为5列和3列。手牌96×120（小窗口）或96×148；两段费用使用独立图标，数值14px，状态12px。
- 详情卡保留精绘卡框，名称、图标数值和两行摘要独立绘制；完整名称、属性和18px效果在卡框外显示并可滚动。
- 对局沿用1.0双方镜像五区，解析区按阵体占槽并保留宿主/附属卡关系。高度小于1050时区域标题与卡条同行；小窗口卡条保持14px名称，区域内部滚动，手牌及确认操作位于底部。施法区不占用多余纵向空间。
- 开局和设置使用居中640px表单；主要页面、弹窗使用同一主题。错误提示、换手、目标选择与终局也纳入布局检查。
- 规则、桥接、保存及复盘接口不变。点击、拖放、选择均不提前支付，最终确认继续由C++复验；详情只读。

真实运行截图、三种尺寸和30卡检查见[界面精修报告](../reports/v1.5-ui-polish.md)。144 DPI设备下的实际窗口调整与200%离屏渲染已记录；跨显示器系统缩放切换和真人IME仍需专项验收。

以下保留阶段0早期稿及流程说明作历史参考；深色石板、横向阵法等旧视觉提案不覆盖以上当前要求。流程表仍供后续网络与输入验收使用。


## 设计入口

[评审画廊](../../assets/art/design/v15/index.html)提供标题、复杂对局场地、卡组编辑器和状态流程，分别覆盖1920×1080、1280×720、1600×1000，共12张。源生成器为`tools/generate_v15_design.py`，从当前30卡JSON和运行美术映射读取文字与插画。场地使用真实Alpha AI复盘第107步的查看者0投影（`board-view.json`），包括阵体占槽、宿主关联和响应窗口；来源及摘要保存在manifest。Logo、原始卡牌PNG、字体保持原件；生成图不作为运行界面的背景图使用。

方向为精致像素奇幻：深色石板、古铜边饰、青绿符文。使用原色板的背景/面板/边框/文字层级，交互高亮使用青绿；伤害、恢复、取消与稀有度均配文字或形状，不单靠颜色。边饰集中在角落，面板内部降低对比；文字由运行时控件绘制，避免像素字体牺牲中文可读性。

## 页面和组件

| 页面/组件 | 信息和行为 |
|---|---|
| 标题 | 左侧Logo和符文构图，右侧AI、换手、LAN、构筑、设置；教学留在AI子页，退出独立。LAN仅为待实现入口，设计图不代表功能可用 |
| 开局配置 | 玩家卡组和基础阵法摘要、AI预设打法、难度、种子、开始/返回；只允许合法卡组开始 |
| 对局顶部 | 当前回合、五阶段、行动方/响应优先权、设置/复盘入口；阶段进度不是自由跳转按钮 |
| 双方场地 | 阵法使用横向分组，每阵体消耗对应槽位；附属解析卡在所属阵法容器内排列，不能把阵体2画成只占一个槽。符文有独立可点击角标 |
| 中央连锁 | 可滚动链节列表：速度、来源、目标、支付、取消状态；逆序结算顺序明确，响应操作与当前优先权一致 |
| 手牌 | 独立底栏；点选、拖放、滚动、边缘自动滚动、按类型/费用整理；展示顺序不写入规则或复盘 |
| 详情 | 只读侧栏：名称、类型/稀有度、插画、两段费用、位阶/速度、效果、当前实例信息；长文本可滚动 |
| 操作条 | 跟随选中卡牌，离窗口边缘时重新定位；无合法操作仍允许阅读详情。目标、额外成本和最后确认共享原交互模型 |
| 构筑 | 左详情、中主卡组、右卡池；名称输入、基础阵法、组合筛选、页码、全部校验问题、草稿保存；右键与跨栏拖放增减一张 |
| 房间 | 创建/加入IP、连接状态、双方卡组摘要、准备/取消准备、开始/离开；不显示对方完整牌表 |

## 尺寸与资源

- 主设计1920×1080，最小支持1280×720，并验1600×1000；信息区按容器重排，不能只缩放整张1920画布。主体文字最低16px，次要卡条文字最低14px；实际DPI和IME须在正式页面阶段实测。
- 小窗口优先保持场地和操作可见；详情、连锁、日志分别滚动；手牌横向滚动。设计图只展示当前可见窗口，运行时须保留其他卡牌和完整文本。
- 使用Noto Sans CJK SC。像素纹理nearest过滤、整数边缘定位；字体独立渲染；卡框按切片扩展，插画保持宽高比。
- 复用：Logo、30张卡图、字体、现有图标/卡背/P0音效。新增：统一Theme、可切片面板/卡框、空槽、宿主关联、状态高亮。旧资源不批量覆盖或重绘。

## 必须覆盖的状态与流程

| 状态 | 展示与退出条件 |
|---|---|
| 浏览 / 选牌 | 展示只读详情；选择另一张即同步，Esc清除选择 |
| 拖动 | 预览副本与合法落点；无效落点返回，Esc/右键/失焦取消，不支付 |
| 选目标 / 额外成本 | 明确步骤、候选与当前选择；多宿主或多链目标使用列表选择，取消可回退 |
| 最终确认 | 显示动作及费用摘要；确认时再次校验会话/修订/决策，接受后才刷新规则 |
| 强制决策 | 对应当前查看者展示合法选项；允许跳过时才显示跳过，不把强制决策当普通卡牌操作 |
| 换手 | 先清除详情、日志、特效与指针状态，遮挡私有信息；确认接手后读取新查看者投影 |
| 本地设置 | 暂停AI、自动推进和输入，保留未确认操作；应用保存或放弃后恢复原决策 |
| 教学 | 提示正常规则操作，讲解确认独立；错误操作给原因；重开固定牌表和种子39 |
| 终局 / 离开 | 结果、保存状态、重开/返回；未结束离开需确认，保存失败允许重试或取消 |
| 草稿 / 保存失败 | 未保存退出确认；失败保留编辑内容；损坏旧文件保留原件，不静默覆盖 |
| 联网设置 | 只暂停本机交互和演出，持续接收已确认快照；修订变化后清理过期选择 |
| 断线 / 重连 | 规则冻结、倒计时和恢复状态；重连以裁剪快照恢复，不补播全部历史演出 |

## 设计验收

三种尺寸检查30卡名称/效果、解析和施法费用区分、40生命上限、基础保护、来源荷载、埋伏隐藏、解析中/完成/待施放/专注、长文本和多链节。评审图仅覆盖核心布局，不等于真实交互、IME、DPI或全部卡牌已通过运行时验收。下一步需用户确认此视觉方向，随后按阶段2A→2D迁移页面。
