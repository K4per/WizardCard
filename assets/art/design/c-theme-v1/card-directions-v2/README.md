# 卡牌美术第二轮方向样稿

通过内置 imagegen 生成三版概念图，用相同的火球术、均衡之六芒星、银光锐语比较边框、信息组件与稀有度装饰。

- A 古籍金饰：酒红皮革、金属卷饰与嵌玉角扣；最接近原 C 风格。
- B 奥术珐琅：青绿珐琅、秘银羽饰与宝石结构；三类卡框结构差异更鲜明。
- C 蜡印锦缎：酒红织物、卷轴、金线与蜡印；更强调古籍手工质感。

本目录仅为方向样稿，不替换现有资源，不调整战场布局。生成图中的文字、属性图标与稀有度刻度用于概念展示，正式组件制作时应以当前卡牌定义与确定后的信息设计为准。

每版均附完整提示词；manifest.json 记录工具、引用和原始输出。PNG 为原样复制，没有二次改图。
