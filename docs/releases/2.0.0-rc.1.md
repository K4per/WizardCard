# WizardCard 2.0.0-rc.1

本候选版本包含 46 张正式卡牌、六位编号、40+10 构筑、Alpha v2 阶段与连锁规则、Godot 前端、AI、教学、复盘和局域网会话。

正式卡池稀有度已按卡牌定位重新分档：普通 19 张、罕见 10 张、稀有 8 张、史诗 6 张、传说 3 张。卡组编辑器收紧卡槽留白并放大卡面与空槽基座，便于在 1280×720 及以上窗口中查看和拖放。

程序、规则和卡池标识均为 `2.0.0-rc.1`。Windows x64 包由固定 Godot 4.7.2 导出模板生成，运行资源位于可执行文件同级的 `assets/`；制作源文件、测试夹具和历史文档不进入运行包。

验证入口：

- `python tools/catalog_source.py --check`
- `python tools/prepare_godot_frontend_assets.py --check`
- `python tools/check_module_dependencies.py`
- `ctest --test-dir build/rc1-release -C Release --output-on-failure`
- `wizard_cli validate assets`
- `wizard_cli smoke assets <recording> 42`
- `python tools/network_smoke.py --exe <wizard_network_probe> --assets assets`

实体设备、输入法、DPI、声音和虚拟 LAN 的验收记录必须由实际设备补充，自动化测试不替代这些检查。
