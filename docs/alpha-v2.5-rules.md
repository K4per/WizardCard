# Alpha v2.5.0 规则说明

适用版本：规则和卡池为 `2.5.0`；程序预览版本为 `2.5.0-preview.3`。

本预览版包含开局阵法选择、持续法术生命周期、局域网权威计时及 Godot 对局前端改进。完整规则以仓库中的实现、卡池和测试为准。

preview.2 阶段曾将魔素储存上限提高到20，并按用户提供的法术、阵法列表同步21张法术及8张阵法。伤害法术仅对对方玩家造成伤害；缝合生命可选择己方或对方玩家。解析法术分别支付设置与施法费用，咒符盖伏免费，仅支付施法费用。阳炎爆按己方灰烬区的塑能法术数量降低设置费用，施法费用仍为2。

卡牌的完整数值、配方和效果见[正式图鉴](card-catalog.md)；本轮修改清单及验证见[preview.3 交付记录](reports/2.5.0-preview.3.md)。旧预览版的复盘因程序版本和内容哈希变化而不兼容。

每方场上阵体总量最多5。阵法在场地上连续占用与阵体相同的槽位，解析环位位于该阵法的整个占用区域内；阵体2占两槽，阵体4占四槽，剩余槽位留空。配方消耗和替换会先扣除离场阵法的阵体，再校验新阵法的占用。
