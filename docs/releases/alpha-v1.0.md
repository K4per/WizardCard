# 巫师牌 Alpha v1.0

发布日期：2026-10-07。Windows x64 本地游戏；程序 `1.0.0-alpha`，规则与卡池均为 `1.0.0`。

## 启动

解压 `WizardCard-Alpha-v1.0-windows-x64.zip`，进入解压后的文件夹，双击 `wizard_client.exe`。保留同目录的 `assets` 与运行库 DLL；不需要源码、CMake、Visual Studio或另外下载卡牌资源。ZIP旁的 `.sha256` 文件用于校验下载完整性。发行物为便携版，不安装系统服务。

用户卡组、设置与复盘默认保存在 `%LOCALAPPDATA%/WizardCard`，不写入发行资源目录。更新时保留用户数据，替换发行目录即可；存储格式仍为1。内容变化后会重新校验已有卡组，草稿与无效ID保留并显示问题。规则/内容不兼容的旧复盘明确拒绝读取。

## 本版内容

- 全窗口标题画面与五项主菜单：换手测试对战、单人AI对战、卡组构筑、设置、退出。主菜单与局内设置共用音量、显示和阶段偏好；局内可继续、保存复盘、投降和返回。
- 初始生命与恢复上限均为40；主卡组30张、同名最多3张，基础阵法在构筑器内选择，额外基础容量2。
- 五阶段、速度与指定时点、多层连锁、埋伏/反转、专注、类型伤害、防护和来源荷载。手牌不可直接加入响应；四速后不可追加响应。
- 施法阶段可以不继续释放：待释放法术、已付费用与荷载保留，后续自己的施法阶段可释放。言灵可单独设置；零环即时言灵另提供“设置并释放”。
- 三档本地AI、固定引导教学；30种卡、九套合法预设，覆盖快速解析、来源荷载、五芒星塑能、防护续航、言灵节奏五个代表性方向。
- 全窗口构筑列表与三栏编辑器、名字和组合特征筛选、点选持久详情、拖放/右键增减、草稿与本地保存。
- 30张映射卡面、17个P0音效、对局动画与精简模式；EXE内嵌16–256像素的七尺寸徽标，窗口使用相同图标。来源和许可随包保存。

补充卡牌见[本版卡池](../alpha-release-cards.md)，完整规则入口见[连锁规范](../alpha-v1.0-rules.md)与[新规则接入](../alpha-v1-cards.md)，操作见随包README。
