# Alpha v2.5.4（2026-10-24）

- 程序、规则和卡池版本统一为 `2.5.4`，机制修订为 `8`，正式卡池135张；新增七星16张、血契20张，迁移旧风暴卡至风契系列并更新相关名称、文本与卡图。
- 响应询问提供全时点、自动时点、忽略时点三种模式。模式只控制本方可选响应询问和放弃优先权，不跳阶段、不略过强制选择或结算，也不影响对方响应与回放记录。
- 七星裁定：耀/黯按各自己方回合奇偶确定；星移交换持续到己方下回合开始，重复发动翻转；没有七星阵法时不可用分支效果。遥鉴不绕过瑶光只由开阳设置的限制。七星灯盏发动后提供伤害免疫，发动后离场判负；未发动离场不判负。遥鉴不足7张时查看全部，未选卡按原顺序置于牌库底且不洗牌。注视无效后盖伏回原宿主空环位，无空位则由拥有者选择合法环位，无合法环位进入灰烬区；之后按新盖伏期限等待。
- 血契裁定：未注明的伤害采用暗蚀；“已减少生命上限”按40减当前有效上限；支付生命需至少保留1点生命。折扣后允许混合魔素与生命支付，绑定荷载按折扣后的费用计算；生命替代与神恩炖肉由玩家选择且不能同笔叠加。降低上限时普通生命同步钳制；血印离场恢复有效上限但不返还生命；临时血契上限改动随来源离场恢复，一次性增减保留。血池只响应到期清除临时生命，心脏按实际造成伤害恢复生命。同源只传播实际正数恢复，同一恢复事件每张同源至多触发一次。
- 女祭司从卡组检索符文；世界四项从卡组检索，某类无牌时跳过该项；魔术师不足3个不同卡名时展示所有可用的不同卡名。阵法替换沿用通用离场清理，不继承符文和指示物。
- 对局时点切换按实现范围提供三档询问模式；其他规则与内容迁移细节见[逐卡差异报告](../../assets/design/alpha-v254/card-diff-report.md)及[更新需求报告](../../assets/design/alpha-v254/sources/requirements.md)。

专项原生回归覆盖目标选择时点、AI碎环术、那之后依赖、风暴导向、七星奇偶与替换、注视、灯盏、遥鉴和基础血契资源边界。交付报告记录本次实际构建、测试、UI烟测与便携包校验结果；未执行通过的项目不视为已验证。
