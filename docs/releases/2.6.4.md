# Alpha v2.6.4

## Windows 客户端美术修订

Windows 程序图标与主菜单标题横幅使用原版素材。设置、构筑、图鉴、教学、实战和复盘使用基础形状与文字。沿用上一版深蓝灰配色，以及设置金色、盖伏亮蓝色、合法目标绿色的提示。公开牌采用竖版蓝灰牌面、深色插图窗和浅色文字，手牌下方显示类型与费用。对手手牌与盖伏卡使用素色牌背。施法区继续用卡图缩略图。此 Windows 包可直接加入运行 2.6.4 的房间。

## 对局界面

- 每方五格阵体容量横向排列。大阵体占用相邻格，同一阵法的环位集中在该阵法外侧。
- 手牌、阵法及环位中的牌采用竖版卡面，施法区显示卡图。场地向上下延伸，己方手牌展开时可遮住外侧环位，收起后可查看和点选完整场地。
- 中央施法带左半为己方、右半为对方。两边独立显示占用数和容量，可分别翻页。
- 左栏保留卡牌详情，右栏显示连锁与日志。己方手牌位于底部，对方手牌在顶部显示牌背和数量。
- 对方牌库和灰烬区在左上，副卡组在右上。己方牌库和灰烬区在右下，副卡组在左下。
