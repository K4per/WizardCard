# 初版示例牌修改接入

日期：2026-10-05。程序 `0.6.1-dev`，规则 `0.3.1`，卡池 `0.2.0`。

依据用户提供的《初版示例卡牌修改.md》接入全部13张修改。生命缝合的荷载性质按用户后续确认采用**独立荷载，保留到被效果清除**。稳定卡牌ID和插画映射沿用原值，重命名、类型转换不会更换插画。效果文本完整叙述，费用、位阶和机制字段继续独立供规则校验使用，背景说明单独保存和展示。

## 专注

每位玩家最多维护一个专注法术，解析和言灵共用名额。新专注法术成功释放后销毁旧专注及其符文；新法术被取消或失效时保留旧专注。

自己的准备阶段首先选择维持或销毁，再获得准备收入和推进解析。维持支付解析法术本次准备实际费用；言灵使用设置实际费用。额外承受相同数量的绑定荷载，累积到该法术上。当前魔素不足，或者新增荷载会严格超出容量时，不投影维持选项；等于容量仍可维持。不能借尚未到账的准备收入支付。

销毁、主动放弃或替换专注时，一并移除其解析/设置、施法、历次维持荷载，以及由该专注源产生的其他荷载，并清理附属符文。专注不参与结束阶段的有限持续计数。专注周期效果只在自己的施法阶段捕获：首次释放所在阶段没有既存专注，因此炽燃结界首次只造成2伤害。

## 结算选择与连锁

- “那之后”按同一链节顺序执行，选牌可以暂停结算，恢复后继续；选择期间不能追加响应，不在两句之间判负。
- 火球术选择自己**没有承载解析法术**的扩展阵法；附有符文仍可为空白阵法。基础阵法沿用保护，不能选择。效果销毁不消耗主要阶段阵法操作次数或拆除费用。
- 碎环术和心如止水的弃牌属于结算效果，不是宣告成本。只能从自己手牌选择；没有符合条件的手牌时不执行依赖该弃牌的后续销毁/清除。碎环术的目标已失效时整条释放失效，不再要求弃牌。
- 银光锐语仍使用预置言灵规则。额外准备遵守解析已就绪、当前未被取消、目标和支付条件；可以放弃。选定时支付费用并记录宣告，当前连锁完整结束后，以新的准备根节点开放对手响应；不会在结算中嵌套连锁。准备后进入施法区，等其主人的施法阶段释放。
- 阿克乌姆之弧的保护针对对手效果销毁；允许被指定为目标，但销毁不会执行。自己的效果和主动拆除仍适用；不提供环位，因此不能承载解析法术。
- 符文可附着解析区的阵法/法术及预置言灵，每个宿主仍最多一个。奥术圆环对解析法术返还解析设置支付，对言灵返还预置/设置支付；准备费用和专注维持费用不计入这次奖励。仅成功首次释放返还一次，取消、失效、周期触发不返还。

## 荷载与协议

绑定荷载跟随实体；临时荷载按承担者的结束阶段期限移除；独立荷载无期限，不随瞬时来源进灰烬而消失。心如止水只清临时荷载，不清绑定或独立荷载。内容接口提供 `independent` 和 `clear_independent`，后者供后续明确清除独立荷载的效果使用，现有13张卡不具有该能力。

新增效果选择仍通过 `Choose`；效果给予的 `PrepareCast` 携带64位 `decision`，普通准备不携带。过期选择和缺少完整目标的选择原子拒绝。摘要包括设置支付、专注成本、荷载性质和延后准备队列，复盘保留双方实际卡组。格式仍为2，严格校验程序、规则、卡池和内容哈希；旧记录明确拒绝读取。

阶段二的历史机械回归使用 `tests/fixtures/stage2` 固定卡池；当前数值与新增机制由 `tests/card_updates.cpp` 直接读取正式内容验证，旧断言不作为当前牌面说明。验收记录见[适配报告](reports/alpha-card-updates.md)。
