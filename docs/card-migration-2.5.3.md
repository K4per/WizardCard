# Alpha v2.5.3 卡池裁定

日期：2026-10-23。正式卡池、图鉴、构筑和对局使用 `assets/catalog.json` 的99张卡；机制修订6。原始10.22资料、SHA-256与逐卡字段差异保存在 `assets/design/alpha-v253/`，可用 `tools/import_alpha_v253_content.py --apply-reviewed-fields --exclude-pending-cards` 重建。

- 正十字、逆十字、安卡十字效果待定，仅保存在草稿目录，不进入构筑或对局。旧草稿引用这些ID时显示非法卡牌，需要替换。
- 奥数圆环/奥术圆环与恩格亚斯之星/恩格亚斯四角星的名称差异保留记录；没有新增同名副本或静默改名，稳定ID继续使用。
- 恒风·风暴纹章初始0指示物；0–2指示物为等级1、环位1、荷载上限5、收入1；3–4为2、2、8、1；5以上为3、3、10、2。该数值已获设计确认，等级1时可选作初始阵法。
- 神恩炖肉仅替代魔素费用，按1魔素对应1点对方普通生命，在宣告时支付，对方至少保留1点生命。临时生命、额外弃牌、送灰、指示物和自身生命成本均不替代。费用不足整体拒绝。
- 倒吊人以发动宣告时自身普通生命为基数，向上取整支付一半，不消耗临时生命。双方各自非阵法牌库与非阵法灰烬卡交换，然后洗牌；数量可以不同，阵法留在原区域。
- 烈火回炉与回火有候选时须先选1张，之后可以停止，最多5张；没有候选时正常结束该部分效果。阵法返回副卡组，其余返回主卡组；回火按实际返回数结算火伤和治疗。
- 飘香诱惑先将双方手牌分别返回并洗牌，再由双方分别选择是否抽回实际返回数量；抽牌统一经过手牌上限、抽牌触发和枯竭规则，不以显示数量直接改写手牌。
- 糖浆煎饼每个普通伤害事件先处理免疫、抗性及减伤，再限制到最多4点，最后临时生命吸收、普通生命扣减。多段伤害分别处理；枯竭和过载属于真实伤害，按规则书不受一般减伤或本上限影响。下个己方准备阶段开始时失效。
- 篝火只在成功的表侧设置动作触发一次；规则书区分设置、盖伏和反转，因此盖伏与反转不重复触发。塑能伤害在元素之环上每个伤害事件加1；火焰伤害分类通过效果和结构化trait识别，与派系分别保存。
- 冰糖解除附着获得1魔素。风味转化先支付场上味契符文成本，结算时选择牌库味契符文和己方坩埚；没有合法目标则结束该部分效果，已支付成本不返还。

雪雨暴按10.22来源归为咒符，保留 `snow-rain-storm` 稳定ID、使用唯一编号040013；皇后和节制的速度及月亮荷载上限同步来源。旧的2.5.2发布文档保持历史，不表示当前规则。

复盘格式仍为4，新增可识别的调试操作记录。加载时严格校验程序、规则、卡池版本及内容hash；旧规则内容不匹配时明确拒绝，不把旧命令套入新规则。
