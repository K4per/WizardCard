## 规则会话与兼容性

- 同机双方完成猜拳、初始设置和升级。选择盖伏【阳炎爆】后取消，修订号仍为 70，再点选宿主的第二环位并确认。检查实付费用、占用、双方视角的公开位置和对手可见牌名，再打开终局复盘核对。
- 教学中【护盾术】C2 先于【魔法飞弹】C1 结算，实付 3 魔素，生命保持 40。真实卡组对局把施法容量降至 0 后，玩家选定超额法术送灰。独立内核场景使用正式【土石喷发】，核对五张法术在容量变为三时依次选定两张送灰。界面用例检查剩余数量提示、取消返回及强制专注只提交一次。[会话记录](2.6.4/match-acceptance.json)
- 正式卡池 90 张。2.6.3 复盘和混版握手按严格同版策略拒绝，旧复盘可用 2.6.3 播放。Windows 与 Linux 的种子 42 复盘逐字节一致，共 2,579 条命令，终局摘要 `20ccdb7b1474a233`。
- 打包、内容和源码导出相关 Python 用例运行 19 项，其中 5 项为 POSIX 专用并在 Windows 跳过。另行运行的历史 Python 用例有 8 项失败，可在 2.6.3 基线复现，涉及旧卡池断言、缺少的历史导入工作簿及 v2.5.0 夹具。独立对局页冒烟脚本退出时仍报告两个 ObjectDB 实例，最终包双端验收未出现运行错误。
