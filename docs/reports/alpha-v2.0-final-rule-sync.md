## 规则差异

| 项目 | 原计划/草案 | 最终同步 |
|---|---|---|
| 临时荷载 | 结束阶段既有收尾清除 | 己方准备第1步清除；保留独立、绑定、来源关联荷载 |
| 临时生命 | 下一己方结束清除 | 己方准备第2步清除；仍取较高值、不叠加 |
| 准备阶段 | 阵法、永续、专注、解析 | 临时荷载、临时生命、阵法、永续、专注、解析，共六步 |
| 两倍过载 | 结束收尾后检查双方，可能同时平局 | 结束收尾后只检查回合玩家自身 |
| 盖伏 | 主要阶段有盖伏操作，缺少统一禁止条文 | 所有速度均只能己方主要阶段盖伏，仍需等待至后续全局回合才能反转/发动 |
| 言灵与咒符 | 迁移候选中部分言灵沿用1速 | 默认2速及以上；言灵明确立即解析、立即准备、发动 |
| 速度 | 使用宽泛阶段表，解析准备统一主要 | 按反转/设置/准备/发动分别约束阶段；1速主要准备、施法发动，高速按明确阶段与来源校验 |
| 施法区 | 正文只覆盖准备和发动中 | 普通法术效果处理后继续留施法区，结束清理；持续法术回位例外保留 |
| 动作与时点 | 部分动作只列为“等” | 明列设置、盖伏、准备、反转、发动、附着、替换、放弃及其时点 |

## 本轮确认的两处解释

最终报告第二节写两倍过载在“结束阶段开始”败北，第八节则给出阵法效果、永续效果、计时递减、双方施法区清理、最后判断自身荷载的顺序。用户确认采用第八节：完成收尾后仅检查回合玩家。非回合玩家即使当前达到两倍，也不在本次检查中败北；生命归零仍立即结束，不受此延后规则影响。原“双方同时过载导致平局”约定撤销。

最终报告第四节写所有法术处理后留施法区、结束送灰烬，与原计划的持续回位存在冲突。用户确认保留永续、专注、计时法术回位作为例外；普通法术留施法区至结束。持续回位的合法环位重选、无槽送灰烬和阶段外连锁完成后回位继续沿用。

## 关键时序后果

抽牌仍先收入再抽牌，早于准备阶段。因此已有临时生命可吸收己方抽牌阶段的枯竭伤害，随后才在准备第2步清除。对方的准备阶段不清除自己的临时生命。准备清除步骤之后由效果或专注维持新增的临时荷载/生命不能被同一阶段重复清除。

本回合新增的临时荷载会保留到结束阶段两倍过载检查，不能沿用旧结束清理使其提前消失；纯上限下降仍不产生增量伤害。只有回合玩家的结束检查受到影响，规则伤害和生命归零的立即检查继续适用于双方。

1速在己方主要阶段设置、反转和准备，在施法阶段发动；2速在己方主要/施法阶段执行上述动作，3/4速可在己方全部阶段执行。对方回合的通用来源仍为此前合法盖伏卡，所有连锁响应仍禁手牌。高速度不自动授予任意表侧解析卡阶段外响应权限，魔法飞弹等特例继续逐卡审定。

报告中的设置/反转“适用其效果”按明确的设置/反转规则处理，不代替法术发动并提前结算法术主体效果。此前施法阶段允许放弃施法区法术继续保留，并以“放弃施法”区别报告定义的解析区“放弃”。

## 内容同步

[迁移草案](../proposals/alpha-v2/review.md)及其生成器同步最终规则。7张拟言灵候选由1速调整为默认2速：奥术回想、火花术、魔力扰动、心如止水、克敌机先、瞬发回路过载、奥术复苏。原速度保存在 `previousSpeed`，所有 `reviewStatus` 仍为 `pending`。支援术、虚假生命、护盾术的临时生命说明改为己方准备清除；银光锐语的额外准备改为按目标卡速度/类型/来源共同校验；炽燃结界的说明删除准备阶段收入假设。

30卡的具体等级、配方、费用、能力和9份预设仍未获组内批准。本次规则确认没有替代此前“需要调整，稍后提供修改意见”的内容关卡。9份预设数量合法不代表强度或玩法已经验收。正式 `assets`、规则/卡池版本和内容哈希未改变。
