# Alpha v0.6 下一期开发计划

基线：Alpha v0.5（2026-10-04）。产品目标：v1.0 交付一个可安装、可学会、可完整对战、可复现问题的 Windows 本地双人 Demo。以下为后续计划，未实施内容不计入 v0.5。

## 下一期目标与顺序

| 顺序 | 工作 | 验收条件 |
|---|---|---|
| 1 | 建立试玩记录与指标导出：双方回合、命令数、终局原因、版本/种子、生命变化 | 从同一复盘导出一致统计；区分真人与脚本，不以脚本胜率代替平衡 |
| 2 | 操作反馈：不可用原因、目标提示、拖放确认摘要和取消反馈 | 费用不足、无环位、错误目标均能解释原因；所有强制选择可完成或明确取消 |
| 3 | 新手引导与对局入口：解释解析→准备→响应→施放及换手 | 不读设计文档也能完成一次施法；可查看帮助、开始新局、保存终局 |
| 4 | 窗口适配与交互回归：小窗口、宽屏、长卡名、大量灰烬、连续换手 | 内容不遮挡、命中与绘制一致，弹窗不误操作背景，私有信息不泄漏 |
| 5 | 收集约20局真人探索，评估20生命与当前卡组节奏 | 每局保存复盘、时长、终局原因与体验；报告样本来源、局限、主要卡手点 |

先完成观测与反馈，再根据记录决定是否调整卡池或其他数值。初始生命20保持为对照基线；每轮只修改一组核心参数，独立 balance 提交说明假设、对照和结果。若真人测试尚未完成，明确挂起平衡结论，不用自动化局数补齐。

## 到 v1.0 的路线

| 版本 | 重点 | 出口条件 |
|---|---|---|
| Alpha v0.6 | 操作清晰度、引导、统计与试玩 | 上表开发项验证完成；真人记录单独报告完成度 |
| Alpha v0.7 | 根据观察丰富卡组选择、修复规则边界 | 每张新增卡有结构化定义、规则回归、卡面与合法卡组；无脚本效果混入 UI |
| Alpha v0.8 | 反馈表现与教学打磨 | 关键支付、取消、伤害与离场可辨识；动画不影响结算和复盘 |
| Alpha v0.9 | Demo 候选冻结、安装包和兼容回归 | Windows 全构建、Linux 核心及跨平台复盘通过；已知阻断问题清零 |
| v1.0 Demo | 首个可玩的演示交付 | 干净 Windows 环境启动，从引导到完整双人对局与重开可用；至少一轮有记录的真人验收、许可、说明和已知问题齐备 |

范围基线仍为本地双人，联网与 AI 不作为当前 Demo 的隐含必需项。若后续改变目标，先修订范围和验收，避免边开发边扩大交付标准。

## 分支、版本与交付

每项工作使用短期 `codex/<主题>`，main 仅在 CI 通过后合并。程序版本、规则版本、卡池版本独立记录；每次玩法变化同步回归和设计文档，数值实验独立提交。每个 Alpha 固定标签、发布说明和对应资源，不覆盖历史标签。v0.6 收尾交付进度报告、缺陷列表、试玩统计及下一期范围。
