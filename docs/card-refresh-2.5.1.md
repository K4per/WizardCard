# Alpha v2.5.1 现有卡池逐卡翻新审计

审计基线为本次更新前的 Git 提交 `4a7ff26e6a6c2f3415310179476b00fd4d190a47`（62 张 canonical 定义），目标为 Alpha v2.5.1 工作区正式卡池。逐卡比较 JSON 对象和值，并比较插图资源清单的逻辑 ID、路径、来源、尺寸、采样和 SHA-256；不是仅依据文件是否出现在 diff 中。审计日期：2026-10-20。

原需求没有给出旧卡的具体数值、效果或美术替换方案，并要求“没有明确改动的卡牌保持原定义”。因此本版对下列 62 张均审定为保留，不擅自调整平衡；16 张味契为新增内容，另见 [味契说明](sique-cards.md)。卡池元数据从 `rulesVersion/cardSetVersion=2.5.0`、`mechanicsRevision=3` 升至 `2.5.1/2.5.1/4`，不改变旧卡的稳定 `id` 或 `number`。

本清单是审计快照，不是第二份卡牌维护源。卡面长文本、背景描述及完整字段以每行链接的 canonical JSON 为准。表中“当前规则字段”逐项记录该卡已声明的规则值（缺省字段不补写）；身份字段在前两列，`illustrationId` 和美术来源在后表。`name/rarity/text/flavor/tags/summonCondition` 等卡面字段也已按完整 JSON 比较，全部保持。

依据代码：R1＝原需求“无明确改动则保留”；R2＝完整定义与基线逐值等价；A1＝插图条目与基线等价且运行资源哈希校验通过。影响代码：D＝现有存档/牌组/网络/回放继续引用原稳定 ID；V＝图鉴/构筑/对局/复盘继续使用同一插图。全局规则版本和新增味契交互仍按发布兼容策略处理。

“保留审计通过”表示本次未增设平衡方案，定义与美术映射核查通过；不冒充新增数值的人类审定，也不声称逐张完成手工实战。原生内容校验、卡牌包往返及资源检查的实际结果列于文末；客户端整体视觉与对局回归由发布验收记录。
