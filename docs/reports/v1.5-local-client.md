# v1.5 本地客户端与新素材接入记录

日期：2026-10-07。开发分支 `dev`，程序 `1.5.0-dev`；规则/卡池 `1.0.0`，内容哈希 `733319e247ac38ff`。本轮承接阶段0/1，将新素材接入真实Godot页面，并推进阶段2。

## 本轮结果

- 按用户要求采用A古籍金饰素材，保留原始Logo、30张插画、精绘卡框和徽章。检查314个素材条目、13份原件校验、30张卡图及17个音频文件，未改写原始PNG/MP3。
- 对局沿用1.0镜像布局，每方解析、施法、言灵、行动、灰烬五区。阵法按阵体占槽，宿主法术与符文关联显示，拥挤区域可滚动。
- 构筑沿用详情/主卡组/卡池三栏，每份卡牌独立显示，恢复右键增减、跨栏拖放、基础阵法、组合筛选、分页、草稿及保存失败恢复。合法30张主卡组不分页。
- 接入解析/施法费用、位阶、速度、阵体、环位、容量、收入、生命、魔素、荷载图标；文字与图标共同表达语义，完整长效果留在只读详情滚动区。
- 标题、设置、开局、换手、三档AI、固定教学、目标/成本/链节选择、最终确认、日志、终局、重开、离开确认和复盘使用真实C++应用层。
- 复用 `matchSounds` 的过滤事件判定和现有音频文件，Godot缓存解码、限6路、按优先级替换并限频；暂停、换手和离开清理旧声音。
- 旧页面及手牌拖动携带代次/修订，过期回调不进入新选择；已接受但保存失败的命令只重试保存。

实际默认入口为 `godot/scenes/wizard_client.tscn`；桥接实验台保留。新本地API与运行说明见[开发者文档](../developer-guide-v1.5.md)和[工程说明](../../godot/README.md)。

## 阶段关卡与剩余工作

阶段2A/2B及2C/2D的主要功能已实现，自动流程通过；**阶段2尚未完整验收**。真人IME、DPI、失焦/出窗、拖动边缘滚动、无效落点和复杂选择体验仍需对照Alpha补齐并检查；声音自动解码验证不代替真人听感。当前全卡组逐卡展示与三栏方向以用户本轮要求为准，早期深色布局设计稿仅作历史参考。

下一关先完成本地输入与体验验收，之后进入阶段3网络会话。LAN协议、断线重连、两台实体Windows、Godot完整VFX、新联动规则、独立导出、性能和远程CI均不在本轮通过声明内。首次LAN仍保持Alpha规则/卡池，新卡由用户定稿。本轮未提交、合并或发布，保留既有未提交修改。
