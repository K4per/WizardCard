# 阵法卡

### 七星·天枢

* 召唤条件：魔素×2

* 阵法等级：1

* 阵体：5

* 环位：1

* 荷载上限：7

* 魔素收入：1

* 效果：**己方【七星】卡在奇数回合获得耀，在偶数回合获得黯。**

### 七星·天璇

* 召唤条件：通过【七星】卡的效果才能设置

* 魔素收入：2

# 符文卡

## 七星星帜

* 附着费用：2

* 效果：

   * 附着于阵法：此阵法卡被销毁时，可以将此符文卡解除附着作为替代。

   * 附着于法术：发动费用-3。

# 解析法术卡

### 七星灯盏

* 法术类型：解析法术

* 法术阶级：7

* 派系：死灵

* 设置/发动费用：7/7

* 解析时间：7

* 咒文速度：1

* 效果：**计时7。自己场上有【瑶光】存在才能发动。**发动后，此法术卡只要在己方场上存在，己方不会受到伤害。此法术卡离场时，己方败北。

### 七星归墟

* 法术类型：解析法术

* 法术阶级：7

* 派系：塑能

* 设置/发动费用：7/20

* 解析时间：4

* 咒文速度：1

* 效果：

   * 耀：对双方造成20点光耀伤害。

   * 黯：对双方早成20点暗蚀伤害。

# 言灵法术卡

### 七星启曜

* 法术类型：言灵法术

* 法术阶级：1

* 派系：预言

* 设置/发动费用：3

* 解析时间：0

* 咒文速度：2

* 效果：

   * 耀：将1张【七星】卡从卡组加入手卡，己方选择受到7点光耀伤害/获得7点荷载。

   * 黯：将1张【七星】卡从灰烬区加入手卡。

### 七星遥鉴

* 法术类型：言灵法术

* 法术阶级：1

* 派系：预言

* 设置/发动费用：3

* 解析时间：0

* 咒文速度：2

* 效果：

   * 耀：**将1张卡从手卡送去灰烬区才能发动。**将己方场上1张【七星】阵法卡替换为更高1级的【七星】阵法卡。

   * 黯：查看己方卡组最上方的7张卡，将其中1张【七星】卡加入手卡，其余卡返回卡组最下方。

### 七星星移

* 法术类型：言灵法术

* 法术阶级：1

* 派系：变化

* 设置/发动费用：3

* 解析时间：0

* 咒文速度：2

* 效果：

   * 耀：**支付7点生命值才能发动。**发动后，己方【七星】卡耀/黯效果交换适用。

   * 黯：**将1张卡从手卡送去灰烬区才能发动。**将己方场上1张【七星】阵法卡替换为更高1级的【七星】阵法卡。
