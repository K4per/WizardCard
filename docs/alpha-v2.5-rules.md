# Alpha v2.5.3 规则说明

适用版本：规则、卡池和程序均为 `2.5.3`，机制修订为 `6`。正式卡池99种：18张阵法、36张解析法术、22张言灵法术、13张咒符法术、10张符文。数值、配方与效果见[正式图鉴](card-catalog.md)，省略文字的本版裁定见[卡池迁移决策](card-migration-2.5.3.md)。

## 构筑、开局与场地

主卡组固定40张，副卡组固定10张阵法；各自同名最多三张。副卡组须含等级1阵法。双方各自在开局私下选择一张等级1初始阵法，确认后同时公开设置，此次免费且不消耗回合阵法额度。初始普通生命和普通生命上限为40，双方开局魔素0，魔素储存上限20。魔素保留至后续回合；抽卡阶段由阵法产出魔素，先手首个抽卡阶段仅跳过抽牌。改动报告的“初始费用”按开局魔素解释，不清零卡牌设置或发动费用。

每方场上阵体总量最多5。阵法连续占用与阵体相同的槽位，环位分布在该阵法的占用区域内。配方消耗和替换先扣除离场阵法的阵体，再校验新阵法。己方主要阶段每回合最多设置、替换或主动移除一个阵法，三者共享额度。移除阵法时，其承载法术和附着符文按离场规则清理；阵法的免疫、不会被效果破坏不阻止拥有者主动移除。

解析法术分别支付设置和发动费用。言灵通过合法环位立即准备并发动，也可以盖伏。咒符必须先盖伏且盖伏免费，发动时支付其费用。盖伏不校验阵法等级与法术阶级，仍检查归属、可用环位、区域和通用条件。低等级阵法上的高阶法术不可反转、准备或发动，可放弃送灰；表侧设置和反转仍校验阶级与宿主限制。盖伏卡从盖伏它的全局回合结束后即可满足等待条件：不要求再等到拥有者回合；实际发动仍须满足优先权、速度与卡面条件。

## 统一咒文速度

| 速度 | 没有连锁时 | 加入连锁时 |
|---|---|---|
| 1 | 己方主要阶段设置；施法阶段发动 | 不可响应 |
| 2 | 主要或施法阶段的合法时点 | 主要或施法阶段，响应速度不超过2的链节 |
| 3 | 任意阶段的合法时点 | 响应速度不超过3的链节 |
| 4 | 任意阶段的合法时点，仍须满足卡面触发条件 | 响应速度不超过3的链节；其后不能再加入响应 |

对方回合只可在获授优先权的响应窗口行动。己方回合的合法主要/施法响应时点，手牌中满足速度的言灵法术也可一次完成设置、准备与发动，只支付一次并形成一个链节；对方回合仍须使用满足等待期限的盖伏法术。无额外响应条件的已准备法术、满足等待期限的盖伏法术使用同一速度规则；专属条件优先限制，例如银光锐语仅在对方准备施法时，法术反制仅在对方发动法术时，风击术仅在对方设置解析法术时，恶魔仅在对方选择法术目标时发动。重用过期决策令牌、费用不足、非法目标和错误时点必须整体拒绝，不能部分支付。

## 目标、附着与资源

写“选择一个目标”的伤害或治疗法术可选择任一玩家；明确写“对方”的效果处理对方玩家。炽热射线三段分别选择目标，不能把一次选择默认为三个相同目标。碎环术准备施法不选择目标，发动时选择对方空白阵法；结算时从己方副卡组选择阵法送灰后才破坏目标。副卡组送灰是结算效果，不是发动成本；没有可送灰阵法时仍可发动，但不破坏目标。目标在结算时失效，已支付费用不返还。

每个合法宿主可以附着多个符文。每次附着独立支付费用，并检查符文自己的宿主限制。各符文的环位、收入、费用或伤害修正按正式效果叠加；宿主免疫可排除符文修正。可以单独移除某个符文；宿主离场时一并处理其附着物，解除附着效果按卡面执行。

临时生命与普通生命分开记录，可以按来源和获得事件叠加。伤害先消耗到期较早的临时生命，再按获得顺序消耗；剩余伤害扣普通生命。各来源保留独立期限，在拥有者下一次抽牌阶段开始时清除到期部分。来源卡离场不等于立即失去其已经获得的临时生命。支付普通生命不会消耗临时生命，治疗遵守普通生命上限。

荷载包含绑定、临时、来源关联和独立负担。普通临时荷载在拥有者抽牌阶段清除；指定期限的效果使用指定时点；来源关联荷载随其来源离场清除；独立荷载需要清除效果处理。召雷术给予对方的五点荷载在对方结束阶段清除。超过荷载上限的新增荷载引发过载伤害，月亮仅免疫此类伤害，不免疫枯竭或普通法术伤害。

## 2.5.3专项裁定与调试

神恩炖肉仅替代魔素费用，在宣告时按1:1扣对方普通生命且至少留1；倒吊人宣告时支付自身普通生命向上取整一半。风暴纹章初始0指示物，0–2/3–4/5以上的等级与环位为1/2/3，荷载上限5/8/10，收入1/1/2。更多逐卡裁定见[卡池裁定](card-migration-2.5.3.md)。

挑战AI的对局菜单提供单人调试控制台。加入卡牌不计抽牌，手牌达到8时拒绝；资源调整区分普通与临时生命、绑定/独立/临时荷载，绑定荷载必须引用该玩家有效场上来源。直接增减仍修改实际数值；无限生命/魔素使规则扣减和门槛不阻断，无限荷载上限保留累计但免疫过载伤害和过载判负。关闭开关立即恢复常规判定，状态栏显示∞。

回到上一回合恢复紧邻上一回合开始的完整状态、随机数与回放位置，截去该点后的命令并记录回退调试标记。无快照时不可用。联机、换手、教学、观战和回放均由权威会话拒绝调试调用；包含调试的记录明确标记，普通联机命令编解码不接受调试命令。

对局和回放双方状态栏均来自对应时点快照；荷载提示区分绑定、独立、临时来源。日志默认隐藏，通过日志按钮打开/收起，关闭不清除事件。目标、费用和确认弹窗阻止底层操作，确认与放弃在明显的居中区域。
