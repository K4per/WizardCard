# 卡组构筑与卡组编辑美术需求

依据：用户指定沿用 v1.1 整体布局；旧版截图和 `src/client/deck_layout.inc` 为布局基准。采用已确定的 C 版奇幻像素风，以 1920×1080 为设计基准。美术由内置 ImageGen 生成，再接入 Godot；文字使用开源中文字体实时排版。

## 布局与展示

- 卡组构筑列表：保留上方标题、新建卡组、预设选择和复制入口；中部纵向卡组条目、右侧删除；下方分页、总数和返回。条目展示基础阵法的完整卡牌缩略图、名称、张数和校验状态。
- 卡组编辑：保留上方卡组名称与基础阵法，左侧详情、中部主卡组、右侧卡池，底部保存、校验和返回。
- 中部保留原六列卡牌网格和左右三栏结构，增加主卡组／阵法副卡组页签与独立计数；主卡组容量 40，副卡组容量 10，同名多份逐张展示。主卡组每页 30 张、剩余卡片通过原分页位置浏览；副卡组同样逐张展示。右侧卡池保持 3 列 × 3 行、搜索、六项组合筛选与分页。
- 卡片复用现有五种 ImageGen 原始卡框和 30 张正式卡牌插画，保持完整 3:4 卡面；卡池增加份数角标，满额时降低明度。左侧详情也展示完整卡牌，并提供可滚动全文。
- 用户已纠正本轮容量为 40 张主卡组和 10 张副卡组；阵法进入副卡组，其余类型进入主卡组，初始阵法从副卡组选择。保留点击/悬停详情、右键或双向拖放增减、草稿保存与未保存离开确认。检查现有原生接口的版本兼容，避免把旧版 30 张校验误用到新版构筑。

## 新生成的资产

| 资产 | 用途与要求 |
|---|---|
| 月夜魔法藏书室背景 | 1920×1080；深蓝石墙、金饰、青色魔晶；中央阅读区域安静，装饰集中边缘 |
| 高窄详情面板 | 透明、深蓝底、古金细纹与青色宝石；边框克制，保证左栏全文空间 |
| 卡组/卡池通用面板 | 透明、可九宫格拉伸；用于中栏和右栏，不烘焙格子或标签 |
| 卡组列表条目 | 透明横向皮肤，可拉伸；保留左侧卡牌封面与名称、状态、右侧操作的空间 |
| 空卡槽 | 透明 3:4 卡槽；深色低对比纹理，装饰不与已有卡框竞争 |
| 份数/状态角标 | 透明、金边青晶风；份数、合法/草稿文案实时绘制 |
| 加入/移除落点高亮 | 透明、青色符文轮廓；对实际目标容器叠加，不覆盖卡牌文字 |

主卡组／副卡组页签使用当前 C 版共享控件皮肤；两种容器保持相同卡牌比例与卡框主体。

搜索与筛选框、通用按钮五态、滚动条、确认弹窗材质和字体复用已经完成的 C 版共享资产。完整卡框直接投入使用。
