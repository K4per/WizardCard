# Alpha v0.5

2026-10-04 · 程序 `0.5.0-alpha` · 规则 `0.2.3` · 卡池 `0.1.0`

本版本面向本地双人试玩。行动区扩大、灰烬区缩小；标题避开装饰；解析法术可以拖到解析区空白处，单个合法阵法自动匹配，多个候选弹窗选择。初始生命调整为20，恢复上限仍为30。

解压 `WizardCard-0.5.0-alpha-windows-x64.zip` 后运行 `wizard_client.exe`，保留同目录 assets。点击卡片查看右侧详情和上方操作；拖放后确认才扣费，Esc 取消，F5 保存复盘。换手后由对应玩家确认接手。

旧版本复盘需使用旧版本程序；本版会拒绝不匹配的程序/规则/卡池。Alpha 不代表平衡完成：真人探索、更多设备适配和 Demo 教学仍在后续计划中。
