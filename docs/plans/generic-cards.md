# Alpha 泛用卡设计方向

设计基线见[指南](../card-design-guide.md)。本文件是候选方向，具体卡名、效果和数值由你设计；本批实际接入见[v1.0规范](../alpha-v1-cards.md)；下表仍作为后续候选方向。泛用牌帮助不同策略正常运转并提供应对手段，五种最终卡组仍需要各自的核心收益与操作路线。

先补功能缺口，再做数值相近的重复牌。稀有度不承担“严格更强”的定位；每张泛用牌应有费用、时间、荷载或适用场面的取舍。

| 优先级 | 方向 | 首批设计问题与边界 | 当前实现支持 |
|---|---|---|---|
| P0 | 荷载管理 | 低成本少量临时减压，与心如止水的全清+弃牌区分；另考虑有代价的独立荷载清除，让生命缝合的长期负担存在解法 | 临时少量/全清可接入；独立当前只支持全清，指定点数需扩展 |
| P0 | 基础反制与反反制 | 一张时机较窄、代价清楚的防守响应；一张能保护自己的准备/释放的链节反制。分别标明预置或埋伏模式与速度，手牌禁止响应，避免免费应对一切 | 准备取消、链节取消、额外弃牌、临时负担可接入；“只取消某类链节”等细条件需扩展 |
| P0 | 手牌周转 | 有代价的补牌或抽后弃置，减少起手卡住；与奥术回想“净增手牌+临时荷载”区分。不能无限循环净赚牌和魔素 | 抽牌→结算弃牌可接入；指定标签检索、窥牌、任意换牌需扩展 |
| P1 | 小型伤害与回复 | 低收益低投入或慢速高效率的稳定工具，保留火花术、火球术及生命缝合各自作用；治疗须写清生命上限和荷载性质 | 固定玩家伤害/治疗可接入；按损失生命等动态数值需扩展 |
| P1 | 场面应对 | 有成本的公开场上对象销毁，帮助处理符文/持续法术；考虑阵法被销毁时的关联清理，避免廉价拆阵直接造成普遍过载败北 | 现有公开目标+销毁可接入；只限符文/持续法术等细筛选需扩展 |
| P1 | 构筑基础设施 | 提供环位、收入或荷载上限之间有区别的阵法/符文选择；先测试扩展阵法，不自动给每张阵法基础资格 | 固定阵法属性、环位/收入符文可接入；临时动态属性、多符文需扩展 |
| P2 | 节奏与连锁衔接 | 带代价的额外准备、离场小收益，让玩家练习连续动作；避免免费跳过解析/施法阶段 | 额外准备现有就绪法术、有限触发可接入；已支持固定立即完成解析，任意时间修正需扩展 |

建议第一批先写**6份候选稿**：临时减压1、独立减压1、窄时机反制1、链节保护1、手牌周转1、场面应对1。这个数量用于讨论与验证，不是最终发布卡池规模，也不预设全部入选；需要新增目标条件的方案先设计接口，再接入卡牌。

第二批再补伤害/回复、阵法/符文和节奏工具，结合你确定的五种方向填缺口。每批2–4张进入游戏，使用相同牌表分别试玩普通AI、困难AI和换手局，比较策略是否真的不同。

数值先按现有参照卡讨论：火花术的1设置费用/2伤害、火球术的3解析+1施法/延时10伤害、奥术回想的1使用费用/抽2+临时荷载1、生命缝合的1解析+1施法/回复6+独立荷载2、心如止水的1使用费用/结算弃牌+全清临时荷载。不能只比较单次伤害与魔素，还要比较位阶、环位占用、解析等待、绑定荷载、响应窗口和额外成本。

当前完整数值基线为[30卡图鉴](../card-catalog.md)，生命和治疗上限40。补充参照如下，不仅沿用旧五张卡：

| 参照卡 | 当前费用 / 收益 | 设计比较维度 |
|---|---|---|
| 寒霜射线 | 解析1、施法1，延时3寒冷伤害 | 低阶、低费、伤害类型与基础阵法折扣 |
| 闪电束 | 解析3、施法2，延时8闪电伤害 | 火球术对比：伤害类型、施法荷载与终结效率 |
| 护盾术 | 设置2，6临时生命，2速可响应 | 预先支付、后场占位、响应窗口；不与已有临时生命相加 |
| 次级复原 | 解析2、施法1，立即解析、清全部临时并恢复2 | 环位与立即解析、绑定成本；不清独立荷载 |
| 虚假生命 | 解析2、施法1，立即解析、8临时生命、2独立荷载 | 非叠加防护与长期代价 |
| 奥术复苏 | 使用0，魔素3、临时荷载2到本回合结束 | 上限12的有效收益、过载风险与节奏 |
| 魔法飞弹 | 解析2、施法2，3力场伤害与可选拆埋伏 | 解析等待、对方施法阶段合法时点、2速限制 |
| 法术反制 | 设置4、4速，反制目标实际施法费用等量延迟临时荷载 | 关键响应的目标限制、延迟负担、四速后无响应 |

内容侧提出的12–15张大设计批次、目标总卡数与定稿权仍待用户确认；设计批次和2–4张可验证接入小批次可分开，不能据当前卡数直接证明联动路线不可能。核对结果见[对接报告](../reports/content-handoff-review.md)。

每张候选用[模板](../templates/card-design.md)交付，验收关注：能够明确演算，存在可应对窗口，至少两种策略能合理采用，仍有适合不带它的构筑；不靠无限抽牌、免费收入或低成本拆阵挤压所有策略。对局强度和五方向完成度以真人试玩记录决定，自动跑局验证稳定性。
