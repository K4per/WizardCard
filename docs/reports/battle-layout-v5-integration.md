# 对战场地与手牌布局 V5

2026-10-11。先用内置 imagegen 生成透明美术素材，再接入 Godot 场地预览页。主菜单进入“场地预览”即可体验。

## 本次修改

- 手牌沿弧线重叠、左右向外旋转，点选后沿扇形向外伸出并略微摆正；选中卡最后绘制，保持在其他手牌之上。右键收回并关闭详情和操作条，Esc 同样可关闭。旋转后的点击使用逆变换计算，透明外接矩形角落不会误选手牌。
- 解析区与施法区的卡图增加金色薄边框，选中或悬停使用青色强调框。仍显示方形卡图，不增加完整卡牌的名称、费用、文本面板。盖伏投影仍使用匿名卡背。
- 每方解析区改为一个大框，宽度从场地的48%扩至74%，取消按阵法重复的行框。阵法与法术以独立卡图组显示在区域内，关联线只作轻微提示；额外阵法可通过滚轮浏览。环位仍来自投影，空环位只在拖动时提示。
- 施法区高度从场地的12%收至6%，使用连续的地面刻纹窄条。解析区边界与施法区都由低透明度的石质边缘、金属镶线和奥术刻纹暗示。
- 详情继续保留一个完整卡牌与一个详细信息框；效果检索弹窗继续锁定场地输入，强制选择不会被右键或 Esc 关闭。
