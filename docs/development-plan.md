# 开发计划

规则依据：design.md v0.2.3。首版 Windows x64 本地双人换手；专用卡牌引擎，C++17 / CMake / SFML。银光锐语仅取消准备，每宿主一张符文。

| 里程碑 | 内容 | 验收 |
|---|---|---|
| v0.1 | 构建、内容、状态、CI | Windows 构建，Linux 核心 CI，13 张定义及 30 张卡组合法 |
| v0.2 | 五阶段、支付、阵法、解析、行动、胜负 | 无窗口完整对局 |
| v0.3 | 选择、言灵、符文、持续、队列、复盘 | 设计第16.3节回归、确定性 |
| v0.4 | SFML UI、中文、换手、日志、打包 | 双人完整对战与人工界面验收 |
| v0.5 | 统计、约20局真人探索、平衡 | 保留原始记录，每次只调整一组参数 |

使用 main 与 codex/ 短期分支；提交按 docs/build/feat/fix/test/balance 分类。CI 通过后合并；只有满足验收条件才打里程碑标签。分别记录程序、规则、卡池版本和内容哈希；旧复盘遇到不兼容版本明确拒绝。

首版不实现联网、AI、多符文、多层反制、通用 ECS、编辑器或商业收藏。后续服务器复用核心命令及投影视图。自动化跑局不能代替真人平衡测试。

## 2026-10-04 版本路线修订

以上表格保留为最初工作分解，不再把编号直接视作验收完成证明。本轮按试玩反馈发布 **Alpha v0.5**（`0.5.0-alpha`）；原计划的统计、约20局真人探索和平衡验收尚未完成，转入后续 Alpha 工作。Alpha 标签用于固定可复现测试基线；v1.0 才交付首个可玩的 Demo。

下一期执行 [Alpha v0.6 计划](plans/alpha-v0.6.md)，本轮事实与限制见[进度报告](reports/alpha-v0.5-progress.md)。仍采用 main 与短期 codex/ 分支；功能分支运行 CI 后再合并 main，发行标签可指向已验证的 Alpha 测试分支，不提前宣称跨平台 CI 通过。
