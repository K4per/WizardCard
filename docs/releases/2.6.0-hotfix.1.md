# WizardCard Alpha v2.6.0-hotfix.1

日期：2026-10-31

程序版本推进至 `2.6.0-hotfix.1`，规则与卡池版本保持 `2.6.0`，机制修订保持 `10`。正式卡池仍为 92 张：解析法术 39、言灵法术 21、咒符法术 12、符文 3、阵法 17。

本 hotfix 修复火焰伤害法术设置到硫磺时的合法性判断。`燃烧之手` 和 `炽热射线` 的直接、选择、射线及 v2.6 结构化范围伤害现在都会被识别为火焰伤害法术，因此可以作为硫磺的合法宿主材料。灰盒主界面、图鉴和 v2.6 卡图映射随正式卡池一并发布。

Windows x64 便携包为 `dist/WizardCard-2.6.0-hotfix.1-windows-x64.zip`，同目录的 `.zip.sha256` 是下载校验值。包内 `RELEASE.json` 标记 `status: released`，`SHA256.json` 记录逐文件摘要。

完整验证记录见[2.6.0-hotfix.1交付报告](../reports/2.6.0-hotfix.1.md)。
