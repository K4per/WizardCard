# Alpha v2.6.1 Windows 便携包

发布日期：2026-11-03。基于 `dev` 提交 `cda4b9a`，附加本次版本标识更新。

程序与包版本为 `2.6.1`；规则及卡池继续使用 `2.6.0`，机制修订为 `10`。包含最新中央服务器房间、Godot TLS 客户端、手动重连和联机复盘实现。中央服务器握手按协议、规则、机制和卡池内容检查兼容性。

解压 `WizardCard-2.6.1-windows-x64.zip` 后运行 `WizardCard.exe`，无需安装 Godot。保留同级 PCK、bin、assets 和运行库 DLL。包内 `RELEASE.json` 记录版本，`SHA256.json` 记录逐文件校验值，`package-checks/` 保存内容、对局、复盘和导出程序启动检查。

默认用户数据位于 `%APPDATA%/Godot/app_userdata/WizardCard Alpha v2.6.1/alpha-v2-frontend`，与旧版本目录分开。规则未升级；历史复盘是否可读仍由运行时兼容性检查决定。
