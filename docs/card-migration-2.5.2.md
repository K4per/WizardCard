# Alpha v2.5.2 卡池迁移决策

核对日期：2026-10-21。最新设计的 101 项（71 张法术、10 张符文、20 张阵法）全部映射至正式定义；新增 24 个稳定 ID。卡池共 102 张，额外保留恩格亚斯四角星供已有卡组使用。逐项 ID、编号、插图、字段差异和设计快照哈希见 [迁移表](reports/alpha-v2.5.2-card-pool-migration.md) 及同名 JSON。行为验证单独记录在[逐卡验收矩阵](reports/alpha-v2.5.2-card-acceptance.md)，导入状态不等于最终验收通过。

## 稳定 ID 与兼容

- 中文展示名可以更新，旧卡稳定 ID 保留。四芒星沿用 `small-hexagram`；六、五、八芒星和太阳各沿用旧 ID。恩格亚斯四角星保持独立，不覆盖为四芒星。
- 支援术沿用 `aid`，类型由解析改为言灵，编号由 `020008` 迁移为 `030017`。旧编号停止使用，已有卡组按 ID 继续载入。
- 新增卡在各类型旧编号最大值之后分配唯一编号。`味契·烈火回炉` 与新增 `味契·回火` 是两张卡，分别使用 `sique-refire`、`sique-backfire`。
- 正十字、逆十字、安卡十字的最新设计效果为空且标记待定，三张卡完整保留 2.5.1 的数值、配方与效果。
- 机制修订提升至 5，规则版本和卡池版本均为 2.5.2。旧规则修订的行为仍由原有版本分支决定。

## 本版明确的规则解释

以下解释使设计中省略的细节可以执行，并作为本版卡面之外的裁定依据。

- 未注明来源的“加入手卡”从己方牌库检索；恢复类效果明确从己方灰烬区选择。女祭司与皇帝在发动前必须存在可支付额外费用及匹配的检索候选；若已发动后候选消失，则跳过该次检索，已支付成本不返还。
- 解析法术仅写一个设置/发动费用的，数字作为设置费用，发动费用为 0。隐士为 9/0、节制为 6/0、高塔为 7/0。
- 碎环术准备施法不选择目标，发动时选择对方空白阵法；副卡组阵法送灰是结算效果，不是发动成本。没有可送灰阵法时仍可发动，但不破坏目标；目标结算时失效不返还已支付费用。
- 未注明“临时”的新增荷载使用独立荷载；明确临时荷载遵循卡面指定的清除期限。清除荷载由拥有者在合法荷载来源中选择。
- 倒吊人支付当前普通生命的一半，向上取整；临时生命不能支付。牌库和灰烬区交换时阵法归副卡组，其他卡归主牌库，洗切使用对局确定性随机状态。
- 魔术师选择三个不同名称的己方牌库卡，公开后随机保留一个至手卡，另外两个抹除。抹除不等同送灰，不能触发送灰效果或通过灰烬恢复。
- 愚者的五张手牌门槛在支付/离开手牌前检查；没有其他己方解析区法术时才能发动。余下手牌洗回牌库后抽五张。
- 女祭司额外费用为己方手牌或场上符文送灰；皇帝额外费用为抹除己方解析区法术，检索阶级严格等于被抹除卡阶级加三。
- 世界每种类型最多选择一张（解析、言灵、咒符、符文），言灵候选排除所有同名世界，不要求四种全部存在。
- 死神的伤害类型只在暗蚀和光耀中选择；战车按一次解析减少事件加速一点，不按该事件减少的数值重复触发。
- 教皇免疫下一次完整伤害事件，在任一玩家结束阶段开始时失效。力量对双方伤害事件翻倍，同名唯一限制按控制者分别计算。
- 三、二芒星的设置加速下限为零，同时分别增加一点、两点独立荷载。月亮配方第四个阵法为阵体二的六、五、八芒星之一，不能用任意阵体二阵法替代。
- 恒风·湮灭之纹章保留卡面明确写出的双用途：附阵法时仅限恒风阵法；附法术时提供四点额外雷鸣伤害。
- 味契·魔力坩埚限制己方使用味契卡。香醋附着时获得两点临时生命，解除附着时另获四点；旧版减伤不再适用。辣椒按对方实际抽到的每张牌造成一点火焰伤害。
- 太阳只处理对方解析区盖伏法术；地震术处理双方解析区全部盖伏法术。送灰与销毁分别遵循各自规则，不能把两者合并处理。

## 插图与可重复导入

25 张用户提供的阿卡那与星芒 PNG 原样保存至 `assets/art/alpha-v252-20261021/source/`，同一字节内容复制至 Godot。清单记录来源、尺寸、SHA-256、采样方式和正式 illustration ID。后续提供的炙烤、吹火术、回火三张 JPEG 原图保存至 `source/sique/`，使用 `tools/extract_alpha_v252_sique_art.py` 保留原像素并生成透明 PNG 至 `processed/`，分别注册独立 illustration ID。地震术仍明确共用碎环术插图。正式 102 张卡对应 101 个唯一插图。

`assets/design/alpha-v252/` 保存三个设计 Markdown 和迁移前 2.5.1 定义快照。`tools/import_alpha_v252_content.py` 使用审定映射、稳定编号和显式效果覆盖生成正式卡牌、目录、插图注册与迁移表；不从自由文本猜测效果代码。正常重现不依赖仓库外目录：

```powershell
python tools/import_alpha_v252_content.py
python tools/catalog_source.py
python tools/generate_card_catalog.py
python tools/check_art_assets.py --update-inventory
python tools/catalog_source.py --check
python tools/check_art_assets.py --check
```

仅在设计来源更新时使用 `--design-dir` 显式刷新快照。效果的合法条件与结算由原生规则测试验证，前端只消费正式内容和权威投影。
