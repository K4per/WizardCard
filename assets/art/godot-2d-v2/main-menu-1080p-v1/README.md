## 1080p 排版与接入合同

设计画布 1920×1080，原点左上角。背景铺满；品牌层居中，实际显示位置见预览 HTML；五个菜单按钮从 `(680,480)` 起，尺寸 560×100，垂直间距 12。菜单文案依次为单人游戏、多人游戏、卡组构筑、游戏设置、退出游戏。标签采用实时中文字体，字号 36；文字不烘焙进按钮。

五个按钮的全画布 PNG 只在 `[680,490,560,100]` 放置组件。Godot 使用 `AtlasTexture.region` 读取该区域，再在目标控件中显示；**不能直接把整张 1920×1080 图片塞进 560×100 控件**。文字安全区是画布中的 `[760,512,400,56]`。Logo 实际区域见 manifest。普通/悬停/按下/禁用状态对应各自纹理；焦点稿包含独立标记，正式接入仍需核对与鼠标悬停叠加的优先级。

尺寸导出按有效可见内容统一注册；阈值 8 仅用于计算近透明留白边界，保留实际内容区域内的 alpha。使用 nearest 保持像素边缘。背景只做全屏尺寸归一化。按钮图形包含尖角，manifest 附命中多边形；正式 Godot 输入验收仍待完成。

后续页面同样先按 1920×1080 排版。小窗口采用容器重排、滚动和控件尺寸分档，不把整页连同字体一起缩小。正文目标 18–22px，辅助字段至少 16px；720p 辅助字段至少 14px。

## 边界

本批七份素材已接入 Godot 主菜单。五个产品入口中，单人游戏、多人游戏与卡组构筑尚无对应流程，暂时禁用并提供提示；设置、退出、底部场地预览与图鉴继续可用。运行时通过 AtlasTexture 使用 manifest 的实际区域，按钮有尖角命中与五态优先级。背景没有伪造可编辑的远景/前景分层，火焰与宝石也尚无序列动画。AI 原稿均留存，不宣称已在 Pixelorama 手工修绘。

## Godot 接入验收

实际 Godot 4.7.2 / Windows OpenGL 渲染回归共 355 项通过，覆盖 1280×720、1600×1000、1920×1080；包含悬停、键盘焦点、按下优先级、设置导航和窗口边界。运行资源 249 项哈希与尺寸通过。
