# v1.0 卡牌与规则接入验收

日期：2026-10-07。程序0.10.0-dev / 规则0.4.0 / 卡池0.3.0。对应用户v1.0卡牌设计及后续确认；本批为开发版内容接入，不是Alpha-v1.0最终发行。

## 交付内容

- 卡池24种：新增11种，并将旧13种的学派、速度、伤害类型与阵法费用对齐新规则。新卡原始插画已映射，11个SHA-256均与来源清单一致。
- 实现速度1–4、合法时点与来源检查、禁止手牌响应、埋伏/反转、解析完成直接释放、魔法飞弹对方施法阶段响应、类型伤害、抗性/免疫、临时生命、行动封锁、检索、解析加速与新符文修正。
- 基础阵法在卡组编辑页选择并保存；对战配置采用卡组值。基础荷载容量2，五芒星阵法容量5，开局总容量7；均衡开局10。卡面及详情保留阵法贡献，对局显示总容量与基础贡献。
- 新增速解与支援、持续荷载与防护、五芒星塑能三套合法30张预设；连同原牌表共七套，带打法说明。三档AI通过公开合法操作处理新规则。
- 新命令与状态支持确定性复盘，更新随包示例；旧规则/卡池/内容哈希记录明确拒绝读取。旧用户卡组重新校验，用户设置和卡组格式不变。
- 修复共用拖放区域优先选择埋伏的问题：言灵后场默认预置，解析区域默认解析，埋伏由操作菜单选择。针对解析中的法术使用行动卡可拖至目标。

规则口径与内容接口详见[新卡规范](../alpha-v1-cards.md)，设计者输入详见[指南](../card-design-guide.md)。
