# 保留原生内核并通过共同会话接口连接 Godot

已接受，2026-10-10。Alpha v2.0 保留纯 C++17 权威规则和确定性复盘，采用职责明确的静态库与单进程模块化架构；Godot 2D 通过可选 GDExtension 读取查看者投影、提交操作。本地与联网使用共同会话接口，TCP 位于独立传输适配。这样可以复用现有规则验证与联机协议基础，并让规则、内容、前端和网络工作在不同模块中推进。

重写为 GDScript 会同时改变规则运行与表现环境，使历史回归难以复用；将每个模块拆为进程会增加部署、协议和同步成本。独立测试的模块接口足以满足本轮协作需求。场景类型、渲染、音频与套接字类型不进入规则内核。
