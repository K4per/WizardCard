# WizardCard 2.5.0-preview.2

2026-10-13。本次完成用户修改清单，按法术列表和阵法列表同步21张法术、8张阵法。正式卡池仍为45种，既有稳定ID和插画保留。

- 魔素上限提高至20；阳炎爆仅按己方灰烬区塑能法术减免设置费用，发动费用固定2。繁彩球正确选择六种伤害类型。
- 所有伤害法术只作用于对方玩家，缝合生命可选择己方或对方玩家。咒符盖伏免费、占用环位并保留等待期限。
- 修正克敌机先发动成本、整回合护盾、法术反制荷载、滑稽魔盒目标与等级边界、持续法术触发及阵法配方和免疫。太阳星查看和曳光弹展示不反转盖伏卡。
- 手牌、场地和详情使用实时费用；解析法术右上角显示设置/施法双费用。补齐金光、蓝光、副卡组提示及符文附着小格。
- 手牌扇形左右对齐、悬停抬升并回落；对方牌背与己方同尺寸。盖伏卡无场上卡名，己方可查看详情，对方默认隐藏。
- 己方状态移至左下，回合与阶段提示移至切换阶段按钮上方。
- 阵法按阵体连续占槽：阵体2占两槽、阵体4占四槽，解析环位使用对应区域，剩余槽位保持空白。
- 构筑界面按用户追加要求采用类似YGO Pro2的简洁三栏布局，配色与对局一致：左侧插画和完整详情，中间同时显示40张主卡组与10张副卡组，右侧搜索与筛选卡池。保留插画，取消当前界面装饰素材，列表与确认弹窗统一为简洁样式。

Windows x64便携包解压后运行 `WizardCard.exe`。包内 `SHA256.json` 列出运行文件哈希。旧preview.1复盘因程序版本和卡池哈希变化而拒绝；卡组草稿继续读取并按当前卡池校验。

具体卡牌对照见[卡池同步审计](../reports/preview2-card-alignment.md)，全部清单和最终验证见[交付报告](../reports/2.5.0-preview.2.md)。
