# WizardCard Alpha v2.5.3

发布日期：2026-10-23。程序、规则、卡池版本2.5.3，机制修订6。

- 开局魔素0；高阶盖伏可放在低等级阵法，反转和表侧设置仍须满足等级。补齐手牌高速言灵响应，合法动作与权威命令共用费用、时点和优先权检查。
- 同步10.22卡牌资料及味契修订，落实神恩炖肉、倒吊人与风暴纹章的设计确认。正式卡池99张，三张待定十字阵法仅保留为草稿。名称差异沿用现名和稳定ID，详见[裁定](../card-migration-2.5.3.md)。
- 挑战AI提供调试控制台：从虚空加入卡牌、调整普通/临时生命、魔素和各类荷载，独立无限资源开关，以及回到上一回合。命令由本地权威会话执行并写入可复盘记录；联机、换手、教学、观战和回放不能调用。
- 联机支持域名、IPv4/IPv6、多地址尝试和异步解析；解析失败、拒绝和超时有明确提示。4MiB是待发送队列上限，复盘分块和背压保留，调查见[网络报告](../reports/alpha-v2.5.3-network.md)。
- 对局和复盘在左下显示我方资源、右上显示对手资源，区分普通/临时生命、魔素上限与荷载来源；日志默认收起，确认与放弃按钮居中并阻止底层误触。

便携包解压后运行 `WizardCard.exe`。版本、内容hash和文件校验值见包内 `RELEASE.json`、`SHA256.json`；ZIP旁有 `.sha256`。完整验证结果见[交付报告](../reports/2.5.3.md)。
