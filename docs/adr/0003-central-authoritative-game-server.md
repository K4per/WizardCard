# 中央权威房间服务器

已接受，2026-11-03。延续 ADR 0001/0002 的 C++17 权威规则、查看者投影和传输隔离。服务器是单个 Linux 进程，承载多个独立双人房间；双方均为远端玩家，房主仅配置房间。Godot 继续是唯一产品前端。

中央网络使用独立协议 5 和严格校验证书的 TLS；旧协议 4 仅保留诊断回归。Asio/OpenSSL 仅为可选服务器/native probe 依赖，Godot 客户端使用自身 TLS。应用和规则模块不依赖网络运行时。每房间串行执行规则，不同房间共享有界工作池；磁盘写入使用独立有界 executor。

正式内容为规则/卡池 2.6.0、mechanicsRevision 10，替代 ADR 0002 中生产仅支持 2.5.5 的版本限制。历史卡池仍服务历史回归，不默认用于中央服务器。

2026-11-05 更新：Alpha v2.6.2 将程序、规则及卡池统一为 2.6.2、mechanicsRevision 11，替代上段的生产版本。保留传输协议5及十进制字符串标识；握手严格校验程序、规则、mechanics、卡池及内容哈希。阶段触发、计时、持续修饰、控制权暂借和额外回合纳入事务状态、投影及复盘，使用 `wizardcard-state-v7` 与 digest schema 3。旧状态摘要无法表达新增状态，因此拒绝跨版本客户端和复盘，而不为相同协议增加隐式兼容转换；历史卡池继续用于隔离的回归测试。详见 [2.6.2发行说明](../releases/2.6.2.md)。

2026-11-10 更新：Alpha v2.6.3 统一程序、规则和卡池为2.6.3、mechanicsRevision 12。传输仍为协议5，状态格式v8、复盘格式6、digest schema4；正式握手继续拒绝混版。新增带轮次的秘密猜拳开局与显式环位命令，开局先猜拳、抽5张，再同时公开初始阵法。客户端内置正式服公开证书并保留域名、有效期和信任链校验。固定教学局仅经本地教程入口设置，复盘头记录章节以确定性还原，中央房间不接受教学局配置。

断线冻结规则时钟，60 秒内重连，否则房间中止且不产生胜负。中止元数据与规则 result 分离。增量日志保留持久化进度，Accepted 不承诺落盘；写入故障独立冻结，重启中止未完成对局，不实现活局恢复。完整私密复盘仅正常终局提供给双方。

没有账户、自动匹配、数据库、分片或服务器间调度；部署目标是 20 房间/40 玩家。详见中心服务器设计与实施计划。
