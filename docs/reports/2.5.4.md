# Alpha v2.5.4 交付报告

## 版本与内容

- 程序版本：`2.5.4`；规则与卡池：`2.5.4`；机制修订：`8`。
- 正式卡池：135张（30阵法、42解析、29言灵、19咒符、15符文）；七星16张、血契20张；3张十字阵法仍为不可构筑草稿。
- 需求裁定已按用户确认执行。响应模式为全时点、自动时点、忽略时点；该模式不改变规则阶段或跳过强制效果。
- 卡牌逐字段来源、稳定 ID、效果实现与插图记录见[逐卡差异报告](../../assets/design/alpha-v254/card-diff-report.md)。

## 验证

本节只记录最终构建与发布前的实测结果。构建、内容校验、原生/ Godot 测试、便携包验证和产物哈希在完成后补入；失败或跳过的检查须保留原因，不以既有版本证据替代。

## 已知限制

- 历史 2.5.3 回放与新版本因规则版本、卡池版本或内容哈希变化而不兼容；旧牌组保留稳定 ID，需对无效卡牌进行修复。
- 三张待定十字阵法继续保留在来源快照和草稿目录中，不进入正式构筑。
