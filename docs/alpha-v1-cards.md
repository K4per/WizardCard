# v1.0 新卡与规则接入规范

更新：2026-10-07。程序 `0.10.0-dev`、规则 `0.4.0`、卡池 `0.3.0`。正式卡池共24种：原13种与本批11种。设计来源为用户提供的 `E:/Project/WizardCard-CardDesign/Alpha卡池/v1.0卡牌设计.md`；采用用户确认的歧义处理口径。本规范补充并覆盖旧规范中速度、手牌响应、埋伏及阵法费用的冲突内容。

本页记录24种卡的接入批次。正式 Alpha v1.0 已升级程序 `1.0.0-alpha`、规则/卡池 `1.0.0`，共30种卡；初始和最大生命均40，设置言灵与跳过释放规则按[发布修订](alpha-release-cards.md)执行。

## 咒文速度与时点

连锁仍仅在六种规定窗口建立：阶段开始、阶段结束、行动宣告、准备宣告、释放宣告、被动触发；速度不会凭空创造响应时点。

| 速度 | 可用阶段 | 加入连锁 |
|---|---|---|
| 1 | 自己主要、施法 | 只能根节点 |
| 2 | 双方主要、施法 | 顶端速度≤2 |
| 3 | 双方任意阶段 | 顶端速度≤3 |
| 4 | 双方任意阶段 | 顶端非4；四速之后禁止新增响应 |

响应还须满足卡牌声明的来源、窗口、归属、目标与支付。解析法术最高2速。**正式规则禁止从手牌响应**；可响应来源为预置言灵、已解析完成且声明快速能力的解析法术、可反转且声明能力的埋伏卡。历史阶段二测试卡池单独保留旧规则夹具，用于旧核心回归；不开放旧版复盘。

正常解析、设置、行动在自己的主要阶段进行；解析完成法术可先准备，自己的施法阶段选择释放。自己的施法阶段也可直接支付并释放就绪法术；预置言灵可在速度允许的自己的阶段主动释放，只有响应能力的卡牌必须等待时点。被取消准备的法术本自己的回合禁止重试，包括直接释放与快速响应；下一自己的回合恢复。

魔法飞弹在对方施法阶段的合法窗口从解析完成状态直接支付实际施法费用，入链释放，不先建立准备链。准备和释放仍为不同链节；法术反制只针对对手待释放的法术链节，不取消准备、阶段标记或普通行动。四速后双方自动放弃并开始结算。

## 埋伏与私有信息

埋伏支付1魔素，不形成绑定荷载。行动与言灵共用3个后场位；解析法术占合法阵法环位。阵法与符文不能埋伏；不能给背面卡附着符文。埋伏当个全局回合不可反转，至少进入下一个全局回合后才可反转。

背面解析法术不推进进度。反转解析法术支付实际解析费用，重新开始解析；立即解析与阵法加速仍适用。行动反转支付使用费用并使用；言灵反转支付设置费用并发动，纯响应言灵须在合法响应窗口反转。行动封锁同样阻止反转使用行动卡。效果将就绪解析法术转为埋伏时丢失进度，遵守新的反转等待限制。

敌方视角只接收埋伏实例ID、拥有者、区域、承载关系与背面状态；隐藏名称、定义ID、费用、学派、速度、效果和支付记录。自己的详情可见；反转或销毁后进入公开信息。检索时只给选择者投影合格牌库候选，检索事件对其私有，牌库其余内容仍不可见。

## 伤害、防护与荷载

每位玩家自带基础荷载容量2，与阵法容量相加；不占阵法槽、不产生荷载，也不会因阵法离场消失。生命之五芒星自身容量由3调为5：均衡开局为8+2=10，五芒星开局为5+2=7。荷载等于总容量时安全，超过才发生过载；卡面容量始终表示阵法本身的贡献。

伤害类型共12种：火焰、寒霜、光耀、黯蚀、毒素、闪电、心灵、声波、力场、挥砍、钝击、穿刺。先判断免疫，再抗性减半向下取整，最后先扣临时生命之核，再扣生命之核。抗性不重复减半；免疫优先。

临时生命之核取较高值，不叠加，不受生命上限30限制，也不随回合到期。治疗不补临时生命。避火咒在成功释放后专注生效；同链先结算避火咒可减轻稍后火焰伤害。专注被销毁、放弃或替换后失去抗性。

| 荷载 | 清理 |
|---|---|
| 绑定 | 卡牌离场时清理；解析和实际施法费用形成等量绑定荷载 |
| 普通临时 | 按原承担者自己的结束阶段期限清理 |
| 来源关联临时 | 紊乱波动首次5，后续自己的施法阶段3；不按回合到期，来源销毁时统一清理；临时清除效果仍可清除 |
| 次回合临时 | 法术反制、瞬发回路过载产生；承担者下一个自己的结束阶段清理 |
| 独立 | 生命缝合的2点保留至明确独立清除效果，不随瞬时来源离场清理 |

每个完整链节关联清理后检查过载与胜负。法术反制承担目标宣告时快照的实际施法费用，含符文增加；瞬发回路过载承担目标实际解析支付，含基础阵法折扣。取消不退款。

## 阵法、符文与构筑

设置费用 `cost` 与阵体 `body` 分离。旧均衡、阿克乌姆沿用旧核心实际设置费用0；替换/拆除的原额外2魔素规则保留。生命之五芒星设置1，恩格亚斯设置0；基础阵法开局免费入场。

基础阵法**只在卡组编辑页面选择并保存**，不占30张主卡组。对战配置只展示所选卡组的基础阵法，无额外覆盖项；双方和AI分别使用各自牌表中的配置。

生命之五芒星只有作为基础实例时，减免其承载的塑能、咒法系解析费用1，最低0；支付、荷载和奥术圆环返还都用实际支付。恩格亚斯每个自己的回合自动加速第一张在它上开始解析、位阶≤1且尚需等待的法术；立即解析法术不消耗次数。

昂扬附在阵法上时容量+1、最大位阶+1、收入-1；总收入最低0。附在法术上时实际施法费用+1，成功首次释放额外对对方造成2力场伤害，持续周期效果不重复此额外伤害。预置言灵设置后附上昂扬，发动时补交增加的施法费用及荷载；专注维持使用修正后的费用。

克敌机先检索一张普通或罕见行动卡，选择后加入手牌并确定性洗切剩余牌库；无候选自动继续。昏昏入睡只封锁对方下一个自己的回合。

## 内容接口与版本

正式卡池顶层 `mechanicsRevision: 1`、`baseLoadCapacity: 2`；历史夹具未声明基础容量时默认0。新增 `school`、`speed`、`resistances`、`immunities`；伤害效果使用 `damageType`，默认力场。学派八种含用户确认补充的预言系，均生成构筑标签；速度、伤害类型、抗性、检索与立即解析也生成筛选标签。

响应 `sources` 支持 `words / analysis / ambush`，`phases` 可限制具体阶段；基础限制由速度统一约束。新效果为 `source_temporary / temporary_life / block_actions / counter_spell / search_action / destroy_ambush / accelerate_analysis / grant_resistance / conceal`；新目标为 `own_analyzing_spell / enemy_spell_link`。有限效果均有核心实现，标签不自动赋予规则行为。

符文字段 `capacityBonus / rankBonus / castCostBonus / damageBonus` 与有符号 `incomeBonus`；阵法 `baseAnalysisDiscount / quickRankOne` 当前用于本批固定效果。

新命令编号15埋伏、16反转、17直接释放；原编号保留。复盘格式仍为2，严格核对程序、规则、卡池及内容哈希；新增状态、类型伤害、速度和实际费用进入确定性状态摘要。旧记录明确拒绝。卡组与设置存储格式1继续使用，旧草稿重新校验。
