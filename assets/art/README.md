# 运行时美术资源

程序 0.4.1-dev 接入项目已有 pixel_fantasy_v2 的四张透明 PNG：均衡、火球术、银光锐语、奥术圆环。文件逐字节复制，未修改原图；原型源目录保留在工作区，安装时排除 prototypes。

runtime.json 按稳定卡牌 ID 映射图片。provenance.json 保存来源版本、原始生成文件名、SHA-256 和许可说明，发布包无需原型目录即可追溯。原图来源为项目内 OpenAI imagegen 生成素材，不额外声明第三方图库授权，也不改变项目既有许可。

卡面、场内缩略图及卡牌详情使用同一透明插图，保持比例、最近邻采样。其余九张卡牌暂用代码绘制的类别纹章与名称首字。场地边框、牌背、按钮及高亮由 SFML 绘制，未将旧概念截图作为场地贴图。
