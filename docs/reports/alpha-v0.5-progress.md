# Alpha v0.5 进度报告

日期：2026-10-04。程序版本 `0.5.0-alpha`，规则 `0.2.3`，卡池 `0.1.0`，发行标签 `v0.5.0-alpha`。

## 本轮完成

1. 行动区高度从49增加到101，灰烬区从101缩小到49；双方镜像同步调整，拖放高亮、点击区域与显示一致。窄灰烬条保留卡名与详情入口。
2. 左上标题避开边饰，并显示 Alpha v0.5；窗口标题保持显式 UTF-8 转换。
3. 法术可拖到解析区空白处。依据规则投影的合法候选，单阵法自动匹配，多阵法弹窗选择，显示名称、实例编号与空余环位。无候选不接受拖放；无效选择、取消、视图更新均不支付费用，仍需最终确认。
4. 初始生命30降至20，恢复上限保持30；这是单参数节奏试验，不修改卡牌费用、伤害和卡组。

## 当前能力

已具备纯 C++17 规则核心、JSON 内容层、SFML 客户端、13种示例牌、五阶段、单层响应、符文与持续效果、规则选择协议、状态检查和确定性复盘。本地双人换手可完整对战；独立手牌与对称场地、中文卡牌详情、卡上操作、拖放和排序、低对比背景及现有美术资源已接入。

## 验证与限制

Windows Release 完整构建与45项 CTest 通过。种子42的完整对局为119条命令，拖放重放92次手势，每步摘要一致，最终 `50ac61d134b97de7`。截图检查了标题、区域比例、双阵法弹窗和20点初始生命。详细验证记录见 [validation.md](../validation.md)。

本轮自动跑局不能证明平衡已经改善；约20局真人探索尚未完成。Linux 验证由远程 CI 执行，本机仅验证 Windows Release 与无窗口 Debug，未把它们当作 Linux 结果。不同窗口比例、设备和连续真人对局仍需验收。当前不实现联网、AI、编辑器或复杂反制。

## 发布与兼容性

发布包名 `WizardCard-0.5.0-alpha-windows-x64.zip`，包含运行时资源、字体及许可证，可脱离源码目录运行。Git 保留代码、资源、规则与计划；构建缓存和运行日志不入库。旧版复盘由于程序/规则版本不匹配会拒绝读取，需使用原版程序与原卡池复盘。

后续保持 Alpha 迭代。路线于2026-10-05更新为 [Alpha-v1.0 计划](../plans/alpha-v1.0.md)，目标包含本地换手、AI、构筑和教学；本报告记录的Alpha v0.5功能与验证结果保持不变。
